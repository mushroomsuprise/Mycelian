A container is one browser-source URL that shows several templates at once. Each template stays its own page and is loaded in a frame inside the container. Mycelian does not merge the HTML files.

{{icon:place}} Spore StudioContainers {{icon:save}} Saved to templates/_containers/{route}.json

Use a container when you want one OBS browser source for a whole layout, such as a game scene with a chat box, a goal bar and a now-playing card. Every template inside it still keeps its own URL.

The Containers screen

Click Containers at the left of the Spore Studio toolbar. The columns change to a template library, a container canvas, and container settings.

  1. Toolbar. Pick a container, create one ({{icon:add}} New), duplicate it ({{icon:layers}}, Duplicate this container), delete it ({{icon:delete}}), undo and redo ({{icon:undo}} {{icon:redo}}). Simulate (the menu that says Live content) pretends every “Fits its content” box is empty, half full or full so you can see how the other boxes react; nothing is saved. Placeholders shows template names instead of live previews, which keeps the editor light when many templates are placed. Preview opens the saved route. Save writes the container.
  2. Templates. Every template you can place, grouped as Spore Studio, Built-in (activity_feed and source_controls, which Spore Studio cannot edit but can place) and Other templates. Type in Search templates to filter. Drag a row onto the canvas, or double-click it to add it.
  3. Canvas. Each rectangle is a box showing one template. Drag to move it and drag any edge to resize it; while you drag, every box shows the size you drew it at. The badge in the corner says how the box sizes itself, a dashed outline marks a shared space, and the ↕ arrow shows which box gives room to which (see Sizing and shared spaces). A box whose template no longer exists is marked (missing).
  4. Inspector. Settings for the selected box: Sizing first, then Position and size, Behaviour, Audio and Stacking. On/off settings are switches. Click empty canvas to see Container settings instead.

Create a container

Start a new container

In Containers mode, click {{icon:add}} New. The New container dialog opens. Enter a Name. The Route path fills in from the name (The address OBS loads, like /stream_layout. It follows the name until you edit it.); change it if you want a different URL, such as game_layout. Pick a Resolution: 1920 × 1080, 1280 × 720, 1080 × 1920 or 720 × 1280. This is the size of the OBS browser source. Click Create. If the route is taken or the name is not allowed, the reason shows in the dialog.

Place templates

Drag templates from the Templates list onto the canvas. Spore Studio templates, built-in templates and hand-written HTML templates can all be placed. A container cannot be placed inside another container.

Arrange the boxes and let them make room

Move and resize the boxes. If one box (like FF7 or alerts) changes how much it shows, set it to Fits its content and the box next to it (like chat) to Fills leftover space (see Sizing and shared spaces).

Save and add it to OBS

Click Save. The route is listed on SettingsAbout with a Container badge and a count of the templates inside. Add it to OBS as a browser source at the container's resolution: http://127.0.0.1:{port}/game_layout

Sizing and shared spaces

Boxes can make room for each other. The usual case: chat sits above FF7, and when FF7 pops in its enemies panel, chat gets shorter so the panel has room. When the panel goes away, chat grows back. This works with every template (built-in, your own and Spore Studio ones) without changing them.

SizingWhat the box doesGood for
FixedStays exactly where and how big you drew it. It never moves for other boxes.Game capture frame, webcam border, logos
Fits its contentGrows and shrinks with what the template is showing right now, up to the size you drew it. When it shows nothing it closes up (or keeps its size, if you choose). Mycelian looks at what is actually on screen: text, pictures and coloured boxes. Invisible wrappers, faded-out parts and anything cut off at the edge don't count.FF7, alerts, goal bars, now playing
Fills leftover spaceGets whatever room the Fits its content boxes don't use. Its real size changes: the template sees a smaller window and re-flows (chat keeps its newest messages in view). It is never smaller than its minimum.Chat, activity feed

Place the two boxes

Put chat where it should be and ff7 under it, in the same column. Draw FF7 as big as it can ever get (all panels showing).

Set FF7 to Fits its content

Select ff7 and click Fits its content under Sizing. Chat, the box next to it, joins the same shared space as Fills leftover space automatically. A dashed outline shows the space on the canvas.

Give chat a minimum

Select chat and set Never smaller than, for example 200 px or 25 % of space. A dashed line on the canvas shows it.

Try it with Simulate

In the toolbar, change Live content to Pretend all full and then Pretend all empty, and watch chat shrink and grow. A banner above the canvas reminds you that you are previewing pretend sizes; click Back to live when you are done. Then Save.

Changes on stream are instant. A box that hasn't loaded yet keeps the size you drew it until Mycelian can see its content.

For template authors: control what gets measured

Mycelian measures your template from outside, so you usually don't need to do anything. To measure only part of the page, add data-mycelian-content to the element that holds the content. To report the size yourself, send parent.postMessage({type: "mycelian-content-size", width: 400, height: 120}, "*") (send 0, 0 when nothing shows). Send {type: "mycelian-content-size", auto: true} to go back to automatic measuring.

Duplicate and delete

{{icon:layers}} (Duplicate this container) opens the Duplicate container dialog (Copies the saved version of this container to a new route.). Name and Route path start as the original's name plus copy and its route plus _copy; change them, then click Duplicate.

{{icon:delete}} asks Delete container /game_layout?: The route stops working in OBS. The templates inside it are not deleted. Click Delete container to confirm.

Switching to Templates or to another container with unsaved changes asks Discard unsaved container changes?: Keep editing stays, Discard changes drops the edits. Every dialog closes with Esc or a click outside it.

Warnings

When sizing settings can't all be met, a warning appears above the canvas. Show box / Show boxes selects and outlines the boxes it is about.

WarningWhat to do
The boxes in shared space “Space 1” need more room than the space has …Lower a minimum, lower the gap, or make the space bigger by drawing its boxes larger
In shared space “Space 1”, the minimum of “ff7” is bigger than the size it was drawn at …Draw the box larger or lower its minimum
The boxes in shared space “Space 1” aren't in the same column …Line the boxes up so they overlap, one above the other (or side by side for Left to right)
“poll” is set to scale from its design size, so it can't fit its content …Set its Fit to Native, or make it Fixed
“old_banner” was not found …Pick another template for the box or remove it

Deleting a template asks first and names the containers that use it. Its slot stays: the editor marks it (missing), and on stream that spot is simply empty. Pick another template for the slot or remove it.

Can I name a template the same as a container route?

No. New template names that match an existing container route are refused, so the two URLs cannot collide.
