This action connects to your Mycelian web server to toggle alert playback.

Default settings:
• Server URL: 127.0.0.1:5000 (host:port format)

The button will show "TOGGLE ALERTS" with "ACTIVE" below when alerts are playing, and "PAUSED" below when alerts are paused.

The button automatically syncs with your app - it will update if alerts are paused/resumed from within the Mycelian interface.
