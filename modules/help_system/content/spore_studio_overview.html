Spore Studio is Mycelian's visual editor for browser source overlays. You drag blocks onto a canvas, style them, wire them to live events, and click Save. Mycelian then writes the overlay HTML, its JSON config, and an editor file that Spore Studio reopens later.

The editor at a glance

Spore Studio runs inside the Spore Studio tab. Click the inspector tabs on the right of this picture to see what each one holds.

  1. Toolbar. Switch between Templates and Containers, pick the active template, create or delete one, and undo or redo.
  2. Left column. Blocks is the palette, grouped as Data, Layout, Media, Text and Widgets. Groups start collapsed; click a header to open it, and Spore Studio remembers your choice. Outline lists every element under its category. Assets holds this template's files.
  3. Canvas. The design surface, shown at your template's size. The checkerboard marks transparency, so the overlay composites cleanly in OBS. Elements with an entrance or exit animation show an anim badge.

The Unsaved changes label in the toolbar appears as soon as you edit. There is no separate status bar; messages such as Created my_alert appear briefly as a toast at the bottom of the editor.

Before you start

  • The overlay server is running. It starts with the alert system. If you open the tab too early you see Waiting for the overlay server to start… and a Retry button. The tab also retries on its own for about a minute.
  • OBS or another app that can show a browser source, to put the finished overlay on stream.
  • Optional: you know how templates and alerts work in Mycelian.

Create your first template

Create the template

Click + New. Type a name, pick the alert system, set the size, and click Create.

FieldDetails
NameBecomes the file name and URL. Letters, numbers, _ and - only, and it cannot start with _. static, assets, api and debug are reserved, and so is any container route.
Alert systemQueue (next_alert) or Instant (instant_alert). See Queue vs Instant.
Copy from existing(none), or a Spore template to clone (for example bitcounter)
Width / Height (px)Default 800 × 200. You can change the size later on the Canvas tab.

Add a block

Open a group in Blocks and drag a block, such as Text, onto the canvas. The Element category dialog opens: pick a category or type a new one, then click Use category. Style the block in Properties.

Add media (optional)

Click Upload under Assets, or copy files into assets/my_first_overlay/. Drag a file onto the canvas to create an element, or double-click it to set the selected element's source.

Make it react

Use the Bindings tab to show, hide or change the block when an event arrives, or the block's Data feed section to drive it from live values. See Event bindings and Data feeds.

Test it

Click Preview and use the mock buttons to fire test alerts. You do not need to save first.

Save and add it to OBS

Click Save (Ctrl/Cmd+S). In OBS, add a Browser Source with this URL and set its width and height to your canvas size:

http://127.0.0.1:{port}/my_first_overlay

Replace {port} with the port your overlay server uses. The Source Settings tab lists the URL for every template. Turn on Shutdown source when not visible in OBS if the overlay does not need to run while hidden.

Spore Studio does not control OBS. You add the saved URL as a normal browser source, the same way as the built-in templates.

What Save writes

FilePurpose
templates/{name}.htmlThe overlay OBS loads. Rebuilt on every save.
templates/template_configs/{name}.jsonSource Settings values, Stream Deck actions, and preview mocks. Values you already tuned are kept.
templates/_spore/{name}.spore.jsonThe editor model. Spore Studio opens this, not the HTML.
assets/{name}/Images, video, audio and fonts for this template

Saved overlays also send their JavaScript errors and warnings to mycelian.log, tagged with the template name. Check the log when an overlay misbehaves in OBS.

Protected and legacy templates

activity_feed and source_controls are built-in overlays. They are left out of the template list, so they cannot be opened or deleted here.

Templates under Legacy (advanced mode) are hand-written HTML without a .spore.json file. They open in a limited mode; see Preview and legacy templates.
