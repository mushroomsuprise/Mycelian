Spore Studio is Mycelian's visual editor for browser source overlays. You drag blocks onto a canvas, style them, wire them to live events, and click Save. Mycelian then writes the overlay HTML, its JSON config, and an editor file that Spore Studio reopens later.

The editor at a glance

Spore Studio runs inside the Spore Studio tab. Click the inspector tabs on the right of this picture to see what each one holds. Most toolbar and tab buttons are icons; hover one in the real editor to see its name.

  1. Toolbar. Switch between Templates and Containers, pick the active template, create one ({{icon:add}} New) or delete it ({{icon:delete}}, Delete template), and undo or redo ({{icon:undo}} {{icon:redo}}).
  2. Left column. Blocks, Outline and Assets are cards, each with a count. Blocks is the palette, grouped as Data, Layout, Media, Text and Widgets, with a Search blocks box on top. Groups start collapsed; click a header to open it, and Spore Studio remembers your choice. Typing in the search box shows only the matching blocks. Outline lists every element under its category. Assets holds this template's files.
  3. Canvas. The design surface, shown at your template's size. The checkerboard marks transparency, so the overlay composites cleanly in OBS. Elements with an entrance or exit animation show an anim badge.
  4. Inspector tabs. Each tab is an icon. Only the open tab shows its name; hover the others to see theirs.

The Unsaved changes pill in the toolbar appears as soon as you edit. Next to it a second pill shows what is loading, such as Loading my_alert… or Legacy template (advanced mode). There is no separate status bar. Results such as Created “my_alert” and any errors appear as Mycelian pop-ups and in the notification centre (see Notifications); when Spore Studio is open in an external browser, they show as a short message at the bottom of the editor instead.

Before you start

  • The overlay server is running. It starts with the alert system. If you open the tab too early you see Waiting for the overlay server to start… and a Retry button. The tab also retries on its own for about a minute.
  • OBS or another app that can show a browser source, to put the finished overlay on stream.
  • Optional: you know how templates and alerts work in Mycelian.

Create your first template

Create the template

Click {{icon:add}} New. Type a name, pick the alert system, set the size, and click Create template.

FieldDetails
NameBecomes the file name and URL. Letters, numbers, _ and - only, and it cannot start with _. static, assets, api and debug are reserved, and so is any container route. Press Enter in this box to create the template.
Alert systemClick a card: Queued (next_alert) or Instant (instant_alert). See Queue vs Instant.
Start fromBlank template, or a Spore template to copy (for example bitcounter)
Canvas size (px)Width × height. Default 800 × 200. Click a preset to fill both: Alert 800×200, Lower third 1280×200, Widget 440×620, 720p 1280×720, 1080p 1920×1080. You can change the size later on the Canvas tab.

If the name is taken or not allowed, the reason shows in the dialog above the buttons.

Add a block

Open a group in Blocks (or type in Search blocks) and drag a block, such as Text, onto the canvas. The Which category is it in? dialog opens: click a category chip or type a new one, then click Add element. Style the block in Properties.

Add media (optional)

Click Upload under Assets, or copy files into assets/my_first_overlay/. Drag a file onto the canvas to create an element, or double-click it to set the selected element's source.

Make it react

Use the Bindings tab to show, hide or change the block when an event arrives, or the block's Data feed section to drive it from live values. See Event bindings and Data feeds.

Test it

Click Preview and use the mock buttons to fire test alerts. You do not need to save first.

Save and add it to OBS

Click Save (Ctrl/Cmd+S). In OBS, add a Browser Source with this URL and set its width and height to your canvas size:

http://127.0.0.1:{port}/my_first_overlay

Replace {port} with the port your overlay server uses. SettingsAbout lists the URL for every template under Browser source URLs; see Setting Up Browser Sources in OBS. Turn on Shutdown source when not visible in OBS if the overlay does not need to run while hidden.

Spore Studio does not control OBS. You add the saved URL as a normal browser source, the same way as the built-in templates.

What Save writes

FilePurpose
templates/{name}.htmlThe overlay OBS loads. Rebuilt on every save.
templates/template_configs/{name}.jsonSource Settings values, Stream Deck actions, and preview mocks. Values you already tuned are kept.
templates/_spore/{name}.spore.jsonThe editor model. Spore Studio opens this, not the HTML.
assets/{name}/Images, video, audio and fonts for this template

Saved overlays also send their JavaScript errors and warnings to mycelian.log, tagged with the template name. Check the log when an overlay misbehaves in OBS.

Protected and legacy templates

activity_feed and source_controls are built-in overlays. They are left out of the template list, so they cannot be opened or deleted here.

Templates under Legacy (advanced mode) are hand-written HTML without a .spore.json file. They open in a limited mode; see Preview and legacy templates.
