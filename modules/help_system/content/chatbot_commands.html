A command is a word that starts with !. When someone types it in Twitch chat, the chatbot posts your response. Responses can include variables such as the viewer's name or the words they typed after the command.

{{icon:schedule}} About 3 minutes {{icon:place}} ChatbotCommands {{brand:twitch}} Needs a Twitch connection

The chatbot replies as your channel, or as a separate bot account if you set one up. Both are covered in Twitch Setup.

The Commands tab

  1. New Command opens the editor. Refresh reloads the list.
  2. The search box filters cards by name, command, aliases or description.
  3. The switch turns a command on or off without deleting it. Disabled cards are dimmed and ignore chat.
  4. Badges show Mod Only, Counter and Limit (usage limit) at a glance. Counter commands get a Reset button.

The response preview on each card fills in variables with live or sample values, shown in italics.

What viewers see

Create a command

Open the editor

Click New Command. A large dialog titled Create New Command opens. When the list is empty, the Create First Command button does the same.

Fill in Basic Information

  1. New commands reply to Twitch and YouTube. Untick one to skip it. At least Twitch stays selected if you untick both.
  2. Optional. Pick a server and channel and click Add Discord channel to post the reply there too. Needs Discord connected.
  • Command Name is what viewers type, without the !. Matching ignores upper and lower case.
  • Name is the label on the card. Both are required.
  • quote and add_quote are reserved for the quote system and cannot be used as names or aliases.
  • Turn on Display as banner instead of a chat message to show the reply on the chat overlay banner instead. Twitch, YouTube and Discord are then hidden and skipped.

Set limits in Settings (optional)

Expand Settings under Basic Information.

SettingWhat it does
Mod OnlyOnly chatters with the moderator badge can use it.
Cooldown (seconds)Time before anyone can use the command again. One cooldown per command, shared by all viewers. 0 means none.
Usage LimitTotal uses allowed. After that the command stops working. 0 means unlimited.
Command TypeBasic Command, Counter Command or Reset Command. See below.
Argument MappingsName a word the viewer types after the command. Mapping city to Position 1 lets !weather Paris fill {city} with Paris. Up to Position 10.

When a command is blocked, the bot says so in Twitch chat, for example "Command is on cooldown (12s remaining)", "Command has reached its usage limit" or "Command is mod-only".

Write the response

Type the message in Response Text. Preview above it shows the result as you type. The Variables panel on the right lists what you can insert, grouped as Basic, Arguments, Command/Event, Statistics, YouTube, Quotes, API Response and Custom. Click a variable to add it to the end of the response.

Custom Variable above that panel creates a reusable variable. See Chatbot Variables.

Save and test

Click Create Command at the bottom of the dialog (it reads Update Command when editing). Then click Test on the card.

Test sends the real response to your chat targets as if TestUser used the command. It counts as a use: it adds to Used, raises a counter and starts the cooldown.

Command types

Replies with the response text. The card shows how many times it was used.

Command Name: discord
Response Text: Join us on Discord: https://discord.gg/example

Adds one every time it is used. {count} is the new total. The count is saved with the command and shows on the card. Reset on the card sets it back to 0.

Command Name: deaths
Command Type: Counter Command
Response Text: Deaths this stream: {count}

Counter commands also show a Persistent Counter switch ("Counter will persist between app restarts").

Sets another counter command back to 0. Pick the target in Command to Reset. If you have no counter commands yet, type its name without !.

Command Name: resetdeaths
Command Type: Reset Command
Command to Reset: deaths
Response Text: Reset !{target_command} (was {target_count})

{target_command} is the counter's name and {target_count} its value before the reset. Combine with Mod Only so viewers cannot clear it.

Examples

Command Name: hug
Response Text: {username} gives {command_word_1} a big hug!

!hug @friend → night_owl gives @friend a big hug! Use {command_message} for everything after the command.

Command Name: raids
Response Text: We have been raided {stats.alerts.raids} times. Thank you!
Command Name: time
Response Text: It is {time.hh:mm.12.ampm.tz} for the streamer.

The full list is in Chatbot Variables.

API Integration

The editor also has an API Integration section. Turn on Enable API Call and pick from Select API Endpoint to call a Twitch API endpoint each time the command runs. Only endpoints your Twitch sign-in has permission for are listed. The response fields then appear under API Response in the Variables panel, along with {api_status} and {api_success}.

Questions

Nothing happens when I type the command

Check that the card says Enabled, that the message starts with ! and the name has no typo, and that Twitch is connected. Commands only listen to Twitch chat. YouTube chat does not trigger them, even when YouTube is a reply target.

My moderators can use a Mod Only command but I cannot

Mod Only looks for the moderator badge on the chat message. The broadcaster badge is not the same badge, so the channel owner is treated as a regular viewer for this check.

A variable shows up as plain text like {username}

Check the spelling and the curly braces. Some variables only exist for certain command types: {count} only works on Counter commands, {cooldown} only when a cooldown is set, and {usage_left} only when a usage limit is set.

Can a command run on a timer?

Use an Interval event instead. See Chatbot Events.
