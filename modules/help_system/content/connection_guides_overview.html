Client secrets, tokens and passwords work like passwords. Mycelian stores its API credentials encrypted. Do not share them or show them on stream.

How to tell what is connected

The status footer at the bottom of the main window has a badge for each service you have set up. Green means it is working.

  1. Green (Connected): working.
  2. Gray (Disconnected): set up but not connected right now. For OBS this usually means OBS is closed.
  3. Gray (Idle): credentials are saved, but sign-in has not finished. Open the tab and click Connect.
  4. Red (Error, Expired, Auth Failed): needs you. Check the credentials, then connect again.

A service you have not set up has no badge, except Twitch, which always has one. The full color legend and the minimal badge mode are in Status Footer.

If a connection will not work

The browser opened but Mycelian never connected

Most sign-ins return to a localhost address on this computer. The redirect URL in the service's developer app must match exactly what the guide shows. Fix it there and click Connect again.

The badge turned red after working for days

The token expired or was revoked, or the secret was changed. Open the service's tab and connect again. If that fails, create a new secret and paste it in.

Everything is red at once

Check the Internet badge. With no network, online services show No Internet or Unreachable. See Connection Problems.
