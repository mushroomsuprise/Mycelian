Create an alert

Pick the alert type

Open the Alerts tab and click a sub-tab: Bits, Subscriptions, Streaks, Gift Subs, Donations, Raids, Follows or Channel Points.

Choose + Create New Alert

Open Select Alert and choose + Create New Alert. The form fills with defaults: Duration 3 seconds, Volume 100%, everything else empty or off. To start from an existing alert instead, select it and click Duplicate; the copy gets the next free amount.

Set the amount

Type one amount, or turn on Range Mode and fill Min and Max. The amount is what identifies the alert, so each amount or range can only have one alert. See Amounts and ranges.

Add a GIF and a sound

Open Visual and click Browse to pick an image. Open Audio and click Browse under Primary Sound. Both must be inside Mycelian's assets folder; see Alert Media Configuration.

Test, then save

Click Test Alert to play the form as it is. When it looks right, click Save Alert. A toast confirms, for example Saved bits alert: 100-999 Bits.

The alert form

Every alert type uses this form. Click a section header to open or close it; in the app all sections start closed.

  1. Selector row: which alert you are editing and the amount it answers to.
  2. General: how long it shows and whether it may stack.
  3. Audio: fades, volume and the main sound file.
  4. TTS: read the alert out loud with the browser's speech voice.
  5. Visual: the GIF or image.
  6. Randomizer: play a random sound from a folder some of the time.
  7. Unsaved changes appears after you edit. Delete Alert only shows for an alert that is already saved.

Amounts and ranges

The selector row is different on each sub-tab:

Sub-tabAmount fieldDefault for a new alert
BitsAmount (shown with "bits")100
SubscriptionsMonth: 1 for a new sub, 2+ for resub months1 (range 1-3)
StreaksStreak count2 (range 2-5)
Gift SubsAmount (subs gifted)1
DonationsAmount (alert currency)5
RaidsAmount (raiders)10
FollowsNone
Channel PointsNone. You pick a Twitch reward.

Turn on Range Mode to replace the amount with Min and Max. Both ends count: 100-999 matches 100 and 999. A tiered Bits setup could look like this:

1-99        Small cheer
100-999     Medium cheer
1000-100000 Big celebration

When an event arrives, an exact-amount alert beats a range. If no exact alert exists, the first range containing the amount plays. If nothing matches, Mycelian falls back to another alert of the same type.

Keep ranges from overlapping. If two ranges contain the same amount, either one may play. Test the boundary values (for example exactly 100 and 999) after you save.

Saving with an amount or range that already has an alert replaces that alert. Use a different amount, or select the existing alert and edit it.

Resub Fallback

On Subscriptions, the selector always lists Resub Fallback, and a Resub Fallback switch sits at the right of the row. When the switch is on, the Resub Fallback alert plays for resubs that don't match any configured month alert. When it is off, unmatched resubs fall back to another sub alert.

Channel Points

The Channel Points sub-tab loads your rewards from Twitch. Instead of Select Alert it has Select Point Reward and a Refresh Rewards button. It also adds:

  • Enable as Alert in General. A reward only plays an alert when this is on.
  • Audio Only in Audio, for sound-only redemptions.
  • A Twitch Options section that edits the reward on Twitch itself.

To make a new reward, choose + Create New Reward, fill in Twitch Options, and click Save Alert. If the list shows Twitch not connected - Please connect in Settings, connect on Settings → Twitch. If it shows Channel points not available — Affiliate or Partner required, your channel cannot have custom rewards yet.

Edit, duplicate and delete

  • Edit: choose the alert in Select Alert, change fields, click Save Alert.
  • Duplicate: copies this alert into a new unsaved alert and moves it to the next free amount (a range moves to the next block of the same size, so 100-999 becomes 1000-1899). Check the amount, then save.
  • Delete: click Delete Alert. The Confirm Delete Alert dialog shows the type, name and ID. This action cannot be undone.
  • There is no list to reorder. The amount decides which alert plays.
