This page walks through every control on an alert: the alert list, the header with the trigger and the Test, Duplicate, Delete and Save buttons, and the settings sections. For a first walkthrough, see Setting Up Your First Alert.

Create an alert

Pick the alert type

Open the Alerts tab and click a sub-tab: Bits, Subscriptions, Streaks, Gift Subs, Donations, Raids, Follows or Channel Points.

Click New alert

In the alert list on the left, click New alert. The detail fills with defaults: Duration 3 seconds, Volume 100%, everything else empty or off. To start from an existing alert instead, click it in the list and click Duplicate (content_copy); the copy gets the next free amount.

Set the amount

Next to Triggers on, leave the switch on Exact and type one amount, or switch to Range and type the lowest and highest amount. The amount is what identifies the alert, so each amount or range can only have one alert. See Amounts and ranges.

Add a GIF and a sound

In Visual, click Browse on the file card to pick an image. In Sound, click Browse on its file card to pick the sound. Both must be inside Mycelian's assets folder; see Alert Media Configuration.

Test, then save

Click Test Alert to play the alert as it is. When it looks right, click Save. A pop-up confirms, for example Saved “100-999 Bits”, and the alert shows up in the list.

The alert form

Every alert type uses this layout. All sections are always open. Settings that do nothing with the current switches are dimmed.

  1. The alert list. Click an alert to edit it. RANGE marks a range alert; the small icons show what the alert uses.
  2. The trigger: the Exact / Range switch and the amount, or the lowest to highest amount, with its unit.
  3. Unsaved changes appears after you edit. Then Test Alert, Duplicate (content_copy), Delete (delete, only for an alert that is already saved) and Save.
  4. Playback: how long it shows and whether it may stack.
  5. Visual: the GIF or image, as a file card.
  6. Sound: the main sound file, its volume and fades.
  7. Text-to-speech: read the alert out loud with the browser's speech voice.
  8. Randomizer: play a random sound from a folder some of the time.

File cards

Every file or folder setting is a card. It shows the file name and its folder, or No sound, No GIF or image or No folder when nothing is set. For an image, the card shows a small preview while the overlay server is running.

  • Browse opens the file picker and fills the card for you.
  • The pencil (edit) opens fields to type the path by hand: Folder and File for the GIF and the sound, Directory for a random folder. Click it again to close them.

Amounts and ranges

The trigger in the header is different on each sub-tab:

Sub-tabTriggers onDefault for a new alert
BitsAn amount in bits100
SubscriptionsMonths: 1 for a new sub, 2+ for resub months1 (range 1-3)
StreaksStreams in a row2 (range 2-5)
Gift SubsNumber of gifts1
DonationsAn amount in your alert currency (no unit shown)5
RaidsNumber of viewers10
FollowsNo amount. The header says Plays for every new follower.
Channel PointsNo amount. You pick a Twitch reward in the list.

Switch from Exact to Range to replace the amount with a lowest and highest amount (100 to 999). Both ends count: 100-999 matches 100 and 999. A tiered Bits setup could look like this:

1-99        Small cheer
100-999     Medium cheer
1000-100000 Big celebration

When an event arrives, an exact-amount alert beats a range. If no exact alert exists, the first range containing the amount plays. If nothing matches, Mycelian falls back to another alert of the same type.

Keep ranges from overlapping. If two ranges contain the same amount, either one may play. Test the boundary values (for example exactly 100 and 999) after you save.

Saving with an amount or range that already has an alert replaces that alert. Use a different amount, or click the existing alert in the list and edit it.

Resub Fallback

On Subscriptions, the list always shows Resub Fallback, tagged FALLBACK. The Resub fallback switch sits at the bottom of the list and applies to the whole tab. When the switch is on, the Resub Fallback alert plays for resubs that don't match any configured month alert. When it is off, unmatched resubs fall back to another sub alert.

Channel Points

The Channel Points sub-tab loads your rewards from Twitch into the list. Each entry shows the reward's cost, and Not an alert when the reward is not used as an alert. The refresh button (refresh) next to Search loads the rewards from Twitch again. The tab also differs here:

  • The header has a Use as alert switch instead of a trigger. A reward only plays an alert when this is on.
  • Playback adds Audio only, for sound-only redemptions.
  • A Twitch reward section edits the reward on Twitch itself.

Edit, duplicate and delete

  • Edit: click the alert in the list, change settings, click Save.
  • Duplicate (content_copy): copies this alert into a new unsaved alert and moves it to the next free amount (a range moves to the next block of the same size, so 100-999 becomes 1000-1899). Check the amount, then save.
  • Delete (delete): only shown for a saved alert. The Confirm Delete Alert dialog shows the type, name and ID. This action cannot be undone.
  • The list is sorted by amount and cannot be reordered. The amount decides which alert plays.
