Mycelian posts to Discord through your own Discord bot. You create the bot once in the Discord Developer Portal, paste its token into Mycelian, then invite the bot to your server.

{{icon:schedule}} About 5 minutes {{icon:person}} Discord account with Manage Server on your server {{icon:place}} SettingsDiscord

The bot only sends messages. For what you can do with it once it is connected, see Discord Integration.

Before you start

  • You can sign in to discord.com/developers with your Discord account.
  • You have Manage Server on the server the bot should post in. Discord requires it to add a bot.
  • You know which channel should get go-live announcements, if you want them.

Connect your bot

Create an application

Open the Discord Developer Portal and click New Application. Give it a name (for example Mycelian), accept the terms, and click Create.

Copy the bot token

In the left menu, open Bot. Under Token, click Reset Token, confirm, then click Copy.

  1. Discord shows the token only right after a reset. If you lose it, click Reset Token again and paste the new one into Mycelian. The old token stops working.
  2. Mycelian only sends messages, so it does not need any privileged intent.

The bot token works like a password for the bot. Do not share it or post it in chat. Mycelian never needs your own Discord password.

Paste the token and click Connect

Open SettingsDiscord. On the Discord bot card, paste the token into Bot token (the section is open until a token is saved) and click Connect. Connect saves the token for you.

  1. Bot token is masked. Click the eye icon to check what you pasted. It is stored encrypted in the app database.
  2. Connect changes to Connecting… while the bot signs in. Once it is online, Reconnect and a {{icon:logout}} Disconnect icon take its place. A pop-up says "Discord bot connected".

If the field is empty you will see "Enter a Discord bot token first" and the Bot token section opens. A wrong token shows "Couldn't connect the Discord bot", and the card says "Discord rejected the token. Reset it in the Developer Portal, then connect." with an Auth failed pill.

Invite the bot to your server

After a successful connect, the Invite link box on the bot card fills in. Click its {{icon:open_in_new}} icon (Invite the bot to a server) to open it in your browser, or its {{icon:content_copy}} icon to copy it and paste it somewhere else. Pick your server, click Continue, then Authorize.

Repeat with the same link for each server the bot should post in. Only servers where you have Manage Server appear in the list.

Pick announcement channels and save

Back in Mycelian, use Go-live announcement in the right-hand column. Choose a Server and a Channel, click Add, and turn on Announce when you go live. Then click Save in the header.

  1. Click a placeholder chip to add it to the end of the message.
  2. Each added channel is a row: the channel, then its server. Click its × (Remove channel) to remove it. With none yet, the list says "No channels yet. Pick a server and channel below."
  3. The Server and Channel pickers only appear while the bot is connected; until then the tab says "Connect the bot to pick servers and channels." If you just invited the bot, click the {{icon:refresh}} icon (Reload servers and channels).
  4. Channels, the switch and the message are not kept until you click Save.

Skip this step if you only want Discord replies from the Chatbot or Connectors. Those pick their own channels.

Check it worked

The bot card should be green and show the bot's name, and the header pill reads Bot connected:

The bot also shows as online in your server's member list. Mycelian reconnects it on its own when the app starts.

Connection status

The bottom status bar uses these colors for Discord. The full legend is in Status Footer.

StatusMeaning
ConnectedThe bot is online
ConnectingThe bot is signing in
ReconnectingThe connection to Discord dropped and the bot is trying again
DisconnectedThe bot is not connected. Click Connect
Auth FailedDiscord rejected the bot token. Reset it and paste the new one
ErrorThe bot could not start. Check the log

If something goes wrong

The tab says Auth failed

The token is wrong, has a stray space, or was reset in the Developer Portal. Open Bot, click Reset Token, copy it, paste it into Bot token and click Connect.

"Connect the bot first", or the invite link box is empty

The invite link is built from the bot's application ID, which Mycelian only learns after the bot signs in. Until then the box says "Connect to generate an invite link". Click Connect first and wait for the green status.

The Server list is empty

The bot is not in any server yet, or it is not connected (the pickers are hidden until it is). Invite it (step 4), then click the {{icon:refresh}} icon next to Add (Reload servers and channels). Opening the Discord tab also reloads the list.

My server is missing from Discord's "Add to server" list

You need Manage Server on that server. Ask the owner to invite the bot with the link from the Invite link box (its copy icon copies it).

The bot is connected but messages do not appear

Check the channel's permissions in Discord. The bot's role needs View Channel and Send Messages there. Private channels and channels that override role permissions often block it.

No "Stream is live" message was sent

Make sure Announce when you go live is on, at least one channel is listed under Channels, and you clicked Save. Mycelian sends one message per stream session: if Twitch and YouTube both go live, only the first one posts. The session resets once both are offline.
