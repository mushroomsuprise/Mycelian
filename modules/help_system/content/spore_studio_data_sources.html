Data sources are named live values: bits in the last cheer, the chat message, session totals, another counter, a Source Settings field. You pick them from one list in three places.

WhereWhat it does with the value
A block's Data feed → Run when: A live value (a data source)Shows it, or passes it to the block's target. See Data feeds.
A counter delta with Delta kind data_sourceAdds, subtracts or sets by that amount. See Counters.
A block's or the canvas's TransformationsMaps the value to size, position, rotation or skew

Showing a value with a Data display

A Data display block (in the Data group) shows a value and never changes anything else.

Add the block and set its text

Drag in a Data display. In its Data display section set Format (use {value}), for example Cheered: {value} bits, and Default text, shown before the first value arrives (default —).

Add a feed

Under Data feed, click + Add feed. Its target is Show this value. Choose how the value arrives:

  • From the event itself: keep Run when on an event and pick the Main text field or Number field.
  • From a stored value: set Run when to A live value (a data source), pick the source, and choose Re-read on events or Re-read every (ms).

Save and test

Click Save, then use the mocks in Preview.
