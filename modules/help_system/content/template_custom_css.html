When the fields in Source Settings are not enough, add your own CSS in the OBS browser source. It is applied on top of the template, so you can restyle, hide or animate any part of an overlay.

{{icon:place}} OBS → source Properties → Custom CSS {{icon:info}} Per browser source

Mycelian's Source Settings has no Custom CSS field. CSS goes in the Custom CSS box of each OBS browser source. Try a field in Source Settings first; colors, fonts, sizes and animations are usually already there.

What CSS can do

/* Frame the whole alert */
.alert-display {
    background: rgba(20, 20, 30, 0.85);
    border: 3px solid gold;
    border-radius: 14px;
}

/* Bigger, uppercase name. !important beats the color/size the template sets. */
.alert-username {
    color: gold !important;
    font-size: 48px !important;
    text-transform: uppercase;
    letter-spacing: 0.04em;
}

/* Bounce the image */
@keyframes bounce {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-20px); }
}
.alert-gif {
    animation: bounce 1s ease-in-out infinite;
}

/* Hide the viewer's message */
.alert-message {
    display: none !important;
}

Add CSS to a browser source

Open the source properties

In OBS, double-click the browser source that shows the overlay (or right-click it and choose Properties).

Add your rules to Custom CSS

Scroll to Custom CSS. Keep the rule OBS puts there by default if it is present; it makes the page background transparent. Add your rules below it.

body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }

.alert-username { color: gold !important; }

Click OK and test

OBS reloads the page with your CSS. Trigger a test alert or event to check it (see Testing Alerts).

The CSS belongs to that one OBS source. Another source showing the same template, and the Source Settings preview, do not get it. Sources created with Mycelian's Add to OBS button start with an empty Custom CSS box.

More examples

Fonts

.alert-username,
.alert-text {
    font-family: 'Comic Sans MS', cursive !important;
    font-weight: bold;
}

The font must be installed on the computer running OBS. Fonts in assets/default_assets/fonts/ are easier: pick them with a template's Font fields.

Colors and gradients

.alert-display {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    border: 3px solid gold;
}

.alert-username {
    color: #ff6b6b !important;
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}

Hide an element

.message-badges {
    display: none !important;
}

Responsive text size

.alert-text {
    font-size: clamp(16px, 4vw, 32px) !important;
}

Frosted background

.alert-display {
    background: rgba(0, 0, 0, 0.7);
    backdrop-filter: blur(10px);
}

Troubleshooting

My CSS does nothing
  • Check the selector spelling against the tables above or the template's HTML.
  • Many templates set colors, fonts and sizes from Source Settings directly on the element. Add !important to override those.
  • Make sure you clicked OK in the source properties. If needed, click Refresh cache of current page.
The overlay has a white or black background now

You removed OBS's default body { background-color: rgba(0, 0, 0, 0); … } rule. Add it back at the top of Custom CSS.

Moving the overlay with CSS cuts it off

CSS can only draw inside the browser source's Width × Height. Position the source in OBS instead, or make the source bigger.

My style broke after a Source Settings change

A value you saved in Source Settings may now conflict with your CSS. Rules with !important always win; otherwise the template's own value may apply.
