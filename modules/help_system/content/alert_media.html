Each alert can show one image and play one sound. The Randomizer can swap that sound for a random file from a folder. All media must live inside Mycelian's assets folder so the browser source can load it.

Used forFormats the picker offersNotes
Visual (GIF or image card)GIF, PNG, JPG, JPEG, WebPAnimated GIF and animated WebP both animate. Size on screen comes from the alerts template (GIF Width and GIF Height, 190 × 190 by default), so 300-500 px source files are plenty.

Where to put files

The assets folder sits next to the Mycelian program (in a source checkout, in the project folder). Keep alert media under assets/alerts/, one folder per type:

assets/
└── alerts/
    └── bits/
        ├── small_cheer.gif
        ├── medium_cheer.gif
        ├── cheer.mp3
        ├── random/
        │   ├── cheer1.mp3
        │   ├── cheer2.mp3
        │   └── cheer3.mp3
        └── rare/
            └── epic_cheer.mp3

Random and Extra Random folders must be inside assets/alerts/. The overlay asks for those folders by their path under assets/alerts/; a folder anywhere else is not found and no random sound plays.

Each file card shows the file name and its folder. The card stores web paths, not disk paths: a file at assets/alerts/bits/cheer.mp3 is saved as Folder /assets/alerts/bits/ and File cheer.mp3. Browse fills these in for you. To type them by hand, click the pencil (edit) on the card.

Pick a file with Browse

Every Browse button opens the same picker. For a GIF or primary sound you pick a file; for the randomizer you pick a folder. The same picker opens from the {{icon:folder_open}} button of image, font, sound and video settings in Source Settings and for the database files in Settings → Database.

  1. Places jump to common folders: the assets folder, the bundled media under assets/default_assets, assets/alerts, and a folder named after the sub-tab you are on. Only folders that exist are listed. Click a folder name in the path above the files to go back up.
  2. Files this field can use get a green type badge, a thumbnail (images) or a play button (sounds). Other files are dimmed; untick Only usable files to show them. Click a file to preview it on the right, double-click to use it right away.
  3. Fills in shows exactly what goes into the card. Use this file fills it in. For the randomizer the button is Use this folder, and only folders inside assets/alerts can be chosen.
  4. Add files… copies files from anywhere on your computer into the folder you are viewing, then selects the newest one. A file with the same name is never overwritten; the copy gets a number, like cheer (2).mp3.

The grid and list buttons next to Filter switch between thumbnails and a compact list. The picker only shows what is inside assets, because overlays can't load files from anywhere else.

Volume and fades

These are in the Sound section. Volume (0-100%) applies to whichever sound plays, primary or random. Fade in and Fade out are in milliseconds; 0 means no fade.

On the Channel Points tab, Audio only in Playback plays the sound with no image or text, which suits sound-effect rewards.

Random sounds

Use the Randomizer section. Nothing random happens until Random sounds is on. Then, each time the alert plays:

  1. If Extra random sound is on, roll 1-100. At or under its Chance, play a random file from the extra folder and stop.
  2. Otherwise roll again for Random sounds. At or under its Chance, play a random file from that folder.
  3. Otherwise play the primary sound (the file card in Sound).
  4. If no primary sound is set, always play a random file from the random folder.

Pick a scenario to see the odds:

Sound                    /assets/alerts/bits/  cheer.mp3
Random sounds            on   /assets/alerts/bits/random/  Chance 30
Extra random sound       on   /assets/alerts/bits/rare/    Chance 5

Sound                    /assets/alerts/bits/  cheer.mp3
Random sounds            on   /assets/alerts/bits/random/  Chance 30
Extra random sound       off

Sound                    No sound
Random sounds            on   /assets/alerts/bits/random/  Chance 0

Sound                    /assets/alerts/bits/  cheer.mp3
Random sounds            off

The Extra random sound help in the app says the extra sound plays after the main sound. In practice it plays instead of it: one sound per alert.

Text-to-speech

The Text-to-speech section reads the alert aloud through the browser source. It starts together with the sound. While speech is on, the sound plays at a quarter of its Volume so the voice is clear, and the next alert waits for both to finish. MUTE ALERTS silences speech too. Voice speed, pitch and loudness are set on the alerts template in Source Settingsalerts.
