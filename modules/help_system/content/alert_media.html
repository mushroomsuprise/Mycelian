Each alert can show one image and play one sound. The Randomizer can swap that sound for a random file from a folder. All media must live inside Mycelian's assets folder so the browser source can load it.

Where to put files

The assets folder sits next to the Mycelian program (in a source checkout, in the project folder). Keep alert media under assets/alerts/, one folder per type:

assets/
└── alerts/
    └── bits/
        ├── small_cheer.gif
        ├── medium_cheer.gif
        ├── cheer.mp3
        ├── random/
        │   ├── cheer1.mp3
        │   ├── cheer2.mp3
        │   └── cheer3.mp3
        └── rare/
            └── epic_cheer.mp3

Random and Extra Random folders must be inside assets/alerts/. The overlay asks for those folders by their path under assets/alerts/; a folder anywhere else is not found and no random sound plays.

The fields store web paths, not disk paths: a file at assets/alerts/bits/cheer.mp3 is saved as Directory /assets/alerts/bits/ and File cheer.mp3. Browse fills these in for you.

Pick a file with Browse

Every Browse button opens the same picker. For a GIF or primary sound you pick a file; for the randomizer you pick a folder.

  1. Shortcuts. Default Assets, Images and Sounds open the bundled media under assets/default_assets. The last button is named after the sub-tab you are on and opens assets/bits (or assets/raids, …), not assets/alerts/….
  2. Files of the right type are highlighted. Folders show a folder icon; click one to open it.
  3. Select File fills Directory and File. In folder mode the buttons are Select This Directory and Select Directory.

If you pick something outside assets, Mycelian warns: "This file is outside the assets folder. Move it under assets for correct browser-source paths." Move or copy the file into assets/alerts/… and browse again.

Volume and fades

Open Audio. Volume (0-100%) applies to whichever sound plays, primary or random. Fade In and Fade Out are in milliseconds; 0 means no fade.

On the Channel Points tab, Audio Only plays the sound with no image or text, which suits sound-effect rewards.

Random sounds

Open Randomizer. Nothing random happens until Enable Random Sounds is on. Then, each time the alert plays:

  1. If Enable Extra Random Sounds is on, roll 1-100. At or under its Chance (%), play a random file from the extra folder and stop.
  2. Otherwise roll again for Random Sound. At or under its Chance (%), play a random file from that folder.
  3. Otherwise play the Primary Sound.
  4. If no primary sound is set, always play a random file from the Random Sound folder.

Pick a scenario to see the odds:

Primary Sound            /assets/alerts/bits/  cheer.mp3
Enable Random Sounds     on   Directory /assets/alerts/bits/random/  Chance 30
Enable Extra Random      on   Directory /assets/alerts/bits/rare/    Chance 5

Primary Sound            /assets/alerts/bits/  cheer.mp3
Enable Random Sounds     on   Directory /assets/alerts/bits/random/  Chance 30
Enable Extra Random      off

Primary Sound            (empty)
Enable Random Sounds     on   Directory /assets/alerts/bits/random/  Chance 0

Primary Sound            /assets/alerts/bits/  cheer.mp3
Enable Random Sounds     off

The Extra Random tooltip in the app says the extra sound plays after the main sound. In practice it plays instead of it: one sound per alert.

Text-to-speech

The TTS section reads the alert aloud through the browser source. It starts together with the sound. While speech is on, the sound plays at a quarter of its Volume so the voice is clear, and the next alert waits for both to finish. MUTE ALERTS silences speech too. Voice speed, pitch and loudness are set on the alerts template in Source Settingsalerts.
