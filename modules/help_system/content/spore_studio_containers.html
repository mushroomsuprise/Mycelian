A container is one browser-source URL that shows several templates at once. Each template stays its own page and is loaded in a frame inside the container. Mycelian does not merge the HTML files.

{{icon:place}} Spore StudioContainers {{icon:save}} Saved to templates/_containers/{route}.json

Use a container when you want one OBS browser source for a whole layout, such as a game scene with a chat box, a goal bar and a now-playing card. Every template inside it still keeps its own URL.

The Containers screen

Click Containers at the left of the Spore Studio toolbar. The columns change to a template library, a container canvas, and container settings.

  1. Toolbar. Pick a container, create one, duplicate it, delete it, undo and redo. Placeholders shows template names instead of live previews, which keeps the editor light when many templates are placed. Preview opens the saved route. Save writes the container.
  2. Templates. Every template you can place, grouped as Spore Studio, Built-in (activity_feed and source_controls, which Spore Studio cannot edit but can place) and Other templates. Type in Search templates to filter.
  3. Canvas. Each rectangle is a slot showing one template. Drag to move, and drag the right or bottom edge to resize. A slot whose template no longer exists is marked (missing).
  4. Inspector. Settings for the selected slot. Click empty canvas to see the container's own settings instead.

Create a container

Start a new container

In Containers mode, click + New. Enter a Name. The Route path fills in from the name; change it if you want a different URL, such as game_layout. Pick a Resolution: 1920 × 1080, 1280 × 720, 1080 × 1920 or 720 × 1280. This is the size of the OBS browser source. Click Create.

Place templates

Drag templates from the Templates list onto the canvas. Spore Studio templates, built-in templates and hand-written HTML templates can all be placed. A container cannot be placed inside another container.

Arrange and link slots

Move and resize the slots. Set a size link on slots that should share one side of the canvas (see below).

Save and add it to OBS

Click Save. The route is listed on SettingsAbout with a Container badge and a count of the templates inside. Add it to OBS as a browser source at the container's resolution: http://127.0.0.1:{port}/game_layout

Slot settings

Slots are independent rectangles. A slot on the right can grow down through the same band as a slot on the left without moving it.

SettingWhat it does

X, Y, W, HPosition and size in pixels. Each shows its percent of the canvas.
Z-orderStacking order, 0–999. Bring forward and Send backward change it by one.
Opacity %0–100

SettingWhat it does
FitNative (template fills the slot), or Scale from design size, which shrinks or grows a fixed design to fit the slot
Design width / Design heightShown for Scale. The size the template was designed at.

Mute and Volume never change the template's own URL. Opened on its own, it still plays at full volume.

Set Size link to Share leftover height or Share leftover width on every slot that should split that side of the canvas. Slots with the same Link group share the space. Choose New link to start another group.

Size priorityBehavior
Locked (priority, keeps this size)Keeps the size you set, as a maximum. If the template only uses part of the box, the rest goes to the flexible slots. A 500 px slot whose content uses 350 px gives 150 px to the others.
Flexible (fills leftover space)Shares whatever is left, and can grow past the size you first gave it

Min px, Min %, Max px and Max % limit a linked slot. The larger minimum wins and the tighter maximum wins. Move up in stack and Move down in stack change the slot's order inside the link.

Templates built to fill their whole frame always keep the full size you set.

Warnings

When link settings cannot all be met, a warning appears above the canvas:

WarningWhat to do
Minimum sizes are larger than the canvas, so this link overflows.Lower the minimums or the space between templates
A locked template's minimum is larger than its designated size. The designated size is kept.Make the slot larger or lower its minimum

If you delete a template that a container still uses, its slot stays and the editor marks it (missing). Pick another template for the slot or remove it.

Can I name a template the same as a container route?

No. New template names that match an existing container route are refused, so the two URLs cannot collide.
