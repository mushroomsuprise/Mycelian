Start at the status footer at the bottom of the window. It shows every service Mycelian is watching and its state. Find the item that is not green, then use the matching tab below.

Read the footer

  1. Amber means signed in but not healthy. Red means it needs you. Hover the item for the full status text.
  2. Grey is normal for a service you have not set up or turned off.

If Internet is red, fix the network first. Every remote service then shows No Internet or Unreachable, and they recover on their own once the network is back.

Pop-ups only report a service once it settles into a problem (for example Twitch disconnected) and again when it reconnects. A dropped internet connection gives one You're offline notice instead of one per service. Short reconnects show only in the footer. See Notifications.

Fix by service

Twitch needs your own Twitch application. If you have not done that, follow Twitch Setup first.

Status is Idle or Not Configured

Cause: No credentials, or you have not signed in yet.

Fix: Open SettingsTwitch. On the Main account card, open Client ID & secret (its tag says Needed to connect), paste the Client ID and Client Secret, and click Connect. The {{icon:refresh}} icon only re-reads the status; it does not sign you in.

"Enter your Twitch Client ID and Client Secret first"

Cause: One of the two fields under Client ID & secret is empty.

Fix: Fill both and click Connect again.

The browser opens but never returns to Mycelian

Cause: The redirect URL in the Twitch console is not exactly http://localhost:17563, or another program or firewall is using port 17563.

Fix: Correct the URL in the Twitch developer console (http, localhost, no trailing slash). Close other streaming tools that use Twitch sign-in and try again.

Status is Expired or Auth Failed, or the card says "Token expired"

Cause: The token could not be refreshed: the Client Secret was regenerated, or access was removed on Twitch.

Fix: Paste the new secret under Client ID & secret if it changed, then click Reconnect and approve again. Check the application still exists in the developer console.

Status is Degraded and events stopped

Cause: Signed in, but Twitch's event session dropped.

Fix: Wait a minute; Mycelian reconnects on its own. If it stays amber, click Reconnect on the Main account card. Check status.twitch.tv for a Twitch outage.

Connected, but no alerts

Cause: Process Twitch alerts is off, or the problem is on the overlay side.

Fix: Turn on Process Twitch alerts under Alerts on SettingsTwitch and click Save. If events appear in the Activity Feed but nothing plays, see Troubleshooting Alerts.

Mycelian controls OBS through the OBS WebSocket server built into OBS 28 and newer. Full steps: OBS WebSocket.

Stays Disconnected (the tab says OBS not running, Can't connect or Turned off)

Cause: OBS is closed (OBS not running), its WebSocket server is off (Can't connect), or Enable OBS integration is off (Turned off).

Fix: Start OBS. In OBS, open ToolsWebSocket Server Settings and tick Enable WebSocket server. In Mycelian, turn on Enable OBS integration, then Save and Test.

The tab says Wrong password

Cause: The WebSocket password does not match OBS. Mycelian also shows "OBS rejected the WebSocket password".

Fix: In OBS's WebSocket Server Settings, click Show Connect Info, copy the password, paste it into Mycelian and save.

Wrong host or port

Cause: OBS uses a port other than 4455, or runs on another computer.

Fix: Copy the port from Show Connect Info. For OBS on another PC, enter that PC's IP address as Host and allow the port in its firewall.

Browser sources do not need the OBS connection. Alerts, overlays and Source Controls (tab and dock) work while OBS shows Disconnected; they go through the overlay server. Only OBS actions in connectors need it.

The overlay server is the local web server on port 5000 that every browser source loads from.

"The overlay server could not bind to port 5000"

Cause: Another program is using port 5000. Mycelian keeps running and retries.

Fix: Close the other program. On macOS, turn off AirPlay Receiver in System SettingsGeneralAirDrop & Handoff; it uses port 5000.

Stalled, Overloaded, Crashed or Frozen

Cause: The server stopped answering or cannot keep up.

Fix: Give it a minute; Mycelian restarts it when it can. If it stays red, restart Mycelian. For repeated Overloaded, see Performance Issues.

A browser source shows old data or stops updating

Cause: The source lost its live connection to the server, for example after the server restarted.

Fix: In OBS, open the source's properties and click Refresh cache of current page. Check the URL against Browser source URLs in SettingsAbout.

Cash tips come from Streamlabs or StreamElements; YouTube Super Chats use the same donation alerts. Alert amounts use the Alert currency set on the service's settings tab.

Streamlabs: "Another app is using the port Streamlabs sign-in needs (9975)"

Cause: Another program holds the port Streamlabs sign-in returns to.

Fix: Close it and click Connect again. The redirect URI in your Streamlabs app must be http://127.0.0.1:9975. Steps: Streamlabs guide.

StreamElements disconnects or never connects

Cause: The JWT token is wrong, for another channel, or was regenerated.

Fix: Copy a fresh JWT token from StreamElements (Account → Channels, Show secrets) and click Connect. Steps: StreamElements guide.

Tips arrive but the wrong tier plays

See Donations pick an unexpected tier in Troubleshooting Alerts.

If Mycelian says "Can't connect to the … database", your settings and alerts can't be saved until it is back. See Database and Database Explorer.

A firewall or antivirus blocks Mycelian

Cause: Security software blocks the local ports or the outgoing connections.

Fix: Allow Mycelian in your firewall. It needs these local ports:

Services show Unreachable while Internet is green

Cause: The service is down, or DNS cannot find it.

Fix: Check the service's status page, such as status.twitch.tv. Try another DNS server or restart your router. To test from a terminal: ping twitch.tv (Windows: tracert twitch.tv, macOS: traceroute twitch.tv).

A VPN or proxy is on

Cause: Some VPNs block localhost sign-in returns or Twitch's event connection.

Fix: Turn the VPN off, sign in, then try with it on again. If events stop with it on, leave it off while streaming.

Still stuck: check the log

Open SettingsAbout. Health check lists recent actionable errors and has the folder button (Open the logs folder), which opens the folder holding mycelian.log. Search the file for the service name (for example twitch or obs) near the time it failed. Problems Mycelian noticed are also listed in the notification centre (the bell at the top right of the main tabs); hover an entry and click Copy to copy its details for a bug report. See Notifications.
