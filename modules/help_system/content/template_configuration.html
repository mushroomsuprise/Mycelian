Every template's settings live in the Source Settings tab. Pick a template, change its settings, watch the preview, then click Save. Open overlays pick up saved changes without you touching OBS.

The Source Settings tab

  1. The template you are editing. Click it and type to filter the list; it is sorted by name and leaves out hidden templates. Next to it: how many settings and sections the template has.
  2. N unsaved changes while you have edits, Saved when the form matches the file.
  3. {{icon:refresh}} Reload the template list rescans the folder after you add files. It keeps the open template and, if you have no unsaved edits, reads its file again. {{icon:content_copy}} Duplicate copies the HTML, configuration, Spore Studio file and asset folder under a new name. {{icon:drive_file_rename_outline}} Rename renames the HTML, configuration and Spore Studio file. {{icon:delete_outline}} Delete removes all of them after you confirm. Duplicate and Rename refuse while you have unsaved changes (Save this template before duplicating).
  4. {{icon:help_outline}} opens this page. Discard is greyed out until you change something; it asks Discard unsaved changes? and goes back to the last saved version. Save writes the JSON and shows Saved title.
  5. The outline. Search settings looks at setting names and descriptions; matches stay under their section headings, sections with no match disappear, and the counts show how many matched. Click a section to jump to it; the one you are looking at is highlighted. A dot means the section has unsaved changes. Changed only shows just the settings you changed. In a narrow window the outline is replaced by a Jump to section… list above the settings.
  6. Each section comes from a separator in the JSON, with its number of settings. Settings before the first separator go in General. The first three sections start open.
  7. A changed setting gets a Changed tag and a bar on its left. {{icon:undo}} (Back to the saved value) undoes just that setting.

Each setting is one row: its name and a short description on the left (hover a cut-off description to read all of it), the control on the right. Number boxes use the template's step (for example 0.1 for Line Height) and show a unit such as s or px when the name or description gives one in brackets, like API Refresh Interval (seconds).

Files, fonts and images

Settings that hold a file (images, fonts, sounds, videos) show a small thumbnail before the box: the picture itself for images, an icon for the rest. The {{icon:folder_open}} button (Browse the assets folder) opens the file picker and fills in the path in the form the template expects. You can still type a path by hand.

Colors

Color settings have a swatch and a text box. Click the swatch to open the color picker; the preview follows while you drag, Done keeps the color and Cancel or Esc puts the old one back. Or type a value (#hex, rgb(), rgba() or transparent) and press Enter. The checkerboard behind the swatch shows through transparent colors. A color that is already a CSS gradient gets the picker's Gradient tab.

The preview

  1. What the preview shows: Live (the saved settings), Live · shows unsaved changes, Waiting for the overlay server or No preview for this template.
  2. {{icon:refresh}} Reload preview. {{icon:open_in_new}} Pop out the preview into a floating Live preview window you can drag and resize; it has its own reload and sample-event buttons. {{icon:settings}} Preview settings: Enable preview sounds and Show sample events bar (preview only, never saved into the template). {{icon:visibility_off}} Hide the preview gives the settings the full width; a Show preview button appears in the header to bring it back. Mycelian remembers whether the preview was hidden.
  3. The overlay's size. When OBS is connected and has a browser source for this template, it is read from OBS (From OBS: …). Type a width and height to use your own; that size is remembered for this template (Saved size). Otherwise the template's own design size is used.
  4. Zoom: − and + step the zoom, the number is the current scale, Fit fits the whole overlay in the pane. {{icon:restart_alt}} clears your saved size and detects it again from OBS or the template.
  5. The stage. The checkerboard is the transparent part of the browser source; the dashed outline is the overlay's size.
  6. Sample events plays fake events in the preview only, so you can see an alert or update without going live. Templates without them show No sample events for this template. The alerts template has Queue alert, Play alert and Refresh.

Drag the line between the settings and the preview to give either side more room. Mycelian remembers where you left it.

Change and save settings

Pick the template

Open Source Settings and choose the template from the list at the top. The name matches the URL: /title is title.

Find the setting

Click a section in the outline, or type part of a name or description into Search settings. The grey description under each setting says what it does and which values it takes.

Change it and check the preview

The preview redraws with your unsaved values and its chip says Live · shows unsaved changes. Use Sample events to trigger an update. Changed settings are marked Changed; turn on Changed only to review them, and use {{icon:undo}} on a row to undo one.

Save

Click Save. The header pill changes to Saved. Mycelian tells open overlays the file changed and most reload their settings straight away. If an overlay in OBS still looks old, refresh that browser source.

Switching to another template with unsaved edits asks "You have unsaved changes to … Save them before switching?" with Stay, Discard and switch and Save and switch.

Setting types

Each entry in a config's elements list has a type. Source Settings draws a different control for each one. Pick a type to see it.

The JSON file

Source Settings reads and writes templates/template_configs/<name>.json. A trimmed example from title.json:

{
    "template_name": "title",
    "elements": [
        { "type": "separator", "label": "Text Size" },
        {
            "type": "number",
            "id": "FontSize",
            "label": "Max Font Size",
            "value": 60,
            "min": 8,
            "max": 400,
            "description": "Largest size the text is allowed to be, in pixels."
        },
        {
            "type": "select",
            "id": "TextWrap",
            "label": "Text Wrapping",
            "value": "wrap",
            "options": ["wrap", "nowrap"]
        },
        {
            "type": "color",
            "id": "FontColor",
            "label": "Font Color",
            "value": "#ffffff",
            "transparent": false
        }
    ],
    "dynamic_controls": { "elements": [ ... ] }
}
KeyMeaning
idThe setting's name. The template's HTML uses it as a variable, for example {{ FontSize }}.
label, descriptionText shown in Source Settings (and searched by Search settings).
valueThe saved value. This is the only key Save changes, plus transparent on color settings.
min, max, step, optionsLimits and choices for number, slider, select and color settings.
hidden (top level)true leaves the template out of Source Settings and Browser source URLs.
dynamic_controls (top level)Live controls shown in Source Controls. Not shown in Source Settings.
preview_mocks (top level)The Sample events buttons for a Spore Studio template.

Editing the file by hand

You can edit the JSON in a text editor, for example to add a setting to a template you wrote yourself. Keep the JSON valid, then click {{icon:refresh}} Reload the template list in Source Settings. If you have no unsaved edits for that template, it reads the file again. Refresh the browser source in OBS to load the new values.

Copy the file before large hand edits. Source Settings has no undo after Save, and there is no "restore defaults" button. If the file has a JSON syntax error, Mycelian cannot read it: the template shows no settings in Source Settings and the overlay loses its saved values until you fix the file.

Templates from Spore Studio

For new overlays, use Spore Studio. Settings you mark Expose in Source Settings (JSON) appear here automatically; see Designing Templates in Spore Studio. Live buttons for the stream are authored in Dynamic Controls.

Common questions

I saved, but OBS still shows the old look

The overlay may not listen for the save notice, or it was loaded before Mycelian started. Right-click the source in OBS, choose Properties, and click Refresh cache of current page.

A template is missing from the list

It is marked "hidden": true, or its JSON is not in templates/template_configs/. Click {{icon:refresh}} after copying files in.

I can't find a setting

Type part of its name or description into Search settings. Check that Changed only is off; with it on, only settings you changed are shown, and the form says No unsaved changes when there are none.

The preview says "Waiting for the overlay server"

The built-in web server is still starting or has stopped. Check the overlay server status in the status footer.

Where did the preview go?

It was hidden with {{icon:visibility_off}}. Click Show preview in the header. If the sample-event buttons are missing, open {{icon:settings}} Preview settings and turn on Show sample events bar.
