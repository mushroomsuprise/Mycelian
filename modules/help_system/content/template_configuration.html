Every template's settings live in the Source Settings tab. Pick a template, change its fields, watch the preview, then click Save. Open overlays pick up saved changes without you touching OBS.

The Source Settings tab

  1. Template list. Type to filter it. It is sorted by name and leaves out hidden templates. The refresh button rescans the folder after you add files.
  2. Duplicate copies the HTML, settings, Spore Studio file and asset folder under a new name. Rename renames the HTML, settings and Spore Studio file. Delete removes all of them after you confirm. Save your edits first; Duplicate and Rename refuse while there are unsaved changes.
  3. Filters the fields by label or description and shows Showing N of M properties.
  4. Reset throws away unsaved edits and reloads the saved file. Save writes the JSON and shows Configuration saved for title.
  5. Each group comes from a separator in the JSON. Fields before the first separator go in Other Settings.
  6. A field you changed but have not saved is highlighted.
  7. Preview size. When OBS is connected and has a browser source for this template, the size is read from it (From OBS: …). Type a size to override it; Reset clears your size and detects it again.
  8. Mock event buttons send fake events to the preview only, so you can see an alert or update without going live. Templates without mocks show No mock events for this template.

Change and save settings

Pick the template

Open Source Settings and choose the template from the list. The name matches the URL: /title is title.

Change fields

Open a group and edit. Use Search properties when a template has many fields. Each field's grey description says what it does and which values it takes.

Check the preview

The preview on the right redraws with your unsaved values and says Unsaved changes reflected in preview. Use the mock buttons to trigger sample events. Turn Show preview off for more room, or use Pop out preview for a floating Live preview window you can drag and resize.

Save

Click Save. The preview label changes to Preview matches saved file. Mycelian tells open overlays the file changed and most reload their settings straight away. If an overlay in OBS still looks old, refresh that browser source.

Switching to another template with unsaved edits asks "You have unsaved changes to … Save them before switching?" with Stay, Discard and switch and Save and switch.

Field types

Each entry in a config's elements list has a type. Source Settings draws a different control for each one. Pick a type to see it.

The JSON file

Source Settings reads and writes templates/template_configs/<name>.json. A trimmed example from title.json:

{
    "template_name": "title",
    "elements": [
        { "type": "separator", "label": "Text Size" },
        {
            "type": "number",
            "id": "FontSize",
            "label": "Max Font Size",
            "value": 60,
            "min": 8,
            "max": 400,
            "description": "Largest size the text is allowed to be, in pixels."
        },
        {
            "type": "select",
            "id": "TextWrap",
            "label": "Text Wrapping",
            "value": "wrap",
            "options": ["wrap", "nowrap"]
        },
        {
            "type": "color",
            "id": "FontColor",
            "label": "Font Color",
            "value": "#ffffff",
            "transparent": false
        }
    ],
    "dynamic_controls": { "elements": [ ... ] }
}
KeyMeaning
idThe setting's name. The template's HTML uses it as a variable, for example {{ FontSize }}.
label, descriptionText shown in Source Settings (and searched by Search properties).
valueThe saved value. This is the only key Save changes, plus transparent on color fields.
min, max, step, optionsLimits and choices for number, slider, select and color fields.
hidden (top level)true leaves the template out of Source Settings and Available Source URLs.
dynamic_controls (top level)Live controls shown in Source Controls. Not shown in Source Settings.

Editing the file by hand

You can edit the JSON in a text editor, for example to add a field to a template you wrote yourself. Keep the JSON valid, then click the refresh button in Source Settings and reselect the template. Refresh the browser source in OBS to load the new values.

Copy the file before large hand edits. Source Settings has no undo after Save, and there is no "restore defaults" button. If the file has a JSON syntax error, Mycelian cannot read it: the template shows no fields in Source Settings and the overlay loses its saved values until you fix the file.

Templates from Spore Studio

For new overlays, use Spore Studio. Fields you mark Expose in Source Settings (JSON) appear here automatically; see Designing Templates in Spore Studio. Live buttons for the stream are authored in Dynamic Controls.

Common questions

I saved, but OBS still shows the old look

The overlay may not listen for the save notice, or it was loaded before Mycelian started. Right-click the source in OBS, choose Properties, and click Refresh cache of current page.

A template is missing from the list

It is marked "hidden": true, or its JSON is not in templates/template_configs/. Click the refresh button after copying files in.

The preview says "Waiting for overlay server…"

The built-in web server is still starting or has stopped. Check the overlay server status in the status footer.

Where are the mock event and sound settings?

Click the settings gear in the preview bar. Preview settings has Enable preview sounds and Show mock event toolbar. These only affect the preview, not the saved template.
