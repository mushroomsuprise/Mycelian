The trigger is the event that starts a connector. Each connector has one. You pick it from Trigger Type in the editor's Trigger Configuration section.

The trigger also decides two things: which Field choices you get for conditions, and which {placeholders} hold real data in your actions.

Choosing a trigger

The list has 24 triggers in five groups:

  • Twitch: cheers, subs, follows, raids, channel points, chat, and going live or offline. Needs Twitch connected.
  • YouTube: live chat, memberships, Super Chats and Super Stickers. Needs YouTube connected.
  • Donation: tips from Streamlabs or StreamElements.
  • OBS: scene, stream, recording and mute changes. Needs OBS WebSocket.
  • Manual: a keyboard Hotkey Trigger or a Stream Deck button.

Any (all events) fires on every event the connector system receives.

On the connector card, some names are shorter: Twitch Sub, Twitch Resub, Gift Sub, Chat Message, Hotkey, OBS Scene, OBS Stream, OBS Record, OBS Input Mute.

Hotkey Trigger

  1. Type the combination, joined with +: ctrl+shift+f, f12, alt+tab. Modifiers are ctrl, alt, shift and cmd/meta.
  2. Record opens a small dialog. Press the keys and the field fills in. If another connector already uses the same combination, an orange Also used by: line names it. Both connectors fire.
  3. Global hotkey (on by default) works while another app, such as your game, has focus.

The modifiers must match exactly: ctrl+f does not fire for Ctrl+Shift+F.

Stream Deck

The editor shows: Assign this connector on a Stream Deck button using the Connector action in the Mycelian Stream Deck plugin. There is nothing else to set here. Save the connector, then pick it in the plugin's Connector action. See Connect Stream Deck.

Any (all events) fires for every event type above: bits, chat, subs, OBS changes, hotkeys, Stream Deck presses and more. The editor warns:

Warning: This trigger fires on every connector event type (bits, chat, subs, OBS, hotkeys, and more). Use specific conditions to avoid unwanted activations.

Its Field list combines the fields of every trigger, sorted by name. Events that do not have a field fail a condition on it, so a condition like Message ∋ hype limits it to events that carry a message.

Triggers the editor does not offer

These are not in the Trigger Type list. Here is what to do instead:

  • Chat commands: use Twitch Chat Message with the condition Message ^ !yourcommand (First word). See Conditions. For simple replies, Chatbot Commands may be easier.
  • Timers and schedules: not available from the editor.
  • Hype trains: not available as a trigger.
  • Combining triggers: one connector has one trigger. Make one connector per trigger, or use Any (all events) with conditions.
  • "10 follows in 5 minutes" style thresholds do not exist.

Placeholders from the trigger

Write a field name in single braces in any action text: Thanks {username} for {amount} bits!. Besides the trigger's own fields, these always work:

PlaceholderValue
{event_type}The event's internal name, e.g. twitch_bits
{source}Where it came from, e.g. twitch, youtube, obs, hotkey
{timestamp}, {triggered_at}Event time and fire time (Unix seconds)
{connector_id}, {trigger_id}, {trigger_type}Identifiers for this connector and its trigger
{message.word.1}, {message.word.2}…The Nth word of the message
{message_after_conditions}The message with the text matched by your Message conditions removed. See Conditions.

A placeholder with no value becomes empty text. The full list, including outputs from earlier actions, is on Connector Actions.
