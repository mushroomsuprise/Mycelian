This page covers what you draw and set up on the canvas before you wire bindings: placing blocks, categories, nesting, assets, the shared property sections, and the Canvas tab. For the editor layout and the files Save writes, see Spore Studio Overview.

Place a block

Drag a block from the Blocks panel onto the canvas. The palette is grouped as Data, Layout, Media, Text and Widgets; type in Search blocks to find one by name. Every block and its settings is listed in the Widget reference.

When you drop a block, the Which category is it in? dialog opens:

  • Existing categories shows the categories already used in this template as chips. The last one used is picked for you; click another to use it.
  • New category creates a new group. Typing a name here replaces the chip choice. In a template with no categories yet, only this box shows, filled with Elements.
  • Add element places the element. Cancel, {{icon:close}}, Esc or a click outside places nothing.

Categories group elements in the Outline and in the saved JSON config, which is what Source Settings shows.

Use one category per part of the overlay, such as alert_box and username_label, so Source Settings stays organized.

Work on the canvas

  1. Drag a block over a container and it highlights. Drop to nest the block inside it. Hold Alt while dropping to keep the block on the canvas root.
  2. The selected element has a resize handle at its bottom-right corner.
  3. Audio has no picture in the overlay. On the canvas it is a small labeled box.

Outline

The Outline lists every element under its category heading. Elements inside a container are indented under it, with a dotted guide line. Each row shows a type icon, the element id and the type. The count next to Outline is the number of elements. Click a row to select the element on the canvas and in the inspector. With nothing on the canvas it says No elements yet — drag a block onto the canvas, or open an existing template to populate this list.

Nesting

  • Only Container blocks accept children. A container clips its children, and child positions are relative to its top-left corner.
  • The header card at the top of Properties shows in <container> for a nested element, or on the canvas. Move to canvas in the Element section un-nests it.
  • A nested element gets a Placement in container section: a 3 × 3 grid of anchors (↖ ↑ ↗ ← ◎ → ↙ ↓ ↘) and Offset X/Y for fine tuning. Picking an anchor resets the offset. Dragging changes the offset and keeps the anchor.

Properties sections

Select an element to fill the Properties tab. A header card at the top shows the element's ID, where it sits (in box for a nested element, on the canvas otherwise) and its block type. Below it, each section is a card with an icon. A closed card shows a one-line summary on the right, such as 20, 200 · 400×60 for Layout or Starts hidden for Visibility. Click the section headers in this picture to open and close them.

Start hidden until shown

When checked, the element starts hidden and appears when a Show action runs. If you leave it untouched and the element has a Show binding, it is hidden automatically (the tooltip says Auto: hidden while a Show binding exists). Uncheck it to keep the element visible on load. It works for every block, including centred and bottom-aligned text. If a block is shown again while its exit animation is still playing, it stays visible. On a Poll it means hidden until a poll runs.

Transformations

Transformations map a live value onto a block. The same section on the Canvas tab maps a value onto the whole template. Both can be on at once: the canvas transform applies first, and the block adds its own on top.

Input min / Input maxThe source range
Output min / Output maxThe result. Size is a multiplier where 1 is unchanged. Move is pixels. Rotate and skew are degrees. Values between are interpolated.

Colors

A color row has a swatch and a text box. Click the swatch to open the color picker, titled with the property's name; the canvas follows while you pick, Done or a click outside keeps the color, and Cancel or Esc puts the old one back. The opacity bar and chips make a color see-through, down to {{icon:block}} Fully transparent. Fills (Background, Fill, Highlight background and a few block colors such as a progress bar's Fill color) also get a Gradient tab for linear and radial gradients. You can type any value into the text box too, including a CSS gradient on a fill.

Show in Source Settings

Most rows in Appearance and the block sections have a small {{icon:tune}} sliders chip at the right end of the label. Click it to turn it on or off: lit up in the accent color means on. Its tooltip reads Show in Source Settings. When off, the value is written into the HTML only. A one-line legend at the top of Appearance explains the chip. New elements start with it on. On the Style row each of B, I, U and S has its own chip.

Lit (on)Not lit (off)
Value stored in template_configs/{name}.jsonValue written into the generated HTML only

Light the chip on the colors, text and URLs you change often on stream. Leave it off for sizes you do not need to change live.

Text, Counter and Data display

Text is static copy. A Counter block holds a number with rules, and a Data display block shows a live value. Older templates that used a Text block in counter or data mode are converted to the new block types when you open them, and stay that way after you save.

  • Counter and Data display have a Value change animation section (tick_up, fade-in and others), separate from Entrance and Exit. See Counters and Data sources.
  • Image can use From counter (ranges) to swap art by a counter's value. See Counters.

Queue vs Instant

ValueCard in the New template dialogLabel in the Canvas tab dropdownUse it for
queueQueuedQueue (next_alert; emit alert_complete in Advanced JS if you use the alert queue)Full-screen alerts that take turns in the alert queue
instantInstantInstant (instant_alert)Sub bars, counters and HUD pieces that must not hold up the queue

A Queue template handles the alert queue for you. For each next_alert it runs your bindings, holds for Duration (or the alert's own duration) and while its media is still playing, then tells the queue it is done. It only does this when it is one of the alert's queue_holders, normally alerts plus a matching Queued point-reward template. You do not need to send alert_complete yourself, despite what the dropdown label and the Queued card in the New template dialog say. See Advanced JS.
