This page covers what you draw and set up on the canvas before you wire bindings: placing blocks, categories, nesting, assets, the shared property sections, and the Canvas tab. For the editor layout and the files Save writes, see Spore Studio Overview.

Place a block

Drag a block from the Blocks panel onto the canvas. The palette is grouped as Data, Layout, Media, Text and Widgets. Every block and its settings is listed in the Widget reference.

When you drop a block, the Element category dialog opens:

  • Existing category lists categories already used in this template. Its last entry, + New category…, moves you to the name field.
  • New category name creates a new group.
  • Use category places the element. Cancel places nothing.

Categories group elements in the Outline and in the saved JSON config, which is what Source Settings shows.

Use one category per part of the overlay, such as alert_box and username_label, so Source Settings stays organized.

Work on the canvas

  1. Drag a block over a container and it highlights. Drop to nest the block inside it. Hold Alt while dropping to keep the block on the canvas root.
  2. The selected element has a resize handle at its bottom-right corner.
  3. Audio has no picture in the overlay. On the canvas it is a small labeled box.

Outline

The Outline lists every element under its category heading, indented under its container. Each row shows the element id and type. Click a row to select the element on the canvas and in the inspector. With nothing on the canvas it says No elements yet — drag a block onto the canvas, or open an existing template to populate this list.

Nesting

  • Only Container blocks accept children. A container clips its children, and child positions are relative to its top-left corner.
  • The Parent row in Properties shows the container, or (canvas root). Move to canvas un-nests the element.
  • A nested element gets a Placement in container section: a 3 × 3 grid of anchors (↖ ↑ ↗ ← ◎ → ↙ ↓ ↘) and Offset X/Y for fine tuning. Picking an anchor resets the offset. Dragging changes the offset and keeps the anchor.

Start hidden until shown

When checked, the element starts hidden and appears when a Show action runs. If you leave it untouched and the element has a Show binding, it is hidden automatically (the tooltip says Auto: hidden while a Show binding exists). Uncheck it to keep the element visible on load. It works for every block, including centred and bottom-aligned text. If a block is shown again while its exit animation is still playing, it stays visible. On a Poll it means hidden until a poll runs.

Transformations

Transformations map a live value onto a block. The same section on the Canvas tab maps a value onto the whole template. Both can be on at once: the canvas transform applies first, and the block adds its own on top.

FieldWhat it does
PropertySize, Move X, Move Y, Rotate, Skew X or Skew Y
OriginThe pivot for size, rotate and skew: Center, Top left, Top center, Top right, Center left, Center right, Bottom left, Bottom center, Bottom right. When several rules are on, the last enabled rule's origin is used.
Input min / Input maxThe source range
Output min / Output maxThe result. Size is a multiplier where 1 is unchanged. Move is pixels. Rotate and skew are degrees. Values between are interpolated.
Run when and the rows under itThe input, picked the same way as a Data feed source: a live value (a counter, a session stat), an event's field, or another template's output. On a Counter block the rule starts with that counter's own value.

Expose in Source Settings

Most rows in Appearance and the block sections have a small checkbox before the label. Its tooltip reads Expose in Source Settings. When off, the value is written into the HTML only. New elements start with it on.

CheckedUnchecked
Value stored in template_configs/{name}.jsonValue written into the generated HTML only
Editable later in Source Settings and Source ControlsFixed until you change it in Spore Studio and save

Expose the colors, text and URLs you change often on stream. Leave sizes unexposed if you do not need to change them live.

Text, Counter and Data display

Text is static copy. A Counter block holds a number with rules, and a Data display block shows a live value. Older templates that used a Text block in counter or data mode are converted to the new block types when you open them, and stay that way after you save.

  • Counter and Data display have a Value change animation section (tick_up, fade-in and others), separate from Entrance and Exit. See Counters and Data sources.
  • Image can use From counter (ranges) to swap art by a counter's value. See Counters.

Queue vs Instant

ValueLabel in the dropdownUse it for
queueQueue (next_alert; emit alert_complete in Advanced JS if you use the alert queue)Full-screen alerts that take turns in the alert queue
instantInstant (instant_alert)Sub bars, counters and HUD pieces that must not hold up the queue

A Queue template handles the alert queue for you. For each next_alert it runs your bindings, holds for Duration (or the alert's own duration) and while its media is still playing, then tells the queue it is done. It only does this when it is one of the alert's queue_holders, normally alerts plus a matching Queued point-reward template. You do not need to send alert_complete yourself, despite what the dropdown label says. See Advanced JS.
