Steam gives every account a free Web API key. With that key and your Steam profile, Mycelian sees the game you are playing, its achievements and your profile picture, and sends them to your overlays.

After you connect, see Steam Integration for the achievements overlay.

Before you start

  • You can sign in to Steam in a web browser.
  • In your Steam privacy settings, My profile and Game details are Public. Steam hides the game you are playing and your achievements from everyone else otherwise, including Mycelian.

Get a Web API key

Open SettingsSteam and click Get an API key (or go to steamcommunity.com/dev/apikey). Sign in, enter any domain name such as localhost, agree to the terms and click Register. Copy the 32-character key.

Paste the key

Open Web API key on the account card and paste the key. Mycelian stores it encrypted. Treat it like a password: anyone with the key can use it as you.

Enter your profile

Under Tracking, enter your Steam profile in any of these forms:

  • your profile link, for example https://steamcommunity.com/id/yourname
  • your custom URL name, for example yourname
  • your 17-digit SteamID64, for example 76561198000000000

Click Connect

Mycelian saves the settings and connects. The account card shows your Steam name, profile picture and status, and Current game lists the achievements of the game you are playing.

Questions

It says I'm not in a game, but I am

Set Game details to Public in your Steam privacy settings, and make sure you aren't set to Invisible. Steam only reports the game of a visible profile. Non-Steam games added to your library are not reported.

Achievements are private

The game shows, but its achievements don't: set Game details to Public. Changes can take a few minutes to reach the Steam Web API.

How quickly do new achievements show?

Mycelian checks your profile every 15 seconds and the current game's achievements every 15 seconds, so a new achievement shows within about 15 seconds. Achievement names, icons and rarity are read once per game and kept, so each check is a single request. Settings → Steam shows how many requests Mycelian made in the last hour and today, with a live graph of requests per minute.
