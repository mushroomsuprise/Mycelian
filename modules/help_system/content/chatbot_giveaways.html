Run a chat giveaway from Chatbot → Giveaways. Viewers enter by typing a keyword you choose. You draw winners, and the chatbot posts the result as a Twitch chat announcement.

{{icon:schedule}} About 3 minutes {{icon:place}} ChatbotGiveaways {{brand:twitch}} Twitch chat

Announcements need the chatbot account to be a moderator with the moderator:manage:announcements permission. Setting up the chatbot account is covered in Twitch Setup.

The Giveaways tab

  1. Status line. A Last issue line appears under it in amber if the last draw had a problem.
  2. Each field saves when you click out of it.
  3. Type a username and press Enter to block it. Click the close on a chip to unblock.
  4. The controls for a round. Options opens the switches described below.

Run a giveaway

Set the keyword

Type what viewers must send in Entry keyword, for example !enter. The whole message must equal the keyword. Capitals do not matter and spaces at the ends are ignored, but "!enter please" does not count.

Start

Click Start giveaway. The status changes to Active giveaway: Yes (chat entries on). Without a keyword you get "Set an entry keyword before starting."

Let chat enter

Draw winners

Click Draw winners. Mycelian picks up to Winners per draw names and posts one announcement.

With Remove winners from pool on (the default), winners leave the pool, so you can click Draw winners again for a runner-up.

Finish

Click Stop accepting to close entries but keep the pool, or Clear giveaway to empty the pool, clear the keyword and stop.

Buttons

ButtonWhat it does
Start giveawayStarts accepting entries. Needs a keyword. Does not clear the pool.
Stop acceptingStops new entries. The keyword and pool stay.
Draw winnersPicks winners, posts the announcement and records statistics. Does not stop entries. Removes winners from the pool only if that option is on. With an empty pool you get "Pool is empty."
Clear giveawayEmpties the pool, clears the keyword and stops accepting.
OptionsOpens Giveaway options.
RefreshReloads the tab from saved settings.

Clearing the Entry keyword field also stops accepting entries.

Giveaway options

OptionDefaultWhat it does
No duplicate entriesOnOne ticket per Twitch account. Off lets a viewer enter many times, and each entry is another ticket.
Unique winners per drawOnWhen drawing more than one winner, a viewer can win only one slot per draw. Off can pick the same viewer twice if they hold several tickets.
Remove winners from poolOnTakes every ticket of each winner out of the pool after the draw.
Exclude moderatorsOffChatters with the moderator badge cannot enter.
Exclude VIPsOffChatters with the VIP badge cannot enter.
Display winners as a bannerOffAlso shows the winner message on the chat overlay banner. The Twitch announcement is still sent.

The announcement message

Winning announcement is sent as a Twitch announcement, the highlighted chat message, not a normal line. {winners} and {winner} both become the winners' names, separated by commas.

🎉 Winners: {winners}. Thanks for entering!

With a dedicated chatbot account the announcement comes from the bot. In fallback mode (no separate bot) it comes from your main account.

Statistics

Mycelian counts giveaways completed (each draw), total entries, average entries per giveaway and how often each name has won. The totals are on SettingsStatistics.

The built-in giveaway overlay template shows the keyword, entries and winners live if you add it to OBS. See Templates.

Troubleshooting

Nobody gets entered
  • The status must say Active giveaway: Yes. Click Start giveaway.
  • The message must be exactly the keyword, nothing more.
  • The viewer may be blocked, a moderator or VIP with that exclusion on, or already entered.
  • If the keyword is the name of one of your commands, the command answers and the message is not an entry. Pick a keyword that is not a command.
  • Only Twitch chat can enter.
Winners are drawn but no announcement shows

The toast says "Drew winner(s) but announcement failed." and the Last issue line explains. Check that the chatbot is connected and is a moderator on your channel. The draw still counts and the winners are still removed if that option is on.

The same person keeps winning

Turn on Remove winners from pool, or Clear giveaway between rounds.
