Run a chat poll from Chatbot → Polls. Each overlay that contains a Spore Studio Poll widget has its own poll. Viewers vote by typing an option's #keyword anywhere in their message. Settings save as you change them.

The Polls tab

  1. The status: Not running (with the last winner, if any), Ended · winner … right after a poll, or Poll open with the time left and a timer bar. While a poll is open, the right side shows the vote count and the leading option (or 2-way tie). If something went wrong, an amber line under the status says what happened.
  2. The overlay whose poll you are looking at. You can switch at any time, even while a poll is live. Overlays with a live poll show · live in the list.
  3. The options viewers vote for. While a poll is open this becomes Live results and the options are locked.
  4. How long the poll runs and how votes count.
  5. Let a chat command start this poll.
  6. What happens when the poll ends.
  7. A small preview in the widget's own colours, with its title, keyword chips and bar gradient, and the overlay address for OBS.

If no overlay has a Poll widget yet, the tab says No overlay has a Poll widget yet with Open Spore Studio and Check again.

Set up a poll

Have an overlay with a Poll widget

Add a Poll block in Spore Studio, or use the built-in poll template, and save.

Pick it and add options

Open Chatbot → Polls and choose the overlay in Overlay. Click Add option until you have at least two, and type a name in each. Each change saves when you press Enter or click away.

Set the timing

In Timing & voting, pick Timer and set how long (seconds, minutes or hours), or Until I stop it.

Start

Click Start poll. Starting sets every option's votes back to 0. You need at least two options, or you get "Add at least two options before starting."

Options

  • A new option is called Option 3 (the next number). Rename it in the Option box.
  • The keyword follows the name with spaces removed and a # in front (Pizza Time becomes #PizzaTime), and shows AUTO while it does. Type your own keyword and it stops following. It always keeps the #, and two options can't share one: "#pizza is already used by another option."
  • Votes can be corrected by hand between polls. Changing them after a poll ended picks the winner again and updates the overlay.
  • {{icon:arrow_upward}} {{icon:arrow_downward}} change the order and {{icon:close}} removes the option.
  • While a poll is open, options can't be changed: "End the poll before changing its options."

How a vote counts

Matching ignores capitals, and the keyword has to be its own word. I vote #yes counts. #yesterday does not. If one message has several keywords for the same poll, the earliest one wins.

Twitch and YouTube chat both count. If polls on more than one overlay are open, one message can vote in each of them when the keywords match.

Ending and restarts

End poll now, or the timer running out, closes the poll and picks the option with the most votes. Every option tied for that count wins. A poll with no votes ends without a winner and without a banner or chat message.

While the poll is open, Live results shows each option, its keyword, its votes and its share, with a bar in the widget's bar colour measured against the leader. It is sorted like the overlay, most votes first, and updates every second.

The last winner stays in the status line, including while the next poll is set up and after a restart. A later poll replaces it only when that poll has a winner.

Open polls are always saved. An open timed poll comes back after a restart when time is still left. A poll set to Until I stop it comes back until you end it. A poll whose end time passed while the app was closed is dropped and not announced later. Options, keywords, settings and the last winner are always saved.

Start from chat

In Start from chat, turn on Start it with a chat command and type a command. A Twitch moderator or broadcaster, or a YouTube chat moderator or owner, then starts this overlay's poll when their message begins with the command. The command always gets a leading ! and loses any spaces.

  • !startpoll and !startpoll now count. please !startpoll does not.
  • With the box empty, or Start it with a chat command off, the poll only starts from the app.
  • Give another overlay's poll the same command when you want one message to start both.
  • A poll that is already open is not restarted.

When it ends

Turn on Show the winner on the chat banner to post the result on the chat overlay. Post the winner in chat sends the same message in Twitch and YouTube chat. Both are off by default. The { } button in the message box inserts these variables, and the preview below it uses the last result or your first option:

VariableBecomes
{option}The winning option's name. With a tie, every winner, comma separated.
{options}Every winning option, comma separated.
{keyword}The winning keyword (or keywords).
{votes}The winning vote count.

The default message is Poll winner: {option} ({votes}). Leave the box empty and the default comes back. Banner stays up is in seconds (10 by default); 0 keeps the banner up until another banner replaces it.

Overlay

The Overlay card shows a small preview of the results in the Poll widget's own colours, with its title, keyword chips and bar gradient, and names the widget and its template. Click the address to copy it for an OBS Browser Source. Edit in Spore Studio opens the template, and Preview opens the overlay in your browser.

The Poll widget draws the live results: a style (bars, labels inside thick bars, or side-by-side cards), a title, keyword chips, rank numbers, a countdown chip and timer bar, a footer with the vote total, colors and a bar gradient, a leader highlight, a winner effect or winner-only list, autohide, and a rotator for extra options. Options are always ordered by votes, highest first. With the rotator off, only the top items are shown. With it on, the widget pages through that same order. The stock poll template is a Spore Studio template, so you can rearrange it like any other.
