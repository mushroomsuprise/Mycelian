Run a chat poll from Chatbot → Polls. Each poll belongs to one overlay template that contains a Spore Studio Poll widget. Viewers vote by typing a category's #keyword anywhere in their message.

The Polls tab

  1. Only templates with a Poll block are listed. If there are none, the tab says "No templates with a Poll widget yet".
  2. Voting rules and moderator start. Hover a switch in the app for its tooltip.
  3. What happens when the poll ends.

Setup

Have a template with a Poll widget

Add a Poll block in Spore Studio, or start from the built-in poll template, and save.

Pick it and add categories

Open Chatbot → Polls and choose it in Poll template. Click Add category at least twice. The keyword follows the name with spaces removed and a # in front (Pizza Time becomes #PizzaTime) until you edit the keyword yourself. It always keeps the #, and two categories cannot share one.

Set the duration

Enter Duration (seconds). 0 stays open until you press Stop.

Start

Press Start. Starting clears the vote counts. You need at least two categories, or you get "Add at least two categories before starting."

How a vote counts

Matching ignores capitals, and the keyword has to be its own word. I vote #yes counts. #yesterday does not. If one message has several keywords for the same poll, the earliest one wins.

1 entry per user is on by default, so the first vote sticks. Allow vote switching is off by default. Turn it on to let a later keyword move that person's vote. With 1 entry per user off, every matching message adds another vote.

Twitch and YouTube chat both count. If polls on more than one template are running, one message can vote in each of them when the keywords match.

Ending and restarts

Stop closes the poll and picks the option with the most votes. Every option tied for that count wins. A poll with no votes ends without a winner and without a banner or chat message.

The status beside Categories is green while the poll is open, amber after it ends, and muted when it is not running. While the poll is open, the box shows live results: each option, its keyword, its votes, its share, and a bar measured against the leader. Add category is disabled. The name, keyword and vote editors come back when the poll ends. You can type a vote count by hand then.

The last winning result stays centered in the header, including while the next poll runs and after a restart. A later poll replaces it only when that poll has a winner.

Open polls are always saved. An open timed poll comes back after a restart when time is still left. A permanent poll (duration 0) comes back until you press Stop. A poll whose end time passed while the app was closed is dropped and not announced later. Category names, keywords, banner settings and the last winner are always saved.

Moderator start

Turn on Mods can start and set a Start command that begins with !. That command belongs to the poll you are editing. A Twitch moderator or broadcaster, or a YouTube chat moderator or owner, starts the poll when their message begins with the command.

  • !startpoll and !startpoll now count. please !startpoll does not.
  • Leave the command blank and this poll ignores moderator start.
  • Give another poll the same command when you want one message to start both.

Winner banner

Turn on Send winner as a chat banner to post the result on the chat overlay. Send winner in chat posts the same message in Twitch and YouTube chat. The banner switch on this tab is the only switch for that overlay.

PlaceholderBecomes
{option}The winning option's name. With a tie, all tied names.
{options}All winning names, comma-separated.
{keyword}The winning keyword (or keywords).
{votes}The winning vote count.

The default message is Poll winner: {option} ({votes}). Banner duration 0 stays up until another banner replaces it.

Overlay

The Poll widget draws the live results: font, horizontal or vertical list, bars or text, timer text and timer bar, colors, winner highlight or winner-only, autohide, and a rotator for extra options. Options are always ordered by votes, highest first. With the rotator off, only the top items are shown. With it on, the widget pages through that same order.

The stock poll template is a Spore Studio template, so you can rearrange it like any other.
