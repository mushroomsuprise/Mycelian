Complete connectors you can rebuild in a few minutes. Each tab shows the finished card, the values to enter in the editor, and what happens on stream.

New to connectors? Read Connector System Introduction first. Values in the tables are typed or picked in the editor exactly as shown.

Examples

Trigger TypeTwitch Raid
Condition #1Viewer Count ≥ 10
Action #1Send Chat Message, Twitch only:
Welcome raiders from {username}! All {viewer_count} of you, make yourselves at home.
Action #2Delay 2 s. OBS Studio (WebSocket), OBS — Set program scene, Scene Raid Welcome
Action #3Delay 10 s. Same operation, Scene Main

What happens: a raid with 10 or more viewers posts the welcome, waits 2 seconds, shows your Raid Welcome scene for 10 seconds, then returns to Main. Smaller raids do nothing. Change the scene names to ones in your OBS.

Trigger TypeTwitch Chat Message
Condition #1Field Message, Operator ^ (First word), Value !so
Condition #2Is Moderator = True
Action #1Send Chat Message, Twitch only:
Go follow {message_after_word.1} at twitch.tv/{message_after_word.1}

What happens: a moderator (or you) types !so CoolStreamer. The First word condition matches !so and removes it, so {message_after_word.1} is CoolStreamer. The bot posts Go follow CoolStreamer at twitch.tv/CoolStreamer. Viewers who are not moderators get no reply.

Trigger TypeTwitch Chat Message
Condition #1Message ^ !lurk
Action #1Send Chat Message, Twitch only:
Enjoy the lurk, {username}! See you when you're back.

What happens: anyone who types !lurk (or !lurk brb dinner) gets a reply with their name. Matching is case-sensitive, so !Lurk does not match. To answer YouTube viewers too, make a copy with the YouTube Chat Message trigger and the YouTube box ticked. For plain text replies like this one, chatbot commands also work.

Trigger TypeTwitch Bits
Condition #1Amount ≥ 500
Action #1Display Banner: {username} cheered {amount} bits!, Duration 15
Action #2Send Announcement, Color Purple: Huge thanks to {username} for {amount} bits!

What happens: cheers of 500 bits or more show a banner on your chat overlay for 15 seconds and post a purple announcement in Twitch chat. Your normal bits alert still plays as usual. Announcements need the chatbot to have the announcements permission.

For tiers (100–499, 500+…), make one connector per range, for example Amount ≥ 100 and Amount < 500 on the first, Amount ≥ 500 on the second.

Trigger TypeTwitch Subscription
Condition #1Tier = 3000
Action #1Send Announcement, Color Orange: {username} just subscribed at Tier 3. Thank you!

What happens: a new Tier 3 subscription gets an orange announcement. Twitch reports tiers as 1000, 2000 and 3000, so the value must be 3000, not 3. Returning subscribers who share a resub message use the separate Twitch Resubscription trigger; copy this connector and switch the trigger to cover them.

Trigger TypeChannel Points
Condition #1Reward Name = Hydrate (the reward's exact title on Twitch)
Action #1Display Banner: {username} says: drink some water!, Duration 20
Action #2Write to File, File Path logs/hydrate.log, Append to file on, Content {username} redeemed Hydrate followed by a new line

What happens: each redemption of the Hydrate reward shows a banner for 20 seconds and adds a line to logs/hydrate.log. Other rewards do nothing. If the reward asks viewers for text, {user_input} holds it.

Trigger TypeHotkey Trigger, Key Combination ctrl+shift+b, Global hotkey on
Action #1OBS Studio (WebSocket), OBS — Set program scene, Scene BRB
Action #2OBS Studio (WebSocket), OBS — Set input mute, Input Mic/Aux, Muted Muted

What happens: pressing Ctrl+Shift+B, even while your game has focus, switches OBS to BRB and mutes the mic. Make a second connector (for example ctrl+shift+n) that switches back and unmutes. Using a Stream Deck trigger instead puts the same connector on a button.

Trigger TypeYouTube Super Chat
Condition #1Amount ≥ 5
Action #1Send Chat Message, YouTube only:
Thank you {username} for the {display_amount} Super Chat!

What happens: Super Chats of 5 or more (in the sender's currency) get a thank-you in YouTube chat, with the amount as YouTube shows it, such as $5.00. Compare on Amount; Display Amount is text and does not work with ≥.

Trigger TypeDonation
Condition #1Amount ≥ 20
Action #1Send Discord Message: {username} just tipped {formatted_amount} on stream: {message}. Server and Channel #stream-chat, then Add channel

What happens: Streamlabs or StreamElements tips of 20 or more are posted to your Discord channel with the tipper's message. Needs your Discord bot connected; see Connect Discord.

Tips for your own connectors

  • Start small. One trigger and one action. Test, then add.
  • Test sends for real. The {{icon:play_arrow}} button runs the actions with sample data, so a chat action posts to your real chat. Some triggers, such as Raid and Channel Points, have no sample data; see Testing a connector.
  • Watch for loops. A chat connector with Message ∋ hype whose reply also contains "hype" can answer itself. Use First word with a !command, or keep the trigger word out of the reply.
  • Use delays for overlays. Give a scene or banner a few seconds before the next step.
  • Plan for missing data. An anonymous cheer or an empty message leaves its placeholder blank. Write messages that still read well without it.
  • Need OR? Duplicate the connector and change the condition. All conditions on one connector must pass.
