Dynamic controls are buttons and counter boxes you add to a template in Spore Studio. They show up on Mycelian's Source Controls tab, so you can pause alerts, bump a score or start a timer during a stream without opening the editor.

Controls are saved as dynamic_controls in templates/template_configs/<name>.json when you click Save.

Add controls

Open the Source Controls tab

Open a Spore Studio template and choose Source Controls in the inspector. Legacy templates show "Source Controls are available for Spore Studio templates." instead.

Click + Add control and fill in the card

Each click adds a card. A new card is a Button with id control_N, label New control, action Custom template socket event and button text Run. The fields change with the type.

  1. Type decides how the control looks in Source Controls. See the table below.
  2. Action is what the overlay does. Counter and timer controls have no Action field; they always adjust their counter or timer.
  3. Counter lists the Counter blocks in this template as block id (counter id). It says "(no counters in template)" if there are none.
  4. Adding a Timer block creates this control for you, labelled Timer <block id>. Deleting the timer removes it.

Save, then use it live

Click Save. On Mycelian's Source Controls tab the template gets a card with your controls, grouped by type:

  • The card title is the template name followed by Controls.
  • A button shows its Button text (or its label when that is empty).
  • A counter control has an amount box, filled with the Default step. - and + change the counter by that amount; Reset returns it to its initial value. You can type a different amount before clicking.
  • A timer control has Start, Stop (pauses) and Reset.

The editor sets the type, label and action for inputs, sliders, toggles and selects. It has no fields for ranges or option lists; those come from the template's JSON config. See Configuring Template Settings.

The editor shows no extra fields for these. Their parameters (field id, endpoint, event name, action name) have to be added to the template's JSON by hand.

Custom template socket event, the default for new buttons, sends <template>_custom_template_action to your overlay. Listen for it in Advanced JS:

socket.on('my_hud_custom_template_action', function (data) {
    sporeToggle('logo');
});

How a click reaches the overlay

Every control sends the socket event <template>_<action>, for example game_hud_toggle_alerts. The saved overlay listens for each action it uses and runs it with the settings from the control's card.

The overlay listens once per action. If two controls in one template use the same action, both run with the first control's settings. Use one counter control per counter, and avoid two Adjust counter buttons with different operations in the same template.

Counter control or Adjust counter button

UseWhen
Counter control typeOne box per counter with -, + and Reset. The amount is typed live. The usual choice.
Button with Adjust counterOne labelled button that always does the same thing, for example "Add 100 bits".

Both target the counter id of a Counter block. A counter control uses Adjust counter under the hood; the operation comes from the button you click.

Example: game HUD

  1. Button, label Pause alerts, action Toggle alerts pause.
  2. Counter control, label Score, counter game_score, default step 1.
  3. Add a Timer block; its Timer control appears on its own.
  4. Save, then run all three from the Source Controls tab.

Dynamic controls also appear in the Stream Deck plugin's Action list for this template, under their labels. See Stream Deck Actions.
