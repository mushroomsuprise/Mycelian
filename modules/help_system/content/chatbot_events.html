An event makes the chatbot post a message by itself when something happens: a follow, a sub, a raid, a tip, a chat phrase, a time of day, or a timer every few minutes. For replies to !commands, see Creating Chat Commands.

The Events tab

  1. The line under the name is the event, with its service. Timers show how often they post (Every 20 minutes), and time-of-day events show Daily at 18:00.
  2. The reply with sample values, then tags: the event's filter (10+ viewers, Tier 2, Is “!lurk”…), a Twitch lookup, and where the reply goes.
  3. May not fire: Twitch may no longer send Hype Train events, so these might never post.

Create an event

Choose the event

Click New event (or Create an event). The editor opens on Choose an event; click one, or type in Search events. Then name it at the top.

Narrow it down

Many events show an Only when row under the event, such as a minimum number of bits or a reward name. Leave it at 0 or empty to answer every event of that type. Timers and time-of-day events show Runs with their schedule instead.

Write the reply and save

Write the message in Then · Reply; the Variables panel lists what this event gives you. New events send to Twitch only; click YouTube to add it. Click Create event, then {{icon:play_arrow}} Test on the card to see the reply with sample data. Tests never post.

The event editor

  1. The event and a one-line hint. Change opens the event list again; switching to another event resets the filters.
  2. The filters for this event. 0 or empty means any. Name and reward filters ignore upper and lower case.
  3. Optional. The same Twitch lookups as commands, such as follow age, account age or another channel's info. For events, Check is The viewer from the event (the follower, raider, subscriber…) or A name I type…. See Twitch lookups.
  4. The variables this event gives you, with sample values. Choose an event first; until then the panel says Choose an event to see its variables.

The reply step works like the command editor: Send to Twitch and/or YouTube, Discord channels, Show as banner, the 500-character warning and the Not a variable here warning. An event can post to Discord only, with Twitch and YouTube both off. The status at the bottom names problems such as Choose an event., Timers need at least 10 seconds between messages. or Set the time of day (HH:MM).

Chat message matching

Chat message and YouTube chat message compare the whole message with your text after trimming spaces, ignoring upper and lower case: Is exactly, Starts with or Contains. Leave the text empty to answer every message. The bot never answers its own messages.

Every event can also use the basics ({date}, {time}, {timestamp}…), statistics, quotes, YouTube and custom variables. See Chatbot Variables.

Testing an event

{{icon:play_arrow}} Test on a card, or Save & test, runs the event once on a copy with a sample event that passes its filters. Nothing is posted and the run count doesn't change. You see Test reply: …, or Didn't run: … with the reason. Test works even when the event is off.

Questions

Two messages posted for one follow

Every event that is on and matches posts. If you have two New follower events, both post. Turn one off, or give them different filters.

My Timer posts while I am offline

Timers run whenever the event is on and chat is connected. Turn the switch off on the card when you end the stream.

Nothing posts for subs, bits or raids

Twitch must be connected with every permission accepted. See Twitch Setup. Then check the filters: At least 500 bits ignores a 100-bit cheer. If the event has a lookup with an empty fallback, a failed lookup also posts nothing.

For first-time chatters, use Greetings instead of a Chat message event. To run OBS scenes, sounds or other actions on an event, use Connectors.
