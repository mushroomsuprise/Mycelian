An event makes the chatbot post a message by itself when something happens: a follow, a sub, a raid, a chat phrase, a set time of day, or a repeating timer. For replies to !commands, see Creating Chat Commands.

The Events tab

  1. The line under the name is the event type.
  2. Interval events also show how often they run.

Create an event

Pick the event type

Click New Event. In Basic Information, choose an Event Type, then give it a Name. The Enabled, banner and reply-target options are the same as for commands.

Narrow it down in Event Settings

Many types add an Event Settings box with filters, such as a minimum bit amount or a specific reward. Leave a filter at 0 or empty to react to every event of that type. See the table below.

Write the response and save

Write the message in Response Text. The Examples under it change with the event type. Click Create Event. Use Test on the card to send it once with sample data.

Test posts to your real chat targets with TestUser as the name, and adds to Triggered.

Every event can also use the shared variables: {timestamp}, {date}, {time}, {source}, statistics, YouTube and custom variables. See Chatbot Variables.

The Variables panel in the editor also lists names such as {tier_name}, {raider_name}, {follower_count} or {gifter_name}. The preview fills them with samples, but Twitch events do not send those values, so they stay as plain text in chat. Use the values in the table above.

Questions

Two events posted for one follow

Every enabled event that matches fires. If you have two New Follower events, both post. Turn one off, or give them different filters.

My Interval event posts while I am offline

Interval events run whenever the event is enabled and the chatbot is connected. Turn the switch off on the card when you end the stream.

Nothing posts for subs, bits or raids

Twitch must be connected with every permission accepted. See Twitch Setup. Then check the Event Settings filters: a Bits Quantity of 500 ignores a 100-bit cheer.

For first-time chatters, use Greetings instead of a Chat Message event. To run OBS scenes, sounds or other actions on an event, use Connectors.
