What a tip does

Each StreamElements tip:

  • plays the matching alert from Alerts → Donations,
  • appears in the Activity Feed,
  • fires donation events for the Chatbot and Connectors.

Tips sent with Emulate in the StreamElements overlay editor count too, which makes them a quick test.

Tip moderation

If tip moderation is on in StreamElements, a held tip alerts only after you allow it. Rejected tips are ignored. Each tip alerts once.

Alert currency

The alert currency is shared with Streamlabs and set on either tab. Thresholds in Alerts → Donations use that currency. A tip in another currency is converted using daily exchange rates, rounded to the nearest whole unit to pick the alert, and shown as the original amount with the converted amount in parentheses, for example €10.00 ($10.85). Details are in Streamlabs Integration.

Status

StreamElements appears in the status footer once a JWT is saved. The status colors and fixes are in Connect StreamElements; the full legend is in Status Footer.

Disconnect deletes the saved JWT. To connect again you need to paste it again.

JWTs expire. When yours does, Mycelian shows a notification and the status turns to Expired. Copy a new one from the dashboard.
