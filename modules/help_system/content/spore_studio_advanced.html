Testing a template without going live, where custom JavaScript fits, and how Spore Studio handles older hand-written templates.

Live preview

Click Preview in the toolbar (Open live preview window). The Live preview window opens over the editor and shows your template with its unsaved changes, so you can test without saving. Drag it by its title bar and resize it from the bottom-right corner.

  1. Alerts: a random alert, then one button per alert type with realistic random values. Queue templates send next_alert; Instant templates send instant_alert (Random instant alert).
  2. Other: one button for each non-alert event your bindings or data feeds listen to.
  3. SD: one button per Stream Deck action on this template. It sends the action's event with its default data.
  4. Size sets the preview's width and height (320–7680 by 240–4320). When OBS WebSocket is connected and a browser source uses this template's URL, Mycelian fills the size from OBS and shows From OBS. Otherwise it uses your last preview size or the design canvas. Reset clears the saved size and detects it again. Zoom scales the view from 25% to 200%.

Each mock button sends one socket event into the preview only, shaped like the real event (demo usernames, alert presets). Reload reloads the preview; Close closes the window.

On Save, the same mock list is written to template_configs/{name}.json as preview_mocks, so the preview toolbar in Custom Sources offers the same buttons.

Build bindings in Event bindings, check them here with mocks, then add the browser source to OBS.

Advanced JS tab

Your own JavaScript is saved between the SPORE_STUDIO:user-begin and SPORE_STUDIO:user-end markers and kept across saves. The box on the tab fits a few lines. Expand editor opens a larger editor with line numbers, syntax coloring, find and replace, and a helper reference.

Do not edit the generated block between auto-begin and auto-end; it is rebuilt on every save. The helper list, the queue handshake and examples are in Advanced JS reference.

Stream Deck tab

Defines this template's Stream Deck actions. Each action has an id, a name, a socket event and optional default_data JSON. The full workflow is in Stream Deck actions. Legacy templates show Stream Deck actions are not edited here for legacy templates.

Legacy templates

Templates listed under Legacy (advanced mode) in the template dropdown have HTML but no templates/_spore/{name}.spore.json. Spore Studio opens them in a limited mode.

  • Properties show the template's Source Settings values with the note Read-only legacy template. Edits to this value persist to the JSON config; HTML is not regenerated.
  • Save updates template_configs/{name}.json only.
  • Spore Studio reads elements out of the HTML. Position, size and some styles can be edited.
  • Bindings cannot be edited; they live in the hand-written HTML.
  • Save updates JSON values mapped from the HTML. It does not rewrite the template's websocket code.

You cannot drop new blocks into a legacy template. Trying shows Legacy templates can't accept new blocks — create a new template via '+ New' to edit visually. To get the full editor, create a template with + New and rebuild it, or copy a similar Spore template.
