Events Mycelian receives

Once the Main Account is connected, Mycelian listens for these events on your channel:

EventUsed for
FollowsFollow alerts, Activity Feed, Chatbot events, connector triggers
Subscriptions, resubs and gift subsSub alerts, including the resub message
Bits (cheers)Bit alerts, with the cheer message and emotes
RaidsRaid alerts and the optional raid shoutouts below
Channel point redemptionsChannel point alerts and connector triggers
Hype trains (start, progress, end)Instant alerts and the Activity Feed
Stream online / offlineGo-live triggers, and the Discord go-live post
Channel updates (title, category)A category-change notice, and the current title and category for overlays
Chat messages and moderation actionsChatbot commands and chat polls. Timeouts, bans and deleted messages are passed on to chat overlays

Use these events in alerts, Chatbot events and connector triggers. Chat polls are run by the Chatbot from chat keywords; see Chatbot Polls.

Permissions

When the browser opens, accept every permission Twitch lists. Mycelian uses them for alerts, chat, raids, shoutouts, announcements and moderation. Declining a permission disables the features that need it.

Options on the Twitch tab

SettingsTwitch has three switches under Options. Click Save after changing them.

SwitchWhat it does
Process Twitch alertsSends Twitch events into the alert queue and Activity Feed. Turn it off to keep the connection without playing Twitch alerts.
Send native Twitch ShoutoutAfter a raid, sends Twitch's own shoutout for the raider.
Send chat raid shoutoutAfter a raid, the chatbot also posts a shoutout message in chat.

If events stop

Check the Twitch item in the status footer. Degraded means you are signed in but events have stopped; Expired or Auth Failed means you need to sign in again. Click Connect on the Main Account card. The full status list and fixes are in Connect Twitch, and more in Connection Problems.
