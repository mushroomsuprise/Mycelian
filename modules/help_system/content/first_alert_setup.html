This guide sets up a follow alert from start to finish: create it on the Alerts tab, add the overlay to OBS, and test it without waiting for a real follower.

{{icon:schedule}} About 10 minutes {{icon:place}} AlertsFollows

Before you start

  • Twitch is connected (Connect Twitch) and Process Twitch alerts is on in SettingsTwitch. You can test without Twitch, but real follows need it.
  • OBS is installed on this PC. See Setting Up Browser Sources in OBS.
  • Optional: a GIF or image and a sound file for the alert.

Create a follow alert

Open Alerts, then Follows

Click the Alerts main tab, then the Follows sub-tab. The Alerts tab opens on Bits. Click New alert at the top of the alert list on the left.

  1. The alert list. Click New alert, or an alert you already have. Duplicate (content_copy) in the header copies the current alert into a new, unsaved one.
  2. Playback: Duration is how long the alert shows, in seconds (new alerts start at 3). Stackable lets several alerts of this type show at once.
  3. Visual: the GIF or image to show. Click Browse on the file card to pick a file; the card then shows the file name and folder.
  4. Sound: the sound file, its Volume, and Fade in / Fade out in milliseconds.
  5. Test Alert plays the alert with the current settings, saved or not. Save stores it. Unsaved changes shows until you save.

Set the duration and media

In Playback, set Duration, for example 5. Then click Browse on the file cards in Visual and Sound to pick a GIF and a sound. Both are optional.

More on file types and folders: Alert Media.

Save the alert

Click Save. The alert shows up in the list as Follow. Twitch follows use one follow alert: the default one, or the first one in the list if there is no default.

Set the message text

The follow message is part of the overlay, not the alert. Open the Source Settings tab, pick follow in the template list, and edit Follow Message. Put {{FolName}} where the follower's name should go. The default is:

Thanks for the follow {{FolName}}!

Click Save on Source Settings when you are done. See Template Configuration.

Add the overlays to OBS

Live follow alerts play on the follow overlay. Every other alert type plays on the alerts overlay. Add both as browser sources so you are covered:

OverlayURLShows
followhttp://127.0.0.1:5000/followLive follow alerts
alertshttp://127.0.0.1:5000/alertsBits, subs, raids, donations, channel points and test alerts

Set both to 1920 × 1080 (or your canvas size). The URLs are also listed in SettingsAbout → Browser source URLs, with an OBS button that adds them for you when OBS WebSocket is connected. Step-by-step: Setting Up Browser Sources in OBS.

Other alert types

The other sub-tabs work the same way. Bits, Subscriptions, Streaks, Gift Subs, Donations and Raids also have an Exact / Range switch next to Triggers on, so you can make different alerts for different amounts. See Alert Configuration.

Tips

  • Start simple. Get one alert working, then add more. Test after each change.
  • Keep it short. 3 to 5 seconds for everyday alerts, 5 to 10 for big moments. Do not cover gameplay.
  • Match your look. Fonts, colors and positions are set per overlay in Source Settings.
