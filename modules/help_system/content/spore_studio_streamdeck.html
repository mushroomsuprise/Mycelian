A Stream Deck action lets a physical key change your overlay: show or hide a logo, bump a counter, or send your own socket event. You define the action in Spore Studio, bind elements to it, then pick it on a Template Action key in the Mycelian Stream Deck plugin.

{{icon:schedule}} About 5 minutes {{icon:extension}} Mycelian Stream Deck plugin {{icon:place}} Spore StudioStream Deck

Install the plugin and connect it to Mycelian first. Stream Deck connection guide covers both.

How a key press reaches the overlay

Set up an action

Add the action on the Stream Deck tab

Open your template in Spore Studio, choose the {{icon:grid_on}} Stream Deck tab in the inspector, and click {{icon:add}} Add Stream Deck action. A template without actions shows No Stream Deck actions yet above that button. A new card appears with the id action_1, the name New action, and a socket event equal to the id. Rename them.

  1. Action id is the key stored in the template JSON and the value the plugin sends as actionName. Letters, digits, _ and - only; other characters become _. Renaming it updates bindings that use it.
  2. Display name is what the plugin's Action list and the preview's SD: buttons show.
  3. Socket event is the event the overlay listens for. Every binding with this event runs when the key is pressed.
  4. default_data must be a JSON object. Each key becomes an editable field in the plugin (see below).

If two actions share a socket event, a warning box on the tab says "Multiple actions share socket event(s)…". Bindings on that event then fire for either key.

Bind elements to the action

Select the element on the canvas, open {{icon:bolt}} Bindings, and click {{icon:add}} Add binding. Under 1 When, set Trigger to Stream Deck action and pick the action. Under 2 Do this, pick what the element does. New bindings default to the first action not already used in this template.

If the list says "Add Stream Deck actions in the Stream Deck tab first.", go back to step 1.

Test in Preview, then Save

Click Preview. The mock toolbar has an SD: group with one button per action, labelled with its display name. Clicking one emits the action's socket event with its default_data, so no hardware is needed.

Click Save. The actions are written to streamdeck_options in templates/template_configs/<name>.json, which is where the plugin reads them.

Assign a key in the Stream Deck app

Drag Template Action from the Mycelian category onto a key. In its settings pick the template, then the action.

  • Template lists every template that has Stream Deck actions or Source Controls.
  • Action shows display names. The key stores the action id.
  • Parameters shows one field for each key in default_data: true/false keys become True/False choices, numbers a number box, text a text box. Values you set here replace the defaults for this key only.
  • Saved a change in Spore Studio? Click Refresh next to Action.

Payload and name matching

When a key fires, Mycelian builds the payload in this order:

  1. Start with the action's default_data.
  2. Apply the values set under Parameters on that key. They win on conflicts.

The template's config is authoritative for the socket event. A stale event name saved in the key's settings is ignored. If the action has no socket event, Mycelian uses <template>_<action id>.

Mycelian finds the action by the name the plugin sends, trying each of these in turn:

  1. The action id.
  2. The display name.
  3. The socket event, or an event ending in _<name>.

If none match, the press does nothing for your bindings. Renaming an action id after assigning keys breaks those keys until you pick the action again.

Registry events or your own event

Socket eventWhen to use
Your own name, such as toggle_logoThe usual choice. Only bindings for this key react. It does not need to exist in the event registry.
A registry event, such as instant_alertReplay an existing event with a fixed payload in default_data, for example {"alert_type": "bit", "amt_cheered": 100}. Anything else listening to that event in this overlay also reacts.

Common patterns

  1. Action id toggle_logo, socket event toggle_logo, default_data {}.
  2. On the logo Image: binding, trigger Stream Deck action → Toggle logo, action Toggle visibility.
  1. Add an action such as add_point.
  2. On any element (the counter itself works): binding, trigger Stream Deck action → add_point, action Adjust counter.
  3. Set counter_id, operation and the delta fields. See Counters.

A counter's Data feed only listens to registry events, so use a binding for keys.

Binding with primary action Show element, then Add chained step (Then, step 1) with Hide element and a delay in ms. Or use Show for N seconds as a single action.

Other ways to fire an action

  • Dynamic controls appear in the plugin's Action list under their labels, so a key can press a Source Controls button directly.

Troubleshooting

The action is missing from the plugin

Save the template in Spore Studio, then click Refresh next to Template and Action. If Template shows "Connection failed - click Refresh", Mycelian is not reachable at the server address. Use Test and see the connection guide.

The key works in the plugin but nothing changes on stream

Check that the binding's trigger is Stream Deck action with the right action, that the template is saved, and that the OBS browser source was reloaded after saving. The SD: button in Preview should do the same thing.

One key triggers two things

Two actions share a socket event. Give each action its own event on the Stream Deck tab.

The Stream Deck tab says actions are not edited here

That message appears for legacy templates. Stream Deck actions can only be edited on Spore Studio templates.
