Every block in the Spore Studio Blocks panel, what it does, and the settings it adds to Properties. Defaults are the values a new block starts with.

Click a group header in the real panel to open or close it. Groups start collapsed, and your choice is remembered.

Drag a block onto the canvas, pick a category, then set it up in Properties. Every block has the shared sections described below, plus its own.

Most rows have a small Expose in Source Settings checkbox before the label. When it is on, the value is written to template_configs/{name}.json and can be changed later in Source Settings without reopening Spore Studio. When it is off, the value is baked into the HTML.

Confetti

Throws a burst of confetti across the block. It is drawn inside the overlay, so it needs no internet connection. The block is see-through and pieces stay inside it, so size it to the area the confetti should cover. Default size 640 × 360. Poll

A live view of the poll set up in Chatbot → Polls for this template. The widget does not collect votes. Options arrive sorted by votes, highest first.

  1. Title and a chip with the time left. An open-ended poll shows Live, and an ended one Poll closed. The thin bar under it shrinks as a timed poll runs.
  2. Rank number, name, chat keyword, then votes and share. The leader glows while voting is open.
  3. Footer note (while voting is open) and the total votes.

Bars grow smoothly as votes arrive. When the poll ends, the winner turns the winner color with a trophy, and the other options fade.
