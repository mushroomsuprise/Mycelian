Every color swatch in Mycelian opens the same color picker: in Source Settings, in SettingsTheme and in Spore Studio. It does solid colors with transparency, and gradients where a fill can take one.

{{icon:place}} Source Settings, SettingsTheme, Spore Studio

Open the picker

Click a color swatch. The picker opens next to the swatch and moves to stay on screen. Only one picker is open at a time. What you pick shows straight away in the preview, the theme preview or the Spore Studio canvas, so you can judge it in place before you keep it.

Solid colors

  1. Drag in the square to set how strong and how bright the color is. The rainbow bar below sets the hue, and the checkered bar under it sets the opacity.
  2. HEX / RGB switches how the value is written. Type a color into the box (#hex, rgb(), rgba(), hsl(), a color name or transparent), and the opacity in percent next to it. {{icon:colorize}} Pick a colour from the screen is an eyedropper; it only appears where the system supports it.
  3. One click sets 100%, 75%, 50% or 25% opacity. {{icon:block}} is Fully transparent.
  4. Before is the color you started with (click it to go back to it), New is the current one. Template colours are the colors the template suggests for this setting; Show all lists every one when there are more than twenty. Recent holds the last ten solid colors you kept.
  5. Done keeps the color, Cancel puts the old one back.

Transparency

Lower the opacity to let what is behind the overlay show through. The checkerboard behind the bars, the swatches and the Before / New strip shows how see-through the color is. At 0% the value becomes transparent.

The value is written back in the format it came in. An opaque color stays #hex (or rgb() if it was written that way), a see-through color is written as rgba(r, g, b, opacity), and a color you did not change is left exactly as it was.

Gradients

Where a fill can be a gradient, the picker has Solid and Gradient tabs. Opening Gradient starts a two-stop gradient from the current color; going back to Solid uses the color of the selected stop.

  1. Linear or Radial. A linear gradient has an angle: drag the dial (hold Shift to snap to 15°) or type degrees. Radial gradients spread out from the middle and have no angle.
  2. The stops. Click the bar to add a stop (it takes the color at that point), drag a stop to move it, click a stop to select it. A selected stop also moves with the arrow keys and is removed with Delete.
  3. The selected stop: its color, opacity and position in percent, and {{icon:delete}} Remove this stop. A gradient keeps at least two stops. The square and bars below change the selected stop's color.
  4. The finished gradient and its CSS. Edit as CSS lets you type or paste a gradient; while the text is not a valid gradient yet, the last valid one is kept. Gradients the stop editor can't show (for example a conic or repeating gradient) are kept as written and can be edited here.

Keep or cancel

Keeping a color only changes the form. In Source Settings and on the Theme tab you still click Save (or Apply); in Spore Studio the change goes into the editor's undo history and is saved with the template.

There is no eyedropper button

The eyedropper uses a browser feature that not every system has. When it is missing, the button is left out; type the color or pick it in the square instead.

My value looks different after picking

Only colors you change are rewritten. A picked opaque color keeps the format the value came in (#hex or rgb()); a see-through one becomes rgba(); a gradient becomes CSS text such as linear-gradient(90deg, …).
