Mycelian itself is light. Most slowdowns come from what OBS has to draw (browser sources, big GIFs) or from a very long alert history. Find where the load is first, then use the fixes for that area.

Where is the load?

Open Task Manager (Windows) or Activity Monitor (macOS) while the problem happens, and look at which process is busy:

Busy processUsually meansGo to
OBS or obs-browser-pageBrowser sources are heavy: large GIFs, many sources, high resolution or frame rateOBS and browser sources
MycelianA large activity history, a busy overlay server, or many live widgetsMycelian

Also look at Overlay Server in the status footer. Overloaded means it is too busy to keep up; Stalled means it stopped answering. Both are amber. See Status Footer.

OBS and browser sources

OBS lags or drops frames when an alert plays

Cause: The alert image is large. A long, full-size GIF is expensive to decode.

Fix: Resize images to about the size they show at. The alerts template draws them at GIF Width × GIF Height (190 × 190 by default), so 300-500 px is plenty. Cut frames and colors, or convert to animated WebP. See Alert Media.

Many browser sources, high CPU all the time

Cause: Each browser source is a small web browser. Hidden sources keep running unless told not to.

Fix: In each source's properties:

  • Turn on Shutdown source when not visible for overlays you only use in some scenes. Leave it off for the alerts source, so alerts still play when you switch scenes.
  • Set Width and Height to what the overlay needs, not 1920 × 1080 for a small widget.
  • Use Custom frame rate 30 unless the overlay needs smooth motion.
  • Reuse one source across scenes with Add Existing instead of copies.
OBS is slow even with few sources

Fix: Make sure Enable Browser Source Hardware Acceleration is on in OBS SettingsAdvancedSources, update your graphics driver, and remove OBS plugins you no longer use.

Mycelian

The Activity Feed is slow to open or scroll

Cause: It loads a lot of history.

Fix: On the Activity Feed, open History and click Storage settings under the list (or open SettingsApp Settings). Lower Items per page or Pages to load under Activity feed and storage and click Save. See Activity Feed.

Startup is slow or memory keeps growing over weeks

Cause: Every alert is stored for replay. Auto-trim is off by default, so storage only grows.

Fix: Turn on Auto-trim stored alerts (below). Restarting Mycelian between streams also frees memory.

  1. Auto-trim stored alerts deletes old stored alerts. Trimmed alerts can no longer be replayed.
  2. Trim by: Max number keeps the newest N alerts, Age deletes alerts older than the days set, Number and age applies both. Defaults are 500 alerts and 30 days.

While a trim runs, the status footer shows its progress.

Overlay Server shows Overloaded

Cause: Too many updates are going to browser sources at once, for example many live widgets, connectors that fire on every chat message, or several copies of the same overlay open.

Fix: Close overlay pages you left open in browser tabs. Reduce connectors that run on every message (see Connectors). Simplify heavy Spore Studio templates. If it stays overloaded, restart Mycelian.

Template controls lag or stop working

Cause: The browser source lost its live connection to the overlay server.

Fix: Refresh the source in OBS (Refresh cache of current page). If Overlay Server is not Running, see Connection Problems. More on the live connection: Template WebSocket and Source Controls.

Alerts are late

Alerts appear seconds after the event

Cause: Usually the queue, not the computer. Alerts play one at a time, and each waits for the previous alert's duration, sound and speech, plus Delay Between Alerts.

Fix: Shorten durations and long sound files, turn on Stackable where overlap is fine, and check the Internet item in the footer. See Troubleshooting Alerts.

Media loads slowly the first time

Cause: Large files on a slow drive.

Fix: Keep images and sounds small (see above). If the assets folder is on a slow or network drive, move Mycelian to a local SSD.

Optimization checklist

  • Mycelian is up to date (SettingsAbout → Check for updates).
  • Alert images are 500 px or smaller and short.
  • Alert sounds are 3-10 seconds, MP3 or OGG.
  • Unused browser sources are removed, or set to Shutdown source when not visible.
  • Browser source hardware acceleration is on in OBS.
  • Auto-trim stored alerts is on.
  • No overlay pages are left open in browser tabs.
  • Overlay Server shows Running during a stream.

Reporting a problem

If something keeps getting slower, note when it started, then open SettingsAbout. Health check lists recent errors; the folder button (Open the logs folder) opens the folder with mycelian.log (capped at 15 MB, oldest lines trimmed). Include that file and your version number from the same page when you report it on GitHub (View on GitHub).
