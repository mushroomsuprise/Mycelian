The Source Controls tab gathers the live controls of every template in one place: buttons, switches, sliders, counters, text boxes and timers. Clicking one changes the overlay in OBS immediately, without opening Source Settings. The same cards are available as an OBS dock.

The Source Controls tab

  1. How many templates have controls, and how many controls they have in total. Templates without controls are left out.
  2. Search templates and controls hides cards that don't match. It looks at template names, control labels and button text, so typing spin finds the roulette card.
  3. OBS dock link copies the address of the OBS dock. See Source Controls as an OBS dock.
  4. {{icon:refresh}} rebuilds the cards; {{icon:help_outline}} opens this page.
  5. One card per template, named exactly like its config (for example counter), with the number of controls. Cards are sorted alphabetically and flow down each column. Templates marked hidden still get a card, with a Hidden tag.
  6. Hover a label with {{icon:info_outline}} (or a button) to see the control's description.
  7. {{icon:tune}} Open in Source Settings jumps to the template's settings. Only the app has it, not the dock.

Controls appear in the order the template lists them. Buttons that follow each other share a two-per-row grid; an odd last button takes the full width.

Templates you build in Spore Studio add their own cards.

Use it during a stream

Make sure the overlay is loaded

The template must be open somewhere, usually as a browser source in OBS. Controls talk to the open overlay; nothing happens if no copy of it is loaded.

Find the card

Open Source Controls (or the OBS dock) and type part of the template name or the control's label into the search box.

Click the control

The change shows in OBS right away. Every open copy of that template reacts, including the Source Settings preview.

Most controls change the overlay only while it is open. A browser source refresh brings back the saved settings. Controls that save their value, like the Title overlay's Show Category switch, are the exception: the value is written to the template's config.

Source Controls as an OBS dock

The same cards are available as a web page you can dock inside OBS, so you do not need to switch to Mycelian while live.

Copy the dock address

On the Source Controls tab, click {{icon:content_copy}} OBS dock link. A pop-up confirms "OBS dock link copied". The address uses Mycelian's current server port; by default it is http://127.0.0.1:5000/source_controls.

Add a custom browser dock in OBS

In OBS, open Docks → Custom Browser Docks… (older versions: View → Docks). Name it, for example Source Controls, paste the address as the URL and click Apply.

Place and size the dock

Drag the dock where you want it. When it is wide enough, the cards spread over several columns; a narrow dock shows one column.

  1. Search works like the app's: template names, control labels and button text. The header stays at the top while you scroll.
  2. The connection to Mycelian: Live when connected, Connecting… while the dock first connects, Reconnecting… after it lost Mycelian. Controls can't be sent until it is Live again.
  3. {{icon:refresh}} reloads the controls.
  4. Timer controls work in the dock too.

The dock looks and behaves like the tab: same cards, same order, live values that update by themselves. It has no {{icon:tune}} button and no OBS dock link button. It uses the app's theme from the moment it loads and switches when you change themes in Mycelian. Its own small pop-ups are described in Notifications.

If the dock shows a blank page because OBS started before Mycelian, restart OBS with Mycelian running. See OBS Browser Source Setup.

Other ways to trigger controls

  • Stream Deck: template actions can be bound to keys. See Stream Deck.
  • Connectors: run template actions automatically when an event happens. See Connectors.

If something goes wrong

I clicked a control and nothing changed in OBS

Check the overlay is loaded in OBS and the browser source is active. If OBS opened before Mycelian, refresh the browser source. Then click the control again. If a pop-up says the control wasn't sent, check the overlay server in the footer.

The tab says "No source controls yet"

No template defines controls. Add them in Spore Studio's Source Controls tab and save. The dock says "No dynamic controls found" in the same case.

A new control from Spore Studio is missing

The cards rebuild by themselves after a template is saved. If one is still missing, click {{icon:refresh}} in the header.

"Nothing matches your search"

No template name, control label or button text contains what you typed (the dock says "No matches"). Clear the search box.

The dock says Connecting… or Reconnecting…

The dock can't reach Mycelian. Check Mycelian is running and the overlay server is up in the footer. If OBS started first, restart OBS. See OBS Browser Source Setup.
