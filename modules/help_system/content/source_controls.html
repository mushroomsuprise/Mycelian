The Source Controls tab gathers the live controls of every template in one place: buttons, switches, counters, text boxes and timers. Clicking one changes the overlay in OBS immediately, without opening Source Settings.

The Source Controls tab

  1. Search templates hides cards whose template name does not contain the text.
  2. Refresh reloads the cards. Use it after saving a template in Spore Studio or editing a config file.
  3. One card per template, titled <Template> Controls, with a count of its controls. Templates marked hidden still get a card, with a Hidden badge. Cards with fewer controls come first.
  4. Controls are grouped by kind: Actions, Counters & Numbers, Timers, Text Input, Adjustments, Special Controls, Banner.
  5. Hover a control to see its description.

Templates you build in Spore Studio add their own cards.

Use it during a stream

Make sure the overlay is loaded

The template must be open somewhere, usually as a browser source in OBS. Controls talk to the open overlay; nothing happens if no copy of it is loaded.

Find the card

Open Source Controls and type part of the template name into Search templates.

Click the control

The change shows in OBS right away. Every open copy of that template reacts, including the Source Settings preview.

Most controls change the overlay only while it is open. A browser source refresh brings back the saved settings. The Title overlay's Show Category switch is an exception: it is saved to the template's config.

Source Controls as an OBS dock

The same controls are available as a web page you can dock inside OBS, so you do not need to switch to Mycelian while live.

  1. In OBS, open Docks → Custom Browser Docks… (older versions: View → Docks).
  2. Name it, for example Source Controls, and set the URL to http://127.0.0.1:5000/source_controls.
  3. Click Apply and place the dock.

If the dock shows a blank page because OBS started before Mycelian, restart OBS with Mycelian running. See OBS Browser Source Setup.

Other ways to trigger controls

  • Stream Deck: template actions can be bound to keys. See Stream Deck.
  • Connectors: run template actions automatically when an event happens. See Connectors.

If something goes wrong

I clicked a control and nothing changed in OBS

Check the overlay is loaded in OBS and the browser source is active. If OBS opened before Mycelian, refresh the browser source. Then click the control again.

The tab says "No source controls yet"

No template defines controls. Add them in Spore Studio's Source Controls tab, save, then click Refresh.

A new control from Spore Studio is missing

Click Refresh at the top of the tab. The cards are only built when the tab loads or refreshes.
