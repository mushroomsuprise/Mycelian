Every block in Spore Studio gets live data the same way: through its Data feed section. A feed listens for something, keeps the items you want, shapes the text, and tells the block what to do with each one. Only the last step differs between a list, a wheel, a counter or a timer.

{{icon:place}} Spore StudioPropertiesData feed

A block can have several feeds. Add one with + Add feed. A new feed listens to Alert (instant) and Alert (queue), except on a Poll (Poll update, Poll ended) and Now playing (Now playing (Spotify)). Nothing is sent to other blocks; each feed only changes its own block.

A feed card

  1. The switch turns the feed off without deleting it. The name box is optional. Copy duplicates the feed below itself.
  2. The template is built from payload fields. Empty uses the main text field. The Looks like line fills it with sample values.
  3. The only part that changes per block. See Targets below.

The one-line summary under the name shows the source and the target, so you can read a block's feeds without opening them.

Fields in parts 2 and 3 follow the events you turned on in part 1. Alert type and Sub tier appear only for alert events. Split into rows appears only when a chosen event carries a list, such as giveaway winners.

1. When it runs

Run when: An event (alert, chat, giveaway...). Tick one or more events. The feed runs once per event. Events include Alert (queue), Alert (instant), Giveaway entry, Giveaway winner, Poll update, Poll ended, Now playing (Spotify), Refresh alerts, Alerts paused, Alerts resumed, Pause status update, Chat message (Twitch), Chat banner, Chat message (connector), Chat moderation event and Twitch API call (response).

Run when: A live value (a data source). Pick a Data source such as a session statistic or another counter, then:

  • Re-read every (ms): poll the value. 0 reads only when a checked event fires.
  • Re-read on events: read again whenever a checked event fires.

The sources are listed in Data Sources.

Run when: The output of another template. Pick from Template output (for example a roulette or wheel result). Save the other template first so it is listed. You can also type a Template name and Output event. Only when limits it to one field value, for example one wheel in that template.

3. Token formatting

In Template, write {field} or {field|modifier}. Chain modifiers with |. {value} is the Number field. Insert a format... adds these for you.

ModifierExampleResult
number{amount|number}1,234
compact{total|compact}1.2K
int{amount|int}12
decimals:N{amount|decimals:2}12.00
percent{ratio|percent}50%
duration{duration|duration}1:05 (seconds as m:ss)
ordinal{index|ordinal}1st
upper / lower / title{username|upper}CASEY
trim{message|trim}Spaces removed from the ends
truncate:N{message|truncate:40}Cut to 40 characters with …
default:text{username|default:Anonymous}Anonymous when empty

Prefix and Suffix wrap the result. Decimals rounds numbers (0–10, empty keeps the value). If a field is missing is the text used when the payload has no value.

Template outputs

Blocks can announce results that other overlays listen to. Spore Studio writes them into the template's JSON when you save. Each block with outputs has an Outputs section to switch one off or rename it.

Other templates are scanned too. Any socket.emit('…') in a template's HTML is listed automatically, and a template can describe its outputs in an outputs block of its config (the roulette template declares roulette_result). All of these appear under The output of another template.

The server relays every output to every overlay as template_output with {template, event, data}. Preview has a mock button for each one.

My old list or stat card settings disappeared

Before data feeds, lists, wheels, stat cards and data displays had their own source settings. Spore Studio converts them into an equivalent feed the first time you open the block, and the saved template uses the feed from then on.
