Mycelian is a streaming toolkit for Twitch. It runs on your PC and serves alerts, overlays and docks to OBS as browser sources. It also runs a chatbot, automations and integrations with other services.

{{icon:schedule}} About 20 minutes for the quick start {{icon:computer}} Runs on the same PC as OBS

The main window

Everything lives in one window with eight tabs. Mycelian reopens the tab you used last.

  1. Tab content. The eight tabs along the top switch this area. Activity Feed is the live list of follows, subs, raids and other events. The other tabs are described below.
  2. Help ({{icon:help_outline}}) opens help for the tab you are on. Small ? buttons next to some settings open the matching topic.
  3. Notifications ({{icon:notifications}}) opens the notification centre: every pop-up Mycelian has shown, such as a service disconnecting or an error. The number on the bell counts the ones you have not seen. See Notifications.
  4. Status footer. One badge per service. Gray Twitch means it is not connected yet. See Status Footer.

Quick start

Connect Twitch

Create a Twitch application, paste its Client ID and Client Secret into SettingsTwitch, and click Connect. Follow Connect Twitch.

Connect OBS (recommended)

Turn on the WebSocket server in OBS and enter its port and password in SettingsOBS. Mycelian can then add browser sources for you and refresh them. Follow Connect OBS.

Add your first browser source

Copy a URL from SettingsAbout → Browser source URLs, or click its OBS button. See Setting Up Browser Sources in OBS.

Set up and test an alert

Create a follow alert on the Alerts tab and click Test Alert. Follow Setting Up Your First Alert.

Make it yours

Style overlays in Source Settings, pick a theme in SettingsTheme, and connect any other services from Connection Guides.

Click Mark step done as you go. Your progress is saved, so you can come back later.

Getting help

  • Click {{icon:help_outline}} at the top right of the main window for help on the current tab.
  • Click a small ? next to a setting for that setting's topic.
  • Use the search box in the help window to find any topic.
  • When something does not work, start with Connection Problems or Troubleshooting Alerts.
