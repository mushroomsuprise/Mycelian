Mycelian's alerts, overlays and widgets are web pages served from this PC. You show them on stream by adding each one to OBS as a Browser Source.

{{icon:schedule}} About 5 minutes {{icon:place}} SettingsAbout → Browser source URLs

Mycelian must be running for its sources to load. The overlay server badge in the status footer should say Running.

Before you start

  • OBS Studio is installed on the same PC as Mycelian.
  • Optional but easier: OBS WebSocket is connected (Connect OBS). Then Mycelian can add sources for you.

Find the URL

Open SettingsAbout and scroll to Browser source URLs. There is one card per template and Spore Studio container.

  1. The badge shows how many live controls the template has on the Source Controls tab. The copy button copies the URL.
  2. The OBS button (Add to OBS) creates the browser source in OBS for you. It needs OBS WebSocket.
  3. The URL itself. You can select and copy it from here too.

Add it to OBS

Click the OBS button on a source card. Mycelian loads your OBS scenes and shows this dialog:

  1. Pick the scene. If the template is already a browser source on that scene, a warning says so. If the name is taken, Mycelian picks a free one and tells you.
  2. Add creates the source. Use custom frame rate shows an FPS field (default 60).

If WebSocket is off you get "OBS WebSocket is not enabled. Turn it on in Settings → OBS." If it is on but OBS is closed you get "OBS WebSocket is not connected." Use the other tab, or connect OBS.

  1. Copy the URL from its source card.
  2. In OBS, click + under Sources (or right-click the Sources list) and choose Browser.
  3. Name it (for example Mycelian Follow) and click OK.
  4. Paste the URL, set the width and height, and click OK.

Positioning and layering

  • Keep alert sources at full canvas size and move the alert itself in Source Settings.
  • Put alert sources near the top of the Sources list so they draw above gameplay.
  • Use OBS's transform tools (right-click → Transform) only for small overlays like bars and counters.

Common URLs

Mycelian serves every template from port 5000 on this PC. The About tab lists all of them, including your own.

To show a source on another PC (a two-PC setup), replace 127.0.0.1 with this PC's local network address.

Custom browser docks

Activity Feed and Source Controls work best as OBS docks: in OBS choose View → Docks → Custom Browser Docks, give the dock a name, and paste the URL (for example http://127.0.0.1:5000/activity_feed).

Docks behave differently from scene sources:

  • OBS has no WebSocket refresh for docks, so Mycelian cannot reload them for you.
  • If OBS opened before Mycelian, a dock can show a white page or "This site can't be reached." Ctrl/Cmd+R does not fix it, because it reloads the browser's error page, not the Mycelian URL.
  • The fix: keep Mycelian running and restart OBS. Docks reload their URL when OBS starts with Mycelian already listening.
  • When you quit OBS while Mycelian is running, Mycelian points only its own docks at a small local page that says "Waiting for Mycelian…". The next time OBS starts first, the dock waits and then loads instead of failing. Docks for Twitch, StreamElements and other sites are left alone.

Refreshing sources after a late start

If OBS is already open when Mycelian starts, Mycelian's scene sources may have failed to load. With OBS WebSocket connected (SettingsOBS), Mycelian refreshes its own scene browser sources once after it connects. Other browser sources (StreamElements, YouTube and so on) are left alone. Docks are not covered; see above.

Troubleshooting

The source is blank or white
  • Check that Mycelian is running and the Overlay Server badge says Running.
  • Compare the URL with the one on the About tab.
  • Right-click the source in OBS → Properties → Refresh cache of current page.
  • A blank alerts source is normal until an alert plays. Click Test Alert on the Alerts tab.

More: Troubleshooting Alerts.

Follows show in the Activity Feed but not on stream

Live follow alerts play on the /follow source, not /alerts. Add a /follow browser source. See Setting Up Your First Alert.

No sound

With Control audio via OBS on, the source has its own slider in OBS's Audio Mixer; check it is not muted. With it off, sound goes to your desktop audio. See Audio Troubleshooting.

OBS gets slow
  • Turn on Shutdown source when not visible.
  • Remove browser sources you do not use.
  • Make sure browser source hardware acceleration is on in OBS's advanced settings.

More: Performance Optimization. OBS's own help is the OBS Knowledge Base.
