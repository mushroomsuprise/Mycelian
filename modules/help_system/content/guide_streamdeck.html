Mycelian ships its own Stream Deck plugin. You install it from Mycelian with one button, restart the Stream Deck app, then drag Mycelian actions onto your keys.

{{icon:schedule}} About 5 minutes {{icon:computer}} Stream Deck app 6.5 or newer, on macOS 12+ or Windows 10+ {{icon:place}} SettingsApp Settings

The plugin talks to Mycelian over its local overlay server, so there is no account, token or sign-in. Mycelian must be running for the keys to work.

Before you start

  • The Elgato Stream Deck app is installed and has been opened at least once. Mycelian looks for the plugin folder that app creates.
  • Stream Deck and Mycelian run on the same computer (the plugin's default address is 127.0.0.1:5000).
  • For the Connector key: you have a connector with the Stream Deck trigger. For the Template Action key: a Spore Studio template with Stream Deck actions.

Install and connect

Install the plugin from Mycelian

Open SettingsApp Settings and scroll to the Stream Deck plugin panel at the bottom. Click Install Plugin.

  1. Status reads Stream Deck not detected if the Stream Deck app has never run on this computer, Not installed before you install, and Installed after.
  2. The button copies the plugin bundled with Mycelian into Stream Deck's plugins folder. Once installed it reads Reinstall Plugin.

A pop-up says "Stream Deck plugin installed" (or reinstalled) and "Quit and reopen Stream Deck so it loads the plugin."

Where the plugin goes

~/Library/Application Support/com.elgato.StreamDeck/Plugins/com.mushroomsuprise.mycelian.sdPlugin

%appdata%\Elgato\StreamDeck\Plugins\com.mushroomsuprise.mycelian.sdPlugin

Linux is not supported; the Stream Deck app does not run there.

Restart the Stream Deck app

Quit Stream Deck completely and open it again. On macOS use Stream Deck → Quit Stream Deck from the menu bar icon; on Windows right-click the tray icon and choose Quit. Closing the window is not enough.

A Mycelian category now appears in the action list on the right, with three actions:

ActionWhat a press does
Toggle AlertsPauses or resumes alert playback. The key shows ACTIVE or PAUSED and stays in sync with the app.
ConnectorRuns a Mycelian connector that uses the Stream Deck trigger. The key shows the connector's name.
Template ActionRuns a Stream Deck action defined in a Spore Studio template, with optional parameters. The key shows template and action.

Point the key at Mycelian and test

Select the key you just placed. Its settings open below the key grid. Under Connection, leave Mycelian server at 127.0.0.1:5000 and click Test.

  1. Test asks Mycelian whether it is reachable. "Connection failed — is Mycelian running?" means it is not.
  2. Pick the connector to run. Click Refresh after adding a connector in Mycelian.
  3. Pick the template, then one of its actions. See Stream Deck Actions in Spore Studio to define them.

Each key keeps its own server address. Only change it if Stream Deck runs on a different computer: then enter the Mycelian computer's address with port 5000, and allow that port through its firewall.

Check it worked

The keys show live labels from Mycelian, and the App Settings panel shows the installed version:

Press Toggle Alerts: the key flips to PAUSED and Mycelian stops playing alerts until you press it again. A Connector or Template Action key briefly adds a ✓ after a successful press.

If something goes wrong

The Mycelian actions do not show up in Stream Deck

Stream Deck only loads plugins at start. Quit it completely (not just the window) and open it again. Check that App Settings says Installed.

Install fails and asks me to quit Stream Deck

Stream Deck locks plugin files while it runs, so a reinstall cannot replace them. Quit the Stream Deck app completely (macOS: Stream Deck → Quit Stream Deck), click Reinstall Plugin, then open Stream Deck again.

"Plugin files were copied but version check failed."

The files are in place but Mycelian could not read the installed version yet. Restart Stream Deck, then open App Settings again to check.

"Plugin source files not found."

The plugin copy that ships with Mycelian (the sd_plugin folder) is missing. Reinstall Mycelian.

Test says "Connection failed — is Mycelian running?"

Mycelian is closed, or its overlay server could not start on port 5000. Check the Overlay Server item in the status footer. On macOS, AirPlay Receiver also uses port 5000; turn it off in System Settings → General → AirDrop & Handoff. See Connection Problems.

The Connector list is empty

Only connectors with the Stream Deck trigger are listed. Create or edit one in Connectors, save it, then click Refresh in the key settings.

Mycelian says a new Stream Deck plugin version is available

Mycelian was updated and carries a newer plugin. Go to SettingsApp Settings, click Reinstall Plugin, and restart Stream Deck. Your keys keep their settings.
