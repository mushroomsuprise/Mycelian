YouTube needs up to two things from the Google Cloud Console: an API key to watch channels for new uploads, and an OAuth client to read live chat, memberships and Super Chats. Set up the API key first. Live chat is optional.

After you connect, see YouTube Integration for chatbot variables, the playlist filter and how YouTube events map to alerts.

Before you start

  • You can sign in to the Google Cloud Console. A free account is enough.
  • You have the URL of every channel you want to watch, for example https://youtube.com/@YourChannel.
  • For live chat: Mycelian is open on this computer. Google sign-in returns to http://127.0.0.1:9974, which only works on the machine running Mycelian.

Part 1: API key for uploads

Create a project and turn on the YouTube API

  1. In the Google Cloud Console, create a project (or pick one) from the project menu at the top.
  2. Open YouTube Data API v3 in the API Library and click Enable.

Create an API key

Go to APIs & ServicesCredentials, click Create credentials and choose API key.

  1. Copy the key. It starts with AIza.
  2. Optional: under API restrictions, choose Restrict key and select only YouTube Data API v3.

Enter the key and your channels in Mycelian

Open SettingsYouTube.

  1. On the Channel lookups (API key) card, open API key and paste the key into YouTube Data API v3 key. The field is masked; the eye icon shows it. The tag changes from Needed to connect to Saved once it is saved.
  2. Under Channels to watch, type or paste a channel URL and press Enter or click Add. It joins the list; click its × (Remove channel) to remove it. These formats work: https://youtube.com/@Handle, https://youtube.com/channel/UC…, https://youtube.com/c/Name, https://youtube.com/user/Name. Paste several at once opens a Channel URLs, separated by | field that holds the same list as one line (url1|url2).
  3. Click Save in the header.
  4. Then click Test on the Channel lookups card. The {{icon:refresh}} icon (Check now) only re-reads the status.

Check the upload status

Test shows a "Testing the YouTube connection" notice that ends with "YouTube connection works", and the card fills in:

If only some channels work, the card and its pill show Partial with a count such as Partial (1/2 channels). Check the failing URL. "Couldn't reach YouTube" means the key or a URL is wrong, or the daily quota is used up.

Part 2: Live chat and alerts (optional)

Live chat needs an OAuth client from the same Google Cloud project. It lets Mycelian read your live chat, post chatbot replies, and turn memberships and Super Chats into alerts.

Set up the OAuth consent screen

  1. In the Cloud Console, open APIs & ServicesOAuth consent screen.
  2. Choose External. Fill in the app name (for example Mycelian), your support email and developer contact email.
  3. Under Test users (called Audience in newer consoles), add the Google account that owns your channel.

You do not need to publish or verify the app for personal use. Google will warn that the app is unverified when you sign in; that is expected for your own client.

Create an OAuth client ID

Go to APIs & ServicesCredentials, click Create credentials and choose OAuth client ID.

  1. Choose Web application. Desktop and other types do not accept this redirect URI.
  2. Under Authorized redirect URIs, click Add URI and enter http://127.0.0.1:9974 exactly: http, 127.0.0.1, port 9974, no trailing slash.

After Create, Google shows the Client ID (ends in .apps.googleusercontent.com) and Client secret (starts with GOCSPX-). Copy both.

Paste the client into Mycelian and connect

On SettingsYouTube, use the Live chat & alerts (Google sign-in) card at the top of the left column. Open OAuth client ID & secret and paste both values.

  1. Paste the OAuth Client ID and OAuth Client Secret (both masked). The Redirect URI box shows http://127.0.0.1:9974; its copy icon copies it.
  2. Read live chat and Process YouTube alerts are on by default. See YouTube Integration for what they do.
  3. Connect saves the client values and opens your browser. If either field is empty you see "Enter your Google OAuth Client ID and Client Secret first".

Approve access in Google

Sign in with the Google account that owns the channel. If Google says the app is not verified, click Continue. Pick your channel if asked, and allow access to manage your YouTube account; Mycelian needs it to read live chat and post chatbot replies.

The browser then shows "Authorization Successful!". Close the tab.

While Mycelian waits, the button reads Connecting.... Mycelian waits 5 minutes for you to approve. After that, the card's Live status shows Authorization timeout; click Connect again.

Check live status

Mycelian shows "YouTube live chat connected". The card shows your channel name with Offline, the header pill reads Live chat ready, and the button now reads Reconnect:

If something goes wrong

Google says "Error 400: redirect_uri_mismatch"

The OAuth client does not list the exact redirect URI, or it is not a Web application client. Edit the client, add http://127.0.0.1:9974 under Authorized redirect URIs, save, wait a few minutes, and click Connect again.

Google says "Access blocked" or "access_denied"

Your Google account is not a test user of the consent screen. Add it under Test users (or Audience) and try again.

Channel lookups say All Channels Failed

Check that the channel URLs are correct and the channels are public, that YouTube Data API v3 is enabled in the project, and that the API key's restrictions allow it.

Live status stays "Not authorized" or shows "OAuth credentials required"

Fill in both fields under OAuth client ID & secret, make sure they come from a Web application client, and finish the browser consent with the channel owner's account.

Live status says "OAuth server error"

Mycelian could not open port 9974 for the sign-in callback. Close whatever else is using it, or a second copy of Mycelian, and try again.

Live status stays Offline while I am streaming

Wait up to a minute after going live. Live streaming must be enabled on the channel, and the account you authorized must own the broadcast.

Chatbot replies do not post to YouTube

If you connected with an older version of Mycelian that asked for read-only access, click the {{icon:logout}} Disconnect icon on the live chat card, then Connect to grant the current permission.
