An alert is the picture, sound and text that plays in your alerts browser source when a viewer follows, subscribes, cheers, raids, donates or redeems a reward. You set up each alert on the Alerts tab.

How an alert plays

The Alerts tab

Each alert type has its own sub-tab. Each sub-tab is one card: the list of alerts on the left, and the alert you picked on the right. The header row changes per type; the settings below it are the same everywhere.

  1. One sub-tab per alert type. The number shows how many alerts it has.
  2. The alert list. Type in Search to filter it. New alert (New reward on Channel Points) starts a blank one. Each entry shows the alert's name, made from the amount, for example 100 Bits, 1-99 Bits, 3 Months or $5 Donation. RANGE marks a range alert and FALLBACK marks the Resub Fallback alert. Small icons show what the alert uses: sound, GIF or image, randomizer, text-to-speech. On Subscriptions, the Resub fallback switch sits at the bottom of the list.
  3. The alert name and what it triggers on. The Exact / Range switch picks one amount or a min to max range. Follows plays for every new follower. Channel Points has a Use as alert switch instead.
  4. Compact sections hold the settings, one per line. Hover the help_outline next to a label for help. See Configuring Alert Settings and Alert Media Configuration.
  5. Test Alert plays the alert as it is now, even unsaved. content_copy duplicates it. The delete Delete button only shows for a saved alert. Save stores it.

Which alert plays

For an event with an amount, Mycelian checks the alerts on that sub-tab in this order:

  1. Exact amount. A 500-bit cheer plays the 500 Bits alert if you have one.
  2. Range. Otherwise the first range that contains the amount, such as 100-999 Bits. Both ends of the range count.
  3. Fallback. Otherwise another alert of the same type. For resubs, the Resub Fallback alert is used first when the Resub fallback switch is on.

Cover every amount with ranges (for example 1-99, 100-999, 1000-1000000) so you always know which alert will play. Do not let ranges overlap: when two ranges contain the same amount, which one wins is not defined.

Turning alerts on and off

There is no on/off switch for a whole alert type on the Alerts tab. Use these instead:

WhereWhat it does
Source Settingsalerts: Enable Follow Alerts, Enable Bit Alerts, … Turns one alert type on or off in the alerts overlay. Enable Watch Streak Alerts is off by default.
SettingsTwitch: Process Twitch alertsStops all Twitch events from becoming alerts, but keeps the connection.
Activity Feed: Pause / MuteHolds the queue, or plays alerts without sound, until you click Resume or Unmute.
Channel Points: Use as alertPer reward. Off means the redemption is logged but no alert plays.

Tips

  • Keep frequent alerts short (3-5 seconds) and save long ones for big moments.
  • Click Test Alert before you go live. See Testing Your Alerts.
  • Use Duplicate (content_copy) to copy a finished alert, then change only its amount.
