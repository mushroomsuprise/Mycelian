An alert is the picture, sound and text that plays in your alerts browser source when a viewer follows, subscribes, cheers, raids, donates or redeems a reward. You set up each alert on the Alerts tab.

How an alert plays

The Alerts tab

Each alert type has its own sub-tab. The selector row at the top changes per type; the settings form below it is the same everywhere.

  1. One sub-tab per alert type.
  2. Select Alert lists the alerts you have saved for this type, plus + Create New Alert. Names are made from the amount, for example 100 Bits, 1-99 Bits, 3 Months or $5 Donation.
  3. Range Mode switches between one exact amount and a Min/Max range. Follows and Channel Points have no amount.
  4. Five sections hold the settings. See Configuring Alert Settings and Alert Media Configuration.
  5. Test Alert plays the form as it is now, even unsaved. Delete Alert only shows for a saved alert.

Which alert plays

For an event with an amount, Mycelian checks the alerts on that sub-tab in this order:

  1. Exact amount. A 500-bit cheer plays the 500 Bits alert if you have one.
  2. Range. Otherwise the first range that contains the amount, such as 100-999 Bits. Min and Max are both included.
  3. Fallback. Otherwise another alert of the same type. For resubs, the Resub Fallback alert is used first when its switch is on.

Cover every amount with ranges (for example 1-99, 100-999, 1000-1000000) so you always know which alert will play. Do not let ranges overlap: when two ranges contain the same amount, which one wins is not defined.

Turning alerts on and off

There is no on/off switch on the Alerts tab itself. Use these instead:

WhereWhat it does
Source Settingsalerts: Enable Follow Alerts, Enable Bit Alerts, … Turns one alert type on or off in the alerts overlay. Enable Watch Streak Alerts is off by default.
SettingsTwitch: Process Twitch alertsStops all Twitch events from becoming alerts, but keeps the connection.
Activity Feed: PAUSE ALERTS / MUTE ALERTSHolds the queue, or plays alerts without sound, until you click again.
Channel Points: Enable as AlertPer reward. Off means the redemption is logged but no alert plays.

Tips

  • Keep frequent alerts short (3-5 seconds) and save long ones for big moments.
  • Click Test Alert before you go live. See Testing Your Alerts.
  • Use Duplicate to copy a finished alert, then change only its amount.
