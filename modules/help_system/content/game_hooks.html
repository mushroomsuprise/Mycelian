Game Hooks let Mycelian read live data from a supported PC game and push it to browser overlays. Two games are supported: Final Fantasy VII (2013) on Windows, and Factorio on Windows, macOS and Linux.

The Game Hooks tab

Each game has a card with a switch. The card's border shows how the hook is doing. Switch the mock between platforms to see how unsupported games look.

  1. The switch turns the hook on or off. The OS marks show where the game is supported.
  2. Factorio's mod button: Install mod, Update mod when a newer version is bundled, or Mod installed (disabled) when it is current. The text beside it shows the installed version.
  3. A game that is not supported on this OS is dimmed and cannot be switched on.
  4. Nothing changes until you click Save. You see "Game Hooks saved".

When your Twitch category is Final Fantasy VII, Mycelian shows "Playing … on PC? Try the game hook out!" with a button that opens this tab.

Set up a game

Turn on the FF7 hook

Open SettingsGame Hooks, switch on Final Fantasy VII (2013) and click Save.

Start FF7

Run the English PC / Steam version on the same Windows PC. The card turns green once it attaches.

If Windows denies memory access, run Mycelian as Administrator.

Add the FF7 overlay

Add http://127.0.0.1:5000/ff7 as a browser source. See Setting Up Browser Sources in OBS.

Turn on the Factorio hook

Open SettingsGame Hooks, switch on Factorio and click Save.

Install the mod

Click Install mod on the Factorio card. It copies mycelian-stats into your Factorio mods folder and enables it.

Restart Factorio and load a save

If Factorio is running, quit it fully. Start it and load a save. The mod only loads at startup.

Add the Factorio overlay

Add http://127.0.0.1:5000/factorio as a browser source.

If the hook is on but no data arrives, Mycelian reports "Mycelian stats mod not detected — install it from Settings > Game Hooks". Use Install mod or Update mod and restart Factorio. The mod is read-only and does not change gameplay.

When a hook is off, its overlay still loads but receives a stub payload with disabled: true.

What is shown

About four times a second, while attached:

  • Party: names, levels, HP, max HP, MP, max MP, limit gauge, ATB. In battle these are live battle values; on the field they come from the in-memory save data.
  • Enemies (battle only): name, level, HP, MP, ATB.
  • Gil and play time.
  • Boss log: defeated bosses, newest first. Kept until you reset it from the overlay.
  • Menu colors: your in-game window colors, so the overlay panels can match.

The /factorio overlay is styled like the in-game Production and Electric Network windows. In Source Settings you can show, hide, rename and place each section on a grid, or stack them in a row or column.

  • Power: satisfaction, generation vs capacity, accumulator charge, producer and consumer lists, and a flow graph.
  • Production / Consumption: item rates (/m) over a time window you choose. Leave the item list blank to show the top items automatically.
  • Science: packs per minute, plus current research, progress, ETA and queue.
  • Planets: current surface, visited planets and space platforms (Space Age; transit shows as Nauvis -> Gleba).
  • Fluids (optional): fluid rates.
  • Stats (optional): rockets, evolution, pollution, kills.

Power, Production, Consumption and Fluids follow the planet you are on. Turn on cycle mode to rotate through visited planets; the four sections stay in sync.

Payload fields are under hooks.factorio: attached, paused, power, production, consumption, science, planets, misc. Item icons load from your local Factorio install (data/*/graphics/icons).

Crowd control (FF7)

A connector can change the game with a Game Hook (memory write) action. Each action targets one game (FF7 today) and one operation, with arguments as shown in the connector editor. If a connector has a Game Hook action and that hook is off or not attached, the whole connector is skipped. See Connector Actions.

EnemiesKill enemy, Kill all enemies, Damage enemy, Set enemy level, Set enemy stat (party stats plus speed, evade, def, mdef)

Many of these take an optional duration (for example duration_sec on menu rows) and restore the old value afterwards. Timed restores pause while the game is not attached. Battle-only actions fail with a short message if you are not in a battle.

Which changes survive a restart

Game speed, battle speed, ATB mode, menu rows, field menu access, world speed multiplier, menu colors and infinite items are saved under GameHooks/ff7_connector_overrides. They are applied again when the hook next attaches; timed ones use the time that was left. One-off inventory or stat writes are not saved.

Placeholders in action arguments

Use single braces with no spaces inside:

PlaceholderGives
{username}, {message}Who triggered it and their message
{message.word.1}Word 1 of the message
{message_after_conditions}The chat text after removing the trigger's message condition words
{message_after_word.1}, {message_after_conditions.word.2}Word N of that stripped text
{message_after_from_word.3}, {message_after_conditions.from_word.3}From word N to the end. Use it for multi-word values such as item names
{hooks.ff7.party.0.name}Live game data
{random_character}, {random_enemy}A random party member or enemy
{random_damage.1.9999}A random number in a range
{action1.quantity}Output of an earlier action in the same connector, by its number (Action #1 → action1). Fields include item_name, quantity, resolved_name, kind and error from Query inventory quantity

Older {{key}} forms still work and are converted.

Memory writes are powerful. Use them only on your own single-player game. Online services and anti-cheat systems are not a target for this feature.
