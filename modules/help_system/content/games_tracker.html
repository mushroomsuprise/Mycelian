Syncing runs on its own background threads, so the app stays responsive. The library is read again every few minutes (10 by default), and the game you're playing updates within a minute through the PSN and Steam connections.

The first import is silent

The first sync for an account reads your whole library without counting anything, so years of trophies don't flood Statistics or chat. From then on, each change is an event:

  • Unlock: a trophy or achievement was earned. PlayStation unlocks carry the grade.
  • Completed: a platinum, or every Steam achievement (a perfect game).
  • Started: a game showed up in the library for the first time.
  • Milestone: a game crossed one of your progress milestones (25, 50 and 75% by default).

Connecting a different account starts a new silent import for that platform. Reset baseline under Tracker options does the same for the current accounts.

The Games Tracker tab

Overview and library

The header pills show each platform's state: game count, importing n / total during a sync, or not connected. Sync now reads both libraries again. Below the overview, search, filter (All, PlayStation, Steam), status (In progress, Completed, Hidden) and sort the cards. Each card shows the cover, platform, completion and trophy counts.

Game settings

The {{icon:settings}} button on a card opens its settings:

  • Display title: what overlays, chat and connectors show.
  • NPWR ID and NP Title ID (PlayStation): which trophy list the game's presence maps to. Re-resolve NPWR from Title ID asks PlayStation for the right NPWR ID. This replaces the game cache that used to be on the PSN tab.
  • Hide from tracker: the game keeps syncing but leaves the grid and the totals.
  • Remove from cache: forgets the game until the next sync finds it again.

Tracker options

Turn each platform on or off, choose whether changes count in Statistics and fire chatbot and connector events, and set the sync interval, how long cover art is kept (7 days by default; covers that failed are retried after 6 hours) and the progress milestones. Clear covers downloads all cover art again.

Export image

Export image (or Export card in a game's settings) makes a PNG in your theme colors, like the Statistics highlights image:

  • Library recap: headline tiles, a grid of games, the trophy cabinet and recent unlocks.
  • Game spotlight: one game's cover, progress, grade breakdown, trophy groups and recent unlocks.

Pick a layout (Wide 16:9, Portrait 4:5 or Square 1:1), a title, platforms, a period, which sections and tiles to show, and how the grid picks games. Images are saved to the exports folder in the Mycelian data folder. Your choices are remembered.
