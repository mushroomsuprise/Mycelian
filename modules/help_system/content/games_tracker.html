The Games Tracker keeps every PlayStation and Steam game you have played, with trophy and achievement progress and cover art. Changes after the first import reach Statistics, chatbot events and connectors.

Syncing runs on its own background threads, so the app stays responsive. The library is checked again every few minutes (10 by default), and the game you're playing updates within about 15 seconds through the PSN and Steam connections.

To keep requests to PlayStation and Steam low, a routine check reads only the recently played part of the library (usually one request), and the whole library is read on Sync now and every 6 hours. Trophy and achievement names, icons and group details are read once per game and kept; after that each check asks only what you've earned. Settings → PSN, Steam and Games Tracker show how many requests Mycelian made in the last hour and today, with a live graph of requests per minute over the last hour (hover a column for its exact numbers). If PlayStation or Steam asks Mycelian to slow down, it pauses for the time they ask and keeps showing the last data.

The first import is silent

The first sync for an account reads your whole library without counting anything, so years of trophies don't flood Statistics or chat. From then on, each change is an event:

  • Unlock: a trophy or achievement was earned. PlayStation unlocks carry the grade.
  • Completed: a platinum, or every Steam achievement (a perfect game).
  • Started: a game showed up in the library for the first time.
  • Milestone: a game crossed one of your progress milestones (25, 50 and 75% by default).

Connecting a different account starts a new silent import for that platform. Reset baseline in Settings → Games Tracker does the same for the current accounts.

The Games Tracker tab

Overview and library

The header pills show each platform's state: game count, importing n / total during a sync, or not connected. Sync now reads both libraries again, and Options opens Settings → Games Tracker. Below the overview, search, filter (All, PlayStation, Steam), status (In progress, Not started, Completed, Has goals, No goals, Hidden) and sort the cards (recently played, most or least complete, name A–Z or Z–A, most trophies, most playtime, recently added). Each card shows the cover, platform, completion, trophy counts and, when the game has goals, its first three goals with a bar each. Your filter and sort choices are remembered.

Goals

Give any game as many goals as you like from its settings ({{icon:settings}} on the card), under Goals. Each goal shows on the card with its own bar and percent.

TypeDone when
ManualYou count it yourself with {{icon:remove}} / {{icon:add}}, for example Get all endings, 2 of 5. A count of 1 works like a checkbox.
Platinum / 100%You earn the platinum (PlayStation) or unlock every achievement (Steam).
Trophies / achievementsYou have earned N of them in the game. On PlayStation you can count one grade only, for example 10 gold trophies.
Completion %The game's completion reaches the percent you set.
Specific trophy / achievementThe one you pick from the game's list unlocks.

Goals change straight away; there's no Save. Use {{icon:edit}} to rename a goal or change its target, and the arrows to reorder. Automatic goals follow the game, so a goal that is already met when you add it starts out done, without an event. Goals stay with a game when you switch accounts, and go away when you remove the game.

Speedrun info

Under Speedrun info in a game's settings, link one or more LiveSplit split files (.lss), one per category you run. Type a Category (for example Any%), or leave it empty to use the category saved in the file, then click Choose split file…. For each file the card and the Game panel show the category, your personal best and how many attempts you've made (plus how many you finished).

  • Live: Mycelian notices when LiveSplit saves the file and reads it again a few seconds later.
  • Read-only, never in LiveSplit's way: the file is only ever read, never changed or locked. Mycelian checks for changes without opening it, reads it only after a save has finished, and closes it within milliseconds. If LiveSplit saves at that exact moment, Windows makes the save wait for Mycelian to close (a few milliseconds) instead of failing, and Mycelian reads again on its next check.
  • Times: {{icon:edit}} on a split file sets Times: Automatic uses real time, or game time when the file only has game times. You can also rename the category or point it at another file there.

Backlog

Games with goals sit in their own Backlog section above the library, with their own search, platform filter, goal filter (All goals, Goals open, Goals complete) and sort (closest to done, least progress, recently played, name, most goals, newest goal). A game stays in the backlog after all its goals are done; filter to Goals open to hide those. Turn off Keep games with goals in a Backlog section in Settings → Games Tracker to keep them in the library with everything else.

Game settings

The {{icon:settings}} button on a card opens its settings:

  • Display title: what overlays, chat and connectors show.
  • NPWR ID and NP Title ID (PlayStation): which trophy list the game's presence maps to. Re-resolve NPWR from Title ID asks PlayStation for the right NPWR ID. This replaces the game cache that used to be on the PSN tab.
  • Hide from tracker: the game keeps syncing but leaves the grid and the totals.
  • Remove from cache: forgets the game until the next sync finds it again.

Settings → Games Tracker

The tracker's options have their own Settings tab, with Save and Discard like the other Settings tabs. Turn each platform on or off, choose whether changes count in Statistics and fire chatbot and connector events, and set the sync interval, how long cover art is kept (30 days by default; covers that failed are retried after 6 hours, or straight away with Sync now) and the progress milestones. Clear covers downloads all cover art again, and Reset baseline makes current progress the new starting point.

Export

Export in the tab header saves an image or a spreadsheet; pick one under Format. Export card in a game's settings goes straight to that game's image.

Image (PNG)

A picture in your theme colors, like the Statistics highlights image:

  • Library recap: headline tiles, a grid of games, the trophy cabinet and recent unlocks.
  • Game spotlight: one game's cover, progress, grade breakdown, trophy groups and recent unlocks.

Pick a layout (Wide 16:9, Portrait 4:5 or Square 1:1), a title, platforms, a period, which sections and tiles to show, and how the grid picks games. Images are saved to the exports folder in the Mycelian data folder. Your choices are remembered.

Spreadsheet (XLSX)

Your library as an Excel workbook that also opens in Numbers, LibreOffice and Google Sheets:

  • Games: one row per game with completion, earned and total, PlayStation trophies by grade, Steam playtime, last played and first seen dates, and the NPWR / App ID and NP Title ID. Numbers and dates are real values, and the header row has filters.
  • Summary: the totals, the same ones as the overview.
  • Unlock history (optional): every unlock, completion, new game and milestone since the first import, with grade and rarity.

Choose the platforms and whether hidden games are listed (they get a Hidden column and are never counted in the summary). The file is saved to the same exports folder as games_library_<date>.xlsx.

Chat commands for any game

In a chatbot command, add the A game's progress lookup (group Games). It searches your library for the text after the command, forgiving case, ™ symbols, missing spaces and small typos. Left blank, it uses your most recently played game. Hidden games are left out.

CommandReplyFallback text
!progress{game_title}: {game_progress}% ({game_trophies})I haven't played {game_query} yet.
!haveyouplayedYes! {game_title} on {game_console}, {game_progress}% done, last played {game_last_played}.Nope, I haven't played {game_query}.

Other variables: {game_played} (yes/no), {game_earned}, {game_total}, {game_completed} (yes/no), {game_platform} and {game_playtime} (Steam). Without fallback text, a game that isn't in the library still posts the normal reply, with {game_played} set to no. The lookup's Platform option limits it to PlayStation or Steam.

Goals too: {game_goals} lists them with progress (Get all endings 2/5 (40%), Platinum (78%)), plus {game_goals_done}, {game_goals_total}, {game_goal_next} (the furthest along that isn't done) and {game_goal_next_progress}. For one goal by position use {game_goal_1_name}, {game_goal_1_progress}, {game_goal_1_current}, {game_goal_1_target} and {game_goal_1_done} (1 to 10). For example !goals → {game_title} goals: {game_goals}.

Counting a goal from chat

Make a connector with a Chat message trigger and the condition message starts with !ending, then add the Update game goal action: pick the game (or leave it blank for the last played one), type part of the goal's name, and choose Count up. Only manual goals can be changed; automatic ones follow the game.

On a Stream Deck, the Game Goal key does the same with a press: pick the game, the manual goal, Add or Subtract and the amount. The key shows the goal's count.

Game panel in Spore Studio

The Game panel block (group Data) shows a game card like the one in the tracker: cover, completion bar, trophies or achievements and its goals. Under Show, choose:

  • selected: the games you tick under Games. Pick several and the panel rotates between them, in the order you picked them, every Rotate every seconds.
  • backlog: every game with goals, open ones first.
  • current: the game you played last.

The panel updates live as you earn trophies or count goals; you don't need a Data feed. Switches choose what shows (cover, trophies, goals, speedrun info, last played, page dots) and how many goals are listed. With Auto size on (the default), everything grows to fill the block: a bigger block, or fewer rows shown, means bigger text. When it rotates, every game is sized like the fullest one so the text doesn't jump. Turn it off to set the size yourself with Size. The editor's preview is drawn by the same code as the overlay, using your real games.

PlayStation trophy lists must be visible to the account Mycelian signs in with. Steam achievements need a public profile and game details.
