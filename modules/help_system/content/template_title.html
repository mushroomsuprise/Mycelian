The Title overlay shows your current Twitch category, or a custom message, as plain text. The text fills the whole browser source and scales itself to fit, so the source's size in OBS decides how it looks.

Set it up

Add the browser source

In OBS, add a Browser source with the URL http://127.0.0.1:5000/title. Or use the OBS button on the Title card in SettingsAbout.

Type Width and Height for the text area

This is the most important step. The overlay has no inner text box; the text uses the entire source. Set Width and Height in the source properties to the region where the text should appear. A lower-third strip is typically about 900 × 120. Tall, narrow or odd shapes work too.

Move it into place

Drag the source to its spot on the canvas, but do not resize it with the corner handles. Change Width and Height in the properties instead.

Check the category

The overlay should show your current category within a few seconds. If it still says Stream Title, see Troubleshooting at the end of this page.

Why the source size matters

If you change Width or Height while the source is running, the text re-fits right away. You do not need to refresh.

Text scaling

Auto Fit Text To Source (on by default) shrinks the text until it fits inside the source. Max Font Size (default 60) is the ceiling: text is drawn at that size when it fits, and only ever scales down. Min Font Size (default 12) is the floor.

Text Wrapping decides how it shrinks:

Text WrappingBehaviorUse for
wrap (default)Long text breaks onto more lines, then shrinks to fit the heightRoughly square areas
nowrapText always stays on one line and shrinks to fit the widthThin horizontal strips
  • If text is clipped, the source is too small for your Min Font Size. Make the source bigger rather than lowering Min Font Size.
  • Turn Auto Fit off to draw at exactly Max Font Size. Long category names will then overflow and be cut off.
  • Line Height only matters with wrap when the text uses more than one line.

Placement

Because the text fills the source, placement is just alignment inside it. There are no position or size settings in Source Settings; the OBS source handles that.

  • Horizontal Alignment: flex-start (left), center, flex-end (right).
  • Vertical Alignment: flex-start (top), center (middle), flex-end (bottom).
  • Edge Padding: a blank margin kept clear inside every edge. Auto Fit treats it as unusable space, so raising it makes the text smaller.

Keeping the category up to date

Category Data Source (in the Stream Data group) controls how the overlay learns your category:

ModeBehavior
api_and_eventsubRecommended, default. Reads the Twitch API on load and on a timer, and accepts live push updates.
eventsub_onlyLive push updates only. It will not fill itself in after a source refresh.
api_onlyTimer polling only. Ignores push updates.

Live push updates (EventSub) only fire at the moment you change category, so they can never tell the overlay what your category already is. That is why api_and_eventsub is the default: the API read fills in the current value on load, and the timer is a safety net if push updates stop.

API Refresh Interval (seconds) sets how often the safety-net read happens. The default is 60; values below 15 are treated as 15. Set it to 0 to read only on source load and when you press Refresh in Source Controls. It is ignored with eventsub_only.

Custom titles and live controls

Turn Show Category off to show the Custom Title text instead. Category Prefix and Category Suffix add text around the category (for example Now playing: ) while Show Category is on.

During the stream, use the Title Controls card in Source Controls:

  1. Show Category changes the same setting as in Source Settings and is saved, so it survives a source refresh.
  2. Text you type here is sent to the overlay as you type. It only shows while Show Category is off; typing does not turn Show Category off for you.
  3. Clear (Clear Custom Title) empties the text and turns Show Category back on. Refresh (Refresh Category) reads the category from Twitch right now.

Connectors can also set a temporary title with the Change title action. See Connector Actions.

Troubleshooting

The overlay says "Stream Title" and never changes

Twitch is not connected yet, or the category has not been read. Check the Twitch connection (Twitch Setup), then press Refresh on Title Controls. The overlay keeps retrying while it waits for Twitch to authenticate.

The category is stale after I switched games

Check that Category Data Source is not api_only with a long refresh interval. With api_and_eventsub the change appears immediately.

Nothing shows at all

Show Category is probably off with an empty Custom Title, which draws a blank overlay by design. Press Clear on Title Controls to switch back to the category.

The text is tiny

The browser source is probably much larger than it looks, or Edge Padding is high. Text scales to the source size, not the canvas. Check Width and Height in the source properties.

The text is blurry

The source was resized with the mouse handles. Right-click it in OBS, choose Transform → Reset Transform, then set Width and Height in its properties.
