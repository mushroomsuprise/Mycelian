The Settings tab holds service connections, the theme and app-wide options. Each sub-tab has its own Discard and Save (or Apply) buttons; nothing changes until you save.

Find your way around

Settings has fourteen sub-tabs. Use the Jump to box above them to type a tab name instead of hunting for it. Click a sub-tab in the mock to see what it holds.

What each sub-tab is for

Service connections

Twitch, OBS, PSN, Spotify, YouTube, Streamlabs, StreamElements and Discord each have a tab with a status area, credential fields and their own options. Setup steps for each are in Connection Guides. Donation alerts themselves are set up on the Alerts tab under Donations; see Alert System Overview.

Game Hooks

Turns on live data from supported PC games for browser overlays and connector actions. Each game has a card with a switch and a status line (Off, Waiting for the game, Attached · reading live data or Problem: …); the header pill sums them up. Click Save to apply the switches. See Game Hooks.

Database

Chooses where Mycelian keeps settings, alerts and history: a Local file (SQLite, mycelian.db by default), Firebase or MongoDB. The Connection card shows the database in use with Test; Save checks a new connection before switching. Under Your data, Database Explorer opens the raw stored items and Move my data (Migrate…) copies everything to another database and switches to it. See Database and Database Explorer.

Change the storage type only if you know you need to. Switching does not copy anything; use Move my data so your data comes with you.

Statistics

A dashboard for your stream activity: headline numbers with change versus the previous period, activity over time, when your community is active, leaderboards, all-time totals, a viewer lookup and a shareable highlights image. See Statistics.

Theme

Pick a theme from the drop-down; each option shows a few of its colors. The preview on the left draws the app in that theme, so you can see it before you click Apply. The pill next to the drop-down says Current theme, Previewing or Unsaved colors; Discard goes back to your current theme.

To change a color, click its swatch under Colors. The color picker opens next to it, titled with the color's name, and the preview follows as you pick. Done (or a click outside the picker) keeps the color; Cancel or Esc puts the old one back. Theme colors are solid, without gradients. A color that already has transparency opens with the opacity controls and keeps its transparency when you pick a new one. The box below the swatches shows the color's name, value and what it colors, and edited colors get a dot. The undo, redo and reset buttons next to Colors work on your edits. Readability shows the contrast of text, hints and button text against their backgrounds: green is easy to read, amber is low and red is hard to read.

Apply saves color edits into the selected theme. The built-in Dark and Light themes cannot be changed or deleted: edit them, then use Save as to keep the colors as a new theme. These help pages use the same theme colors.

The Pop-up notifications panel under the preview sets how pop-ups look in this theme: style (Accent bar, Icon chip, Minimal, Tinted or Glass), corners, shadow, density and the timer bar, with a live sample. It is saved with the theme like the colors. See Notifications.

About

  • Header: version, build (click to copy) and build date, with Check for updates and What's new. The status line under it shows the result of the last check this session; when a newer version is found it offers Update now.
  • Health check: recent errors from mycelian.log, newest first, with where they came from and how often. Click one to see the full message and copy it. The clipboard button copies a diagnostics report (version, system and these errors) to paste into a bug report; the folder button opens the logs folder.
  • Browser source URLs: every overlay URL you can add to OBS. Type in Filter sources to narrow the list, click a URL to copy it, or use the OBS button to add it straight to a scene. See Setting Up Browser Sources in OBS.

Saving changes

  • Each sub-tab saves separately. Click Save on the tab you changed. On the service tabs (Twitch through Discord), Game Hooks and Database, Discard and Save are in the tab's header, next to the connection pills, and an Unsaved changes tag shows while there is something to save.
  • Discard puts the tab back to its last saved values. It is greyed out while there is nothing to discard.
  • If you leave Settings with unsaved changes, Mycelian asks: "You have unsaved changes in Settings. Save them before leaving?"

Where settings are stored

  • Settings, alerts and history: the database chosen on the Database tab.
  • Service API credentials: stored encrypted in api_credentials.json.
  • Database connection: config.json.
  • Template settings: templates/template_configs/*.json, edited on the Source Settings tab.

To back up, close Mycelian and copy these files and your database file to a safe place.
