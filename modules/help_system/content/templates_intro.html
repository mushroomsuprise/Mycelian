Templates are the overlays you show on stream. Each one is a small web page that Mycelian serves on this computer. You add it to OBS as a Browser Source, and it updates live as alerts, chat and other events arrive.

How a template works

Every template is made of up to three files, all named after the template:

FileWhat it holds
templates/<name>.htmlThe overlay page itself (HTML, CSS and JavaScript). Its file name is the URL path.
templates/template_configs/<name>.jsonIts settings: colors, fonts, sizes, timings. You edit these in Source Settings. It can also define live controls for Source Controls.
templates/_spore/<name>.spore.jsonOnly for templates built in Spore Studio. The editable design.

When OBS loads the URL, Mycelian fills the page with the saved settings and the page connects back to Mycelian over Socket.IO to receive events. See WebSocket Events.

Template URLs

Every template is served at http://127.0.0.1:5000/<name>, where <name> is the HTML file name without .html. The full, current list is in SettingsAbout under Browser source URLs. Each card has a copy button and an Add to OBS button.

  1. Copies the URL. The list shows 127.0.0.1; localhost works the same on this computer.
  2. Add to OBS creates the browser source for you. It needs OBS WebSocket connected and asks for Scene, Source name, Width and Height.

Add a template to OBS

Copy the URL

Open SettingsAbout and click the copy button on the template's card. Or click the OBS button to let Mycelian create the source and skip to the last step.

Create a Browser Source in OBS

In OBS, click + under Sources, choose Browser, name it, and paste the URL.

Set Width and Height

Type the size into the source properties. Do not stretch the source with the mouse handles; that blurs the page. Most overlays expect your canvas size (for example 1920 × 1080). The Title overlay is different; see Title Overlay.

Position it and test

Move the source into place, then trigger a test alert or event. See Testing Alerts and OBS Browser Source Setup.

Text placeholders

Text settings in alert-style templates can contain placeholders in braces, which are replaced with event data. The Alerts template uses, for example:

PlaceholderReplaced with
{tier}Sub tier (1, 2 or 3)
{resub_month}Months subscribed
{gift_qty}Number of gifted subs
{recipient}Gift recipient
{amt_cheered}Bits cheered
{streak_count}Watch-streak length
{raider_count}Viewers in a raid
{title} / {point_cost}Channel point reward name and cost

The username is shown on its own line, so it is not a placeholder in these texts. Each setting's description in Source Settings lists what it accepts.

Good habits

  • Set browser source Width and Height to the area the overlay needs, not more.
  • Keep Shutdown source when not visible on for overlays you only show in some scenes.
  • Check text is readable at your stream resolution, over real gameplay.
  • Test every overlay in the Source Settings preview or with a test alert before going live.

Overlays stop updating if Mycelian is closed. Start Mycelian before OBS, or see OBS Browser Source Setup for what happens when OBS opens first.
