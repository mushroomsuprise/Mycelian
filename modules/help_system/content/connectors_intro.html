A connector is a rule: when something happens, check a few details, then do one or more things. For example: when someone raids with 10 or more viewers, post a welcome in chat and switch an OBS scene.

{{icon:schedule}} About 5 minutes for a first connector {{icon:place}} Connectors

How a connector works

  • Triggers: Twitch, YouTube, donations, OBS, hotkeys, Stream Deck buttons, or any event.
  • Conditions: filters such as Amount ≥ 500 or Message ^ !lurk.
  • Actions: chat messages, announcements, banners, Discord posts, alerts, overlay controls, OBS, key presses, audio, files, commands, web requests and game hooks.

Event details flow into the actions as placeholders. {username} in a chat message becomes the name of the person who raided, cheered or typed.

The Connectors tab

  1. Search filters by connector name, description, trigger name and action names. New Connector opens the editor. Refresh reloads the list.
  2. The switch enables or disables the connector. Then: Edit, Duplicate, Test ({{icon:play_arrow}}) and Delete.
  3. The card shows the trigger, each condition, and each action as coloured chips.
  4. How many times the connector has fired, and when it last fired (Never triggered until the first time).
  5. A folder. Click its preview area to open it in a floating panel. Toggle all enables or disables every connector inside.

With no connectors yet, the tab shows No connectors created yet and a Create First Connector button instead of the grid.

Create a connector

Open the editor

Click New Connector (or Create First Connector). The Create New Connector dialog opens.

Name it

Under Basic Information, type a Connector Name. It is required. Description (optional) shows under the name on the card.

Pick a trigger

In Trigger Configuration, choose a Trigger Type. Hotkey and Stream Deck triggers show extra settings below it. See Connector Triggers.

Add conditions if you need them

Click Add Condition and set Field, Operator and Value. Skip this step to run on every event of that type. See Connector Conditions.

Add actions

In Actions Configuration, click Add Action and choose an Action Type. Add more actions for a sequence; from Action #2 on, Delay (s) sets the wait after the previous action. See Connector Actions.

Save and test

Click Create Connector. New connectors start enabled. Click {{icon:play_arrow}} Test on the card to try it with sample data (see Testing a connector below).

The connector editor

  1. Connector Name is required. Saving without it shows Connector name is required.
  2. Pick the trigger before adding conditions. Each trigger offers its own condition fields.
  3. Each condition has a {{icon:delete}} button to remove it.
  4. Actions after the first have Delay (s): seconds to wait after the previous action finishes.
  5. Saving needs a trigger and at least one action, or you see Trigger type is required or At least one action is required.

If you click Cancel or {{icon:close}} after changing something, Mycelian asks Close this connector without saving? Your edits will be lost. Choose Stay or Discard.

Folders

  • Create a folder: drag one connector card onto another. Both go into a new folder and Mycelian asks you to Name this folder.
  • Add to a folder: drag a card onto the folder tile.
  • Take one out: open the folder, then drag the card onto the strip that says Drop a connector here to move it to the main grid.
  • Toggle all on the folder enables or disables every connector inside. It shows a mixed state when some are on and some off.
  • {{icon:delete}} on a folder offers Delete folder only — keep connectors or Delete folder and all connectors inside.

Testing a connector

{{icon:play_arrow}} Test sends a fake event to the connector. The sample user is TestUser. Conditions are checked as usual, and the actions really run: chat messages are posted, OBS switches scenes, commands execute.

Test always says "did not trigger"
  • Your conditions do not match the sample values above (for example Amount ≥ 500 against the sample 100 bits).
  • The connector is disabled. Test respects the switch.
  • There is no sample event for Twitch Resubscription, Twitch Gift Sub, Twitch Raid, Channel Points, Twitch Stream Online or Twitch Stream Offline, so Test cannot fire them. Use the real event, or temporarily switch the trigger to one that has sample data.
  • A Hotkey connector only matches the sample if its combination is ctrl+f12 with Global hotkey on.

Tips

  • Start with one trigger and one action. Add conditions and more actions once it works.
  • Use conditions to stop a connector firing on every chat line or every tiny cheer.
  • Several connectors can share a trigger. Each one checks its own conditions.
  • Connectors with a Game Hook action are skipped while that game hook is off or not attached.
