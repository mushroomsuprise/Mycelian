A connector is a rule: when something happens, check a few details, then do one or more things. For example: when someone raids with 10 or more viewers, post a welcome in chat and switch an OBS scene.

{{icon:schedule}} About 5 minutes for a first connector {{icon:place}} Connectors

How a connector works

  • Triggers: Twitch, YouTube, tips, OBS, hotkeys, Stream Deck buttons, webhooks, timers, set times, or any event.
  • Conditions: filters such as Bits at least (≥) 500 or Message first word is !lurk.
  • Actions: chat messages, announcements, banners, Discord posts, alerts, overlay controls, OBS, key presses, volume, files, commands, web requests and game hooks.

Details of the event flow into the actions as variables. {username} in a chat message becomes the name of the person who raided, cheered or typed. The editor lists every variable you can use and shows a live preview with example values.

The Connectors tab

  1. Search filters by connector name, description, trigger name and action names. All / On / Off narrow the list further and show how many are in each. {{icon:refresh}} reloads the list. New connector opens the editor.
  2. What the connector does: When is the trigger, If lists the conditions (only shown when there are some), Then lists the actions. Long lists end in +N more. The icon at the top of the card shows the trigger's service.
  3. How many times the connector has run, and how long ago it last ran (hover for the exact time; Never run until the first time). Then {{icon:play_arrow}} Test, {{icon:edit}} Edit (double-clicking the name also edits) and {{icon:more_horiz}}, which holds Duplicate and Delete.
  4. A folder. It lists the connectors inside, with a green dot for each one that is on. Click the list or Open to open it in a floating window. The switch turns every connector inside on or off.

With no connectors yet, the tab shows No connectors yet and a Create your first connector button instead of the grid.

Create a connector

Open the editor

Click New connector (or Create your first connector). The editor opens with three steps down the left: When · Trigger, If · Conditions and Then · Actions.

Name it

Click Name this connector at the top and type a name. Add a short description (optional) shows under the name on the card. The On switch next to it decides whether the connector runs once saved.

Pick a trigger

A new connector opens on Choose a trigger. Click one, or type in Search triggers. Hotkey, timer, set-time and webhook triggers show a few settings under the trigger. See Connector Triggers.

Add conditions if you need them

Click Add condition and set Field, Is and Value. Skip this step to run on every event of that type. See Connector Conditions.

Add actions

Click Add action and pick one from the list. Fill in its fields; the { } button on a text field inserts a variable such as {username}. Add more actions for a sequence. See Connector Actions.

Save and test

The bottom left says Ready to save, or names the first thing still missing. Click Create connector, or Save & test to save and run it once with sample data (see Testing a connector below).

The connector editor

  1. The name (required) and a short description. The On switch turns the connector on or off when you save. {{icon:close}} closes the editor.
  2. The trigger, with a one-line hint. Cooldown ignores new events for that many seconds after the connector runs. Change opens the trigger list again; conditions that don't fit the new trigger are removed.
  3. Conditions as rows of Field, Is and Value. The AND/OR pill joins a row to the one above, Aa ignores upper and lower case, and the line underneath says in plain English when the connector runs.
  4. Each action is a numbered card. The header shows what it does, filled in with example values. On the right: a switch to skip the action without deleting it, {{icon:arrow_upward}} {{icon:arrow_downward}} to reorder, {{icon:content_copy}} duplicate, {{icon:delete}} remove, and {{icon:expand_less}} to fold the card. Click the title to open or fold it.
  5. Fields that accept variables have a { } button, and a preview line shows the text with example values. Every action, the first one too, has Wait … seconds before this action runs; a folded card shows it as wait 2 s.
  6. Variables lists everything the trigger gives you, with example values. Click one to insert it where your cursor was. The panel is hidden when the window is narrow; use the { } button instead.
  7. The status says Ready to save or names the first problem, such as Name this connector., Choose a trigger. or Action 1: Message is empty. Save & test saves and runs the connector once with sample data.

If you try to save with something missing, Mycelian shows the first problem and opens the action cards that need attention. If you close the editor with unsaved changes, it asks Close this connector without saving? Your edits will be lost. Choose Keep editing or Discard.

Folders

  • Create a folder: drag one connector card onto another. Both go into a new folder and Mycelian asks you to Name this folder.
  • Add to a folder: drag a card onto the folder tile.
  • Take one out: open the folder and start dragging the card. A strip appears above the grid that says Drop here to take the connector out of its folder; drop it there.
  • The switch on the folder turns every connector inside on or off. It shows an in-between state when some are on and some off.
  • {{icon:more_horiz}} on a folder has Rename folder and Delete folder…, which offers Delete folder only — keep connectors or Delete folder and all connectors inside.

Testing a connector

{{icon:play_arrow}} Test on a card, or Save & test in the editor, sends the connector a realistic sample event for its trigger: a 100-bit cheer, a raid of 42 viewers, a $5 tip and so on. Conditions are checked as usual, and the actions really run: chat messages are posted, OBS switches scenes, commands execute.

Test says nothing ran
  • Your conditions do not match the sample values above (for example Bits at least (≥) 500 against the sample 100 bits).
  • The connector is off. Test then says Turn the connector on to test it.
  • The Cooldown from the last run has not finished yet.
  • Every action failed, for example because OBS or the chatbot is not connected. Check the log.
  • The connector has a Game hook action and that game hook is off or not attached.

Tips

  • Start with one trigger and one action. Add conditions and more actions once it works.
  • Use conditions to stop a connector firing on every chat line or every tiny cheer, and Cooldown to stop it firing again too soon.
  • Several connectors can share a trigger. Each one checks its own conditions.
  • Connectors with a Game hook action are skipped while that game hook is off or not attached.
