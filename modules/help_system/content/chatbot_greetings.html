The chatbot can welcome viewers the first time they chat. Everyone gets the greeting for everyone else. Regulars you pick can get a personal greeting instead.

How greetings work

  • A greeting is sent on a viewer's first Twitch chat message, including a !command.
  • Each viewer is greeted once every 24 hours by default. Mycelian keeps a list of who it has greeted and starts over when that time has passed. You can pick anything from an hour to a week.
  • A viewer with a personal greeting gets that one while Personal greetings is on. Everyone else, and those viewers too when personal greetings are off, gets the greeting for everyone else, if that is on.
  • Greetings post in Twitch chat as the chatbot account. YouTube chat is not greeted.

The Greetings tab

  1. The greeting for everyone else, as it would look. The switch turns it on or off; when off, the banner says Off: viewers without their own greeting aren't greeted. Edit opens its dialog.
  2. How often a viewer can be greeted: every hour, 3, 6, 12 or 24 hours, 2 days or a week.
  3. How many viewers have been greeted since the list last started over. Greet everyone again asks Greet everyone again?, then forgets who has been greeted, so every viewer is greeted the next time they chat.
  4. Turns all personal greetings on or off. While off, those viewers get the greeting for everyone else.
  5. A personal greeting: the viewer's name, their Twitch login, and the switch for this one greeting. A card that is off has a grey stripe.
  6. When they were last greeted, or Not greeted yet. {{icon:restart_alt}} Greet again the next time they chat, {{icon:edit}} Edit, and {{icon:more_horiz}} → Delete…, which asks Delete Night_Owl's greeting? They'll get the greeting for everyone else instead.

The search box matches the viewer's name or the greeting text. With no personal greetings yet, the tab shows No personal greetings yet and an Add a greeting button.

The greeting for everyone else

Click Edit on the Everyone else banner.

  • Type the greeting. The { } button inserts a variable, and the preview shows it with sample values.
  • Greet each viewer once every takes any whole number of hours, 1 or more. It is the same setting as the menu on the tab.
  • Greet everyone else is the banner's switch.

Changes apply when you click Save. The greeting can't be empty (Write the greeting.); turn the switch off instead if you only want personal greetings.

Give a viewer a personal greeting

Open New greeting

Click New greeting on the Greetings tab (or Add a greeting when the list is empty).

Type the viewer's Twitch name

Type their login in Twitch viewer; the @ is optional. Mycelian checks it with Twitch as you type and shows Found Night_Owl on Twitch. It saves the account's ID, so the greeting keeps working if the viewer changes their name.

Other messages: Couldn't find … on Twitch, That isn't a Twitch name, Twitch isn't connected (connect it in Twitch Setup) and Night_Owl already has a greeting (each viewer can have one; edit that card instead).

Write the greeting and save

Type the greeting. {username} becomes their name, and the { } button inserts any other variable. Leave Greeting on on and click Add greeting. The button stays greyed out until the name was found and the greeting has text.

Edit on a card opens the same dialog, titled Night_Owl's greeting. The name can't be changed there; to greet a different viewer, add a new greeting. Edit also has a Delete button.

Variables in greetings

Both kinds of greeting use the same variables as command replies, and the { } menu lists them with example values:

  • {username} (display name), {user_login} (login name) and {user_id} (Twitch ID) of the viewer being greeted.
  • Date and time, such as {time:%-I:%M %p} for 7:42 PM, statistics, quotes and your custom variables.

Words typed after a command and Twitch lookups are not available, because a greeting is not a command. A viewer's name is always inserted as plain text, so a name with braces in it is never treated as a variable. See Chatbot Variables for the full list.

Questions

Greetings are not sending
  • Check that the Everyone else switch or Personal greetings is on.
  • Check that Twitch is connected and the chatbot account can chat. See Twitch Setup.
  • The viewer may already have been greeted. Use {{icon:restart_alt}} on their card, or Greet everyone again, to test.
Too many greetings in a busy chat

Set Greet each viewer once every to week so regulars are greeted less often. Or turn off Everyone else and keep personal greetings for a few regulars.

"Twitch isn't connected" when adding a greeting

Mycelian needs Twitch to look up the viewer's account. Connect Twitch first, then type the name again.
