The chatbot can welcome viewers when they send their first chat message. Everyone gets the default greeting. Viewers you pick can get their own custom greeting instead.

How greetings work

  • A greeting is sent on a viewer's first Twitch chat message, including a !command.
  • After that, the viewer is not greeted again until the Greeting Reset Interval has passed. The default is 24 hours.
  • A viewer with a custom greeting gets that one. Everyone else gets the default greeting.
  • Greetings always post in Twitch chat, as the chatbot account. YouTube chat is not greeted.

Greeting Settings

Click Settings on the Greetings tab.

  1. Default turns the greeting for everyone on or off. Custom turns all per-viewer greetings on or off. Turn both off to stop greetings entirely.
  2. How many hours before a viewer can be greeted again. Minimum 1. An empty or invalid value saves as 24.
  3. Only {username} is filled in when the greeting is sent. {user_id} is listed here but stays as plain text in chat.

The Default Greeting Text cannot be empty. Turn off Default instead if you only want custom greetings.

Give a viewer a custom greeting

Open Add New Greeting

Click New Greeting on the Greetings tab.

Enter the Twitch username and message

Type the viewer's Twitch username and the greeting. {username} becomes their name. Click Add Greeting.

Mycelian shows "Looking up Twitch user..." and finds the account's user ID, so the greeting keeps working if the viewer changes their name later. This needs Twitch to be connected. Each viewer can have only one custom greeting.

Check the card

The new card appears on the tab.

Edit changes the greeting text and the Enabled switch. User ID and Username are shown read-only. The search box filters by username or greeting text.

In the current version the Enabled switch on a custom greeting card is saved but does not stop that greeting from being sent. To stop one viewer's greeting, Delete the card. To stop all custom greetings, turn off Custom in Greeting Settings.

Questions

Greetings are not sending
  • Check that Default or Custom is on in Greeting Settings.
  • Check that Twitch is connected and the chatbot account can chat. See Twitch Setup.
  • The viewer may already have been greeted within the reset interval. Each viewer is greeted at most once per interval.
Too many greetings in a busy chat

Raise the Greeting Reset Interval, for example to 168 hours (one week), so regulars are greeted less often. Or turn off Default and keep custom greetings for a few regulars.

"User already has a greeting"

Each viewer can have one custom greeting. Edit the existing card instead.
