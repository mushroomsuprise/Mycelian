Mycelian talks to OBS through OBS's built-in WebSocket server. You turn the server on in OBS, then give Mycelian the host, port and password.

{{icon:schedule}} About 3 minutes {{icon:videocam}} OBS Studio 28 or newer {{icon:place}} SettingsOBS

You do not need this connection to show overlays. Browser sources work with only a URL (see OBS Browser Sources). The WebSocket adds the extras listed under What the connection does below.

Before you start

  • OBS Studio 28 or newer is installed. Those versions include the WebSocket server; older versions need the separate obs-websocket plugin.
  • You know which computer runs OBS. Use localhost when it is the same computer as Mycelian.
  • If OBS runs on another computer, its firewall allows incoming connections on the WebSocket port (default 4455).

Connect OBS

Turn on the WebSocket server in OBS

In OBS, open ToolsWebSocket Server Settings.

  1. Tick Enable WebSocket server.
  2. Note the Server Port. The default is 4455.
  3. With Enable Authentication on, copy the Server Password. Show Connect Info also shows the port and password. Click OK to save.

Enter the values in Mycelian

Open SettingsOBS. The connection settings are on the left; the right-hand column repeats the steps above as a WebSocket checklist.

  1. Enable OBS integration is on by default. Turn it off to stop Mycelian from connecting to OBS at all; the card then says "OBS integration is off."
  2. Host defaults to localhost and Port to 4455; both are plain fields. Paste the OBS Server Password into WebSocket password (masked; the eye icon shows it). Leave it empty if authentication is off in OBS.
  3. Test is on the connection card. It saves these settings first, then tries to connect and asks OBS for its scene list.
  4. Save is in the tab's header, next to Discard. Unsaved changes shows until you save.

Check it worked

Test shows a "Testing the OBS connection" notice that ends with "Connected to OBS". The header pill turns green and the card shows the OBS and WebSocket versions:

If OBS is closed, Mycelian keeps retrying in the background (5 seconds at first, then up to every 45 seconds). You can start OBS before or after Mycelian.

What the connection does

  • Refreshes Mycelian's own browser sources once after the WebSocket connects, so overlays that loaded before Mycelian was ready recover. Other browser sources (StreamElements, YouTube and the rest) are left alone.
  • Add to OBS: the OBS button on each card under SettingsAbout → Browser source URLs creates the browser source in a scene for you.
  • Connector actions: OBS actions such as Set program scene, Show/hide scene item, Toggle input mute and Start stream. See Connector Actions.

OBS has no WebSocket command to reload custom browser docks. If a dock opened before Mycelian, restart OBS while Mycelian is running. See OBS Browser Sources.

If something goes wrong

Test says "OBS isn't open" or "Couldn't reach OBS"

"OBS isn't open" means no OBS is running on this computer; open it and test again. "OBS is open, but its WebSocket server isn't answering" means Enable WebSocket server is not ticked or the port is different. "Couldn't reach OBS at localhost:4455" (with your host and port) means nothing answered there. Copy details on the notice copies the exact text from OBS or the network.

Wrong password, or "OBS rejected the WebSocket password"

The password does not match (or OBS asks for one and the field is empty: "OBS needs a WebSocket password"). In OBS click Show Connect Info, copy the password again, paste it into WebSocket password, and click Save. Watch for a stray space at the end.

OBS is on another computer

Enter that computer's IP address in Host (for example 192.168.1.20). Allow the port through its firewall. Overlay URLs still point at the computer running Mycelian.

"OBS WebSocket is not enabled" when clicking Add to OBS

Enable OBS integration is off. Turn it on in SettingsOBS and click Save. If it says "OBS WebSocket is not connected." instead, OBS is closed or the settings are wrong.
