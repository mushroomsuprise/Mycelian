Save memorable lines from your stream and let chat pull them back up. Quotes are numbered. Viewers use the built-in !quote and !add_quote commands; you manage the list on the Quotes tab.

The Quotes tab

  1. New Quote adds one by hand. Settings turns the quote system on or off and sets the cooldown.
  2. A quote without an author shows Anonymous.

Add a quote from the app

  1. Click New Quote.
  2. Type the line in Quote Text. Leave out the quotation marks; the card adds them.
  3. Optionally fill in Author.
  4. Click Add Quote. A toast confirms "Quote #N added successfully!"

Edit on a card changes the text and author (Update Quote). The number stays the same.

Chat commands

These are built in. You do not create them on the Commands tab, and no custom command can use the names quote or add_quote.

Type in chatBot replies
!quoteA random quote, as 12. I meant to jump into the lava.
!quote 12Quote number 12, or Quote #12 not found!
!quote lavaThe best match for lava in the text or author, or No quotes found matching 'lava'
!add_quote "text" authorSaves a new quote and replies Quote #14 added successfully! The author after the closing quotation mark is optional.

Anyone in chat can use !add_quote. There is no moderator-only setting for it. Review new quotes on the tab and delete anything you do not want.

Quote Settings

  • Enable Quote System turns !quote and !add_quote on or off. It takes effect as soon as you flip it.
  • Global Quote Cooldown is shared by everyone. The default is 30 seconds. It starts when a quote is posted, not when one is added.

Questions

Why did my quote numbers skip?

A new quote gets the highest number plus one. Deleting a quote does not renumber the others, so there can be gaps.

Can I post a quote from my own command?

The Variables panel has a Quotes group with {quote.id.text}, {quote.id.author} and similar. They fill in on the card preview, but chat replies currently post them as plain text. Point viewers to !quote instead. See Chatbot Variables.

!quote does nothing

Check that Enable Quote System is on and that Twitch is connected. If the cooldown is running the bot says so. Quote commands only work in Twitch chat.
