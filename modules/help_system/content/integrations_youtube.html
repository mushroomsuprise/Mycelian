Playlist filter

Under Ignore playlists on the right of SettingsYouTube, type a playlist name and press Enter or click Add. If the newest upload is in a listed playlist, Mycelian skips it and uses the next newest video.

  • Matching ignores case but needs the whole name: Shorts excludes a playlist named "Shorts", not "Short Clips".
  • A video is excluded if it is in any listed playlist on its channel.
  • Each filtered playlist costs extra API quota every update cycle.

Use it to keep Shorts, clips, or a series you do not want to promote out of the "latest video".

Show chat in the overlay

YouTube chat messages are off by default in the chat overlay. In the chat template's Source Settings, turn on Enable YouTube Chat (EnableYouTubeChat in chat.json). Membership and Super Chat alerts still fire when it is off.

Permission

Live chat uses the youtube.force-ssl scope so Mycelian can read live chat and send chatbot replies. If you connected earlier with read-only access, click the {{icon:logout}} Disconnect icon on the live chat card, then Connect to grant it.

Quota

  • The YouTube Data API allows 10,000 units per day by default.
  • When the quota runs out, the Channel lookups card shows Quota Exceeded (retry in 1 hour) and Mycelian tries again an hour later.
  • Live chat polling costs about 5 units per poll and follows the interval Google asks for (often about 5 seconds). Long streams may need a quota extension.
  • Fewer channels and fewer filtered playlists use less quota.

If the data looks wrong

The latest video is not updating

Uploads are checked every 30 minutes, so a new video can take that long to appear. The {{icon:refresh}} icon on the Channel lookups card only re-reads the status; it does not ask YouTube again. If the playlist filter is on, the new video may be excluded; check your filter list.

A video I just published does not show

Only public videos are detected for upload monitoring.

A per-channel variable says "Channel not found"

The name after the brace must match the channel's display name with spaces, hyphens and underscores removed. The variable picker in the Chatbot tab lists the exact variables for each configured channel.
